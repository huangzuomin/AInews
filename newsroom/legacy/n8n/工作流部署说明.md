# AI内参日报生成工作流 - 部署配置说明

## 概述

本文档详细说明如何在n8n中部署和配置AI内参日报生成工作流。该工作流实现了完全自动化的AI资讯日报生成流程。

## 工作流文件

- **主工作流**: `AI_Daily_Report_Workflow.json`
- **执行时间**: 每日20:05自动触发
- **预计执行时长**: 15-30分钟

## 部署步骤

### 1. 导入工作流

1. 登录n8n管理界面
2. 点击「Import from file」
3. 选择 `AI_Daily_Report_Workflow.json` 文件
4. 确认导入

### 2. 配置数据库连接

#### 创建PostgreSQL凭证

1. 进入「Credentials」页面
2. 点击「Add Credential」
3. 选择「Postgres」
4. 配置以下参数：
   - **Name**: `PostgreSQL Database`
   - **Host**: 数据库服务器地址
   - **Database**: 数据库名称
   - **User**: 数据库用户名
   - **Password**: 数据库密码
   - **Port**: 5432（默认）
   - **SSL**: 根据实际情况配置

#### 数据库表结构要求

确保 `ai_articles` 表包含以下字段：

```sql
CREATE TABLE IF NOT EXISTS ai_articles (
    id SERIAL PRIMARY KEY,
    title VARCHAR(500) NOT NULL,
    content TEXT NOT NULL,
    source_url VARCHAR(1000),
    author VARCHAR(200),
    published_at TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    word_count INTEGER,
    ai_score DECIMAL(5,2),
    status VARCHAR(50) DEFAULT 'draft',
    summary TEXT,
    is_selected BOOLEAN DEFAULT FALSE
);
```

### 3. 配置OpenAI API

#### 创建OpenAI凭证

1. 进入「Credentials」页面
2. 点击「Add Credential」
3. 选择「OpenAI」
4. 配置以下参数：
   - **Name**: `OpenAI API`
   - **API Key**: 您的OpenAI API密钥
   - **Organization ID**: （可选）您的组织ID

#### API使用说明

- **模型**: 默认使用 `gpt-4`
- **评分节点**: 温度0.3，最大令牌500
- **生成节点**: 温度0.7，最大令牌3000
- **重试机制**: 最多3次，间隔10秒

### 4. 配置邮件通知

#### 创建SMTP凭证

1. 进入「Credentials」页面
2. 点击「Add Credential」
3. 选择「SMTP」
4. 配置以下参数：
   - **Name**: `SMTP Email`
   - **Host**: SMTP服务器地址
   - **Port**: SMTP端口（通常587或465）
   - **User**: 邮箱用户名
   - **Password**: 邮箱密码或应用密码
   - **Security**: TLS或SSL

## 工作流节点说明

### 1. 定时触发器
- **类型**: Cron Trigger
- **时间**: 每日20:05 (`5 20 * * *`)
- **功能**: 自动启动工作流

### 2. 提取文章数据
- **类型**: PostgreSQL
- **功能**: 查询过去24小时的文章
- **时间窗口**: 前一天20:00 - 当天20:00

### 3. 拆分文章列表
- **类型**: Split In Batches
- **功能**: 将文章列表拆分为单个项目进行处理
- **批次大小**: 1

### 4. 文章评分
- **类型**: OpenAI
- **功能**: 使用LLM对文章进行多维度评分
- **评分维度**: 创新性、影响力、清晰度、深度

### 5. 计算最终评分
- **类型**: Code (JavaScript)
- **功能**: 计算加权分数和最终AI评分
- **公式**: `(novelty*0.3 + impact*0.4 + clarity*0.1 + depth*0.2) + word_count*0.00001`

### 6. 更新评分到数据库
- **类型**: PostgreSQL
- **功能**: 将计算出的ai_score更新到数据库

### 7. 合并评分结果
- **类型**: Merge
- **功能**: 等待所有文章评分完成

### 8. 筛选Top5文章
- **类型**: Code (JavaScript)
- **功能**: 按ai_score降序排序，选取前5篇

### 9. 生成综述文章
- **类型**: OpenAI
- **功能**: 使用LLM生成结构化的日报文章
- **输出格式**: Markdown

### 10. 格式化日报数据
- **类型**: Code (JavaScript)
- **功能**: 解析和格式化日报内容

### 11. 存储日报到数据库
- **类型**: PostgreSQL
- **功能**: 将生成的日报保存为新文章

### 12. 成功/错误通知
- **类型**: Email Send
- **功能**: 发送执行结果通知

## 配置参数调整

### 可调整的关键参数

1. **文章数量**: 在「筛选Top5文章」节点中修改 `slice(0, 5)` 的数字
2. **评分权重**: 在「计算最终评分」节点中修改权重系数
3. **时间窗口**: 在「提取文章数据」节点中修改SQL查询的时间条件
4. **LLM模型**: 在OpenAI节点中修改model参数
5. **Prompt模板**: 在OpenAI节点中修改消息内容

### 评分权重说明

- **影响力 (impact_score)**: 40% - 最重要的评分维度
- **创新性 (novelty_score)**: 30% - 技术突破和新颖观点
- **深度 (depth_score)**: 20% - 分析的深入程度
- **清晰度 (clarity_score)**: 10% - 文章的可读性

## 监控和维护

### 执行监控

1. 在n8n「Executions」页面查看工作流执行历史
2. 检查每日20:05后的执行状态
3. 关注执行时长和错误信息

### 常见问题排查

1. **数据库连接失败**
   - 检查数据库凭证配置
   - 确认网络连接
   - 验证数据库权限

2. **OpenAI API调用失败**
   - 检查API密钥有效性
   - 确认账户余额
   - 查看API使用限制

3. **邮件发送失败**
   - 检查SMTP配置
   - 验证邮箱凭证
   - 确认防火墙设置

### 性能优化建议

1. **并行处理**: 可以修改「拆分文章列表」的批次大小来并行处理多篇文章
2. **缓存机制**: 对于重复文章可以添加缓存逻辑
3. **错误重试**: 已配置3次重试机制，可根据需要调整

## 安全注意事项

1. **API密钥安全**: 确保OpenAI API密钥安全存储，定期轮换
2. **数据库安全**: 使用最小权限原则配置数据库用户
3. **网络安全**: 确保n8n实例的网络安全配置
4. **日志管理**: 定期清理执行日志，避免敏感信息泄露

## 扩展功能建议

1. **多语言支持**: 可以添加语言检测和翻译功能
