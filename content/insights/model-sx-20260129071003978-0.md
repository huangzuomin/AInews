TL;DR： 
> 特斯拉老大哥Model S/X宣布“退役”，马斯克决定掀掉汽车桌子改玩机器人。弗里蒙特工厂变身“造人基地”，Optimus V3准备在2026年接管世界，老马这回是真的要在AI这条路上“一条道走到黑”了。

在科技圈，马斯克的嘴，向来是“骗人的鬼”和“未来的光”交织的混沌体。但这一次，老马似乎不打算给燃油车（甚至是自家老款电动车）留任何面子。周三的财报电话会议上，马斯克扔出了一个重磅炸弹：特斯拉将正式停产 Model S 和 Model X。没错，这两款曾凭一己之力定义了“高端电动车”的元老，即将完成它们的历史使命，给特斯拉的下一段征程——机器人，腾地方。[^1]

### 别了，老伙计：Model S/X 也要变成“时代的眼泪”？

曾几何时，Model S 的加速和 Model X 的鹰翼门是科技新贵的标配，也是特斯拉从“车库作坊”走向“万亿帝国”的敲门砖。但花无百日红，在最近的投资者会议上，马斯克直截了当地表示：“是时候结束 Model S 和 X 计划了。”按照计划，这两款车型的产线将在下个季度开始逐步关停。[^1]

为什么要杀掉自家的“开国元勋”？原因简单粗暴：搞钱和搞机器人。随着汽车业务增长放缓，这两款老机型不仅维护成本高，还占着宝贵的工厂空间。在老马眼中，既然汽车业务已经进入“平替时代”，不如把弗里蒙特工厂的产线全面改造，迎接真正的未来——Optimus 人形机器人。[^2] 对特斯拉的老车主来说，这可能是“爷青结”的瞬间，但对马斯克来说，这只是在通往 25 万亿美元估值的路上，踢开了两块已经不那么闪光的垫脚石。

### Optimus V3 登场：马斯克不仅想做你的司机，还想做你的保姆

马斯克这次转型的底气，很大程度上来自于那个代号为 Optimus 的“金属小人”。他曾多次在公开场合表示，特斯拉未来 80% 的价值将来自机器人业务。[^3] 为了给这块“大饼”加点料，他预告了 Optimus V3 将于 2026 年第一季度正式发布。[^4]

> “如果你对机器人的可靠性和安全性有信心，明年底你就能买到一个能帮你干一切活的 Optimus。”——马斯克在达沃斯论坛如是说。

为了实现这个诺言，特斯拉正计划在 2025 年底启动年产 100 万台规模的生产线。[^4] 想象一下，以后你去特斯拉门店，销售可能不再问你“要长续航版还是高性能版车”，而是问你“要家务型机器人还是工业型机器人”。马斯克甚至大胆预测，到 2026 年底，这些机器人将能够处理极其复杂的任务，而不仅仅是现在工厂里那种简单的“搬运工”。[^2][[^3]]

### 25万亿美元的“大饼”：是科技革命还是绝地求生？

把汽车公司的招牌摘下来，挂上“机器人公司”的幌子，这转型跨度确实有点大。马斯克现在的蓝图里，AI 已经成了绝对的 C 位。他坚信 AI 最快在今年底就能超越人类智能，而特斯拉的自动驾驶（Robotaxi）和 Optimus 就是这种智能的最佳载体。[^3] 

然而，资本市场对此的态度也是“又怕又爱”。一方面，特斯拉的股价在马斯克达沃斯演讲后应声大涨 4%，抹平了年初的不少跌幅；另一方面，批评者认为这是在转移视线，毕竟特斯拉的汽车交付量确实已经连续两年下滑。[^3] 25 万亿美元的估值目标听起来像是个科幻小说，但在老马的剧本里，只要星舰能回收、机器人能大卖、AI 能上天，这个数字就只是时间问题。[^3][[^5]]

从四个轮子的“智能终端”到两条腿的“人形工具”，特斯拉的这次断舍离，更像是一场豪赌。老马已经把所有的筹码都压在了 AI 和机器人身上，至于 Model S/X 留下的那点怀旧情怀，可能只能在未来的机器人博物馆里找到了。
