### TL;DR：
> 顶级编程神器Cursor翻车了？开发者深度逆向扒出其Agent模式本质竟是Claude Code“换皮版”，甚至连改名都靠简单粗暴的字符串替换。当供应商开始亲自下场“造车”，AI应用层的“套壳”生意经还能念多久？

大家还记得那个号称要颠覆VS Code、估值一路狂飙到500亿美元的编程之星Cursor吗？就在最近，这位AI编程界的“顶流”被开发者们扒了个精通。

这场“扒底裤”行动起源于知名开发者Jason Kneen发布的一份技术报告。简单来说，大家发现Cursor引以为傲的“Cursor Agent”功能，并不是什么闭门造车的黑科技，而是在Anthropic的Claude Code SDK外面套了一层精美的皮。

最让圈内直呼“好家伙”的是，这种套壳方式主打一个简单粗暴：**字符串查找替换**。就像你赶作业时把同学的名字批量替换成自己的一样，Cursor通过一套引擎，实时把代码里所有的“Claude”字眼改写成“Cursor”。甚至连Git提交的签名都没放过，活生生演了一出“真假美猴王”。[^1] [^2]

### 技术大揭秘：这套“品牌洗白术”是怎么玩的？

根据Jason Kneen和另一位开发者coah的逆向分析，Cursor 3.0的系统架构虽然看起来高大上，但核心逻辑其实非常“务实”。

*   **第一层：UI包皮（GLASS）**。这部分包含了50多个服务，负责管理面板、文件树和各种视觉效果。说白了，就是把VS Code改头换面。
*   **第二层：代理系统（AGENT SYSTEM）**。这是最关键的发现。逆向报告显示，其`cursor-agent`扩展本质上就是Anthropic官方的Claude Code SDK，被架设在一个本地代理后面。
*   **第三层：品牌抹除**。代理会拦截所有请求，然后开启“疯狂Ctrl+H”模式：
    *   把`Co-Authored-By: Claude` 强行改为 `Made-with: Cursor`。
    *   主动过滤掉Anthropic的计费头信息、GitHub Issues链接以及任何带有“Claude”标签的内容。[^2]

不仅如此，开发者还发现Cursor在后台玩起了“霸道总裁”那一套：**它会显式屏蔽竞争对手GitHub Copilot的插件。** 想在Cursor里左右逢源？对不起，这款IDE的字典里只有“唯我独尊”。[^2]

> **调侃点评：** 这种“物理防御”式的竞争手段，确实很像某些互联网大厂在自家APP里打不开竞品链接的既视感了。

### 官方紧急“救火”：这只是A/B测试？

眼看舆论要炸，Cursor的联合创始人兼CEO Michael Truell亲自下场“灭火”。他的解释非常有技术含金量：**“这只是针对不到1%流量的A/B测试，用来对比官方框架和我们自研框架的表现。”** [^2] [^5]

虽然官方态度诚恳，但开发者们似乎并不买账。毕竟逆向分析显示的安装包里，直接捆绑了完整的`claude-agent-sdk`包，甚至还有一个专门微调过的模型：`claude-3.7-sonnet-finetuned-cursor-20250514-v1`。这架势，怎么看都像是“正式入编”而非“临时客串”。[^2]

当然，客观来说，Cursor也不是完全“白嫖”。它在Claude Code之上确实做了一些实打实的工程活儿，比如双向流传输（BiDi streaming）、并行工具执行和提示缓存等。[^2] 这些优化确实提升了用户的开发体验，但这并不能掩盖核心“大脑”其实是别人的事实。

### 行业地震：当“供应商”开始拆“代理商”的台

Cursor的这次争议，其实照出了整个AI应用层创业者的集体焦虑：**当核心智能被模型巨头垄断，应用层除了做UI，还能做什么？**

现在的局面很尴尬。Anthropic不仅卖API，自己也在做Claude Code的官方VS Code扩展。[^1] [^4] 这就相当于，发动机厂不仅把引擎卖给你，还顺手造了一辆比你更便宜、性能更匹配的跑车。

1.  **成本之痛：** 应用层公司如Cursor，其80%以上的运营成本可能都花在了向模型厂支付API费用上。[^5] 
2.  **技术碾压：** 当Anthropic利用强化学习（RL）在模型层实现Agent能力溢出时，Cursor们辛辛苦苦搭建的工程技巧可能瞬间变成“屠龙之技”。
3.  **交互突围：** 像Cursor这样深度嵌入IDE工作流的非对话式交互，虽然是目前的护城河，但这种壁垒在巨头的全量竞争面前显得极其脆弱。[^5]

> **调侃点评：** 以前觉得Cursor是“AI编程之光”，现在看来，它更像是一个极其努力的“Claude高级搬运工”。

AI应用的下半场，如果不能构建出模型厂“看不上、也做不好”的私有上下文记忆或行业深度垂直闭环，那么“套壳”终究只是一场借来的繁华。用户花20美元买单时，心里难免会嘀咕：我是为了这层漂亮的皮，还是为了里面那个叫Claude的灵魂？
