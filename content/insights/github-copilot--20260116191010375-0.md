### TL;DR： 
> GitHub 宕机两小时，“粉色独角兽”刷屏背后是开发者积压已久的怒火。微软强推 Copilot 的“霸王条款”引发 Gentoo Linux 等大佬带头跑路，开源社区正上演一场“去微软化”的大逃离。

就在几天前，全球最大的“同性交友网站”——GitHub 突然罢工了。

大批开发者对着满屏幕的“粉色独角兽”（GitHub 宕机时的标志性错误页面）面面相觑。那一刻，全世界的迭代冲刺仿佛按下了暂停键，本地提交的代码推不上去，API 报错弹个不停。有人在 X 上自嘲：“我以为自己眼花了，后来发现，原来没 GitHub 我真的连汇报都不会写了。”[^1]

虽然 GitHub 在两小时后就满血复活，但这波“小插曲”却成了引爆社区情绪的导火索。更有意思的是，大伙儿这次没去关心服务器是不是被哪位实习生拔了插头，而是整齐划一地把矛头指向了微软的“亲儿子”——**GitHub Copilot**。

### 贴脸开大：当 GitHub 变成 Copilot 的“直销中心”

如果说宕机只是“意外”，那么 GitHub 近期的一系列操作，在很多开发者眼里就是“蓄谋已久的 PUA”。

开源界的大佬 **Gentoo Linux** 最近就公开表示：受够了，我们要搬家。[^2] 作为以“折腾”和“硬核”著称的 Linux 发行版，Gentoo 做出迁出 GitHub 的决定绝非易事。而压死骆驼的最后一根稻草，正是 GitHub 试图强行在代码仓库里“塞”进 Copilot。

据 Gentoo 开发者吐槽，GitHub 会在仓库页面自动弹出横幅，催促贡献者启用 Copilot，甚至还威胁：如果不配合，仓库的曝光度可能会降低。这种“不买保险不让进门”的既视感，让推崇自由、开放精神的开源社区直接原地炸裂。

> “GitHub 正在公然强迫我们的仓库启用 Copilot，而这是我们明确反对的。”
> —— 某 Gentoo 理事会成员的心声

这种“贴脸开大”的推销方式，不仅干扰了正常的代码评审流程，更触及了开源界的底线：**版权与许可证**。[^3]

### “开源刺客”：你拿我的代码训练，还要卖票给我看？

程序员们最不爽的逻辑其实很简单：Copilot 就像是一个读遍了全人类代码的“超级缝合怪”。微软利用开发者们贡献给 GitHub 的开源代码进行训练，转头就把这个 AI 工具打包卖钱。

更让人生气的是，这个 AI 有时候“偷”得不太干净。有开发者发现，Copilot 生成的代码居然和某些带版权保护的原代码**逐字重复**，而且还不标注来源。[^6] 这在法律上简直是踩着 GPL 协议的脸跳舞——这到底是 AI 创作，还是“洗稿”？

早在去年，就有律师和程序员联手对微软和 OpenAI 提起了索赔高达 **649 亿**的集体诉讼。[^4] 
> **调侃点评：** 649 亿，这不仅是想让微软赔钱，简直是想让微软重新定义“开源”。

对于很多开发者来说，Copilot 就像是那个借了你作业抄、最后还成了班长、反过来还要教你写作业的调皮同学。这种身份的转变，让 GitHub 从曾经的“程序员家园”，逐渐变成了微软 AI 部门的“数据养料库”。

### 大逃离：程序员的“数字游牧”时代

既然惹不起，那还躲不起吗？

目前，Gentoo Linux 已经开始物色新家，备选名单里包括自托管的 **Gitea**、非营利组织维护的 **Codeberg**，以及老牌对手 **GitLab**。[^2]

不只是大项目，很多个人开发者也开始清理自己的 GitHub 仓库。一位开发者在抗议无效后直接放话：“如果微软不提供关闭 AI 的选项，我会把代码迁到自托管服务器上，永远不再回来。”

这种情绪的蔓延，反映了一个深刻的趋势：**GitHub 的网络效应正在被它对 AI 的激进追求所削弱。** 

当微软将 GitHub 划归至核心 AI 部门（CoreAI group）的那一刻起，它的 KPI 似乎就不再是“服务好开发者”，而是“提升 AI 指标”。正如开发者 Andi McClure 所言，微软似乎忘记了“客户留存”这种传统目标，只想把用户当成喂养 AI 的工具人。[^1]

### 未来预测：下一个“风口”是去中心化？

GitHub 曾经凭一己之力终结了代码托管的混乱时代，但现在，它的“霸权”正在动摇。如果微软继续这种“自上而下”的强制推广，我们可能会看到一个更有趣的局面：

1.  **Codeberg 等非营利平台崛起**：程序员们开始追求更纯粹的代码托管体验，没有广告，没有 AI 弹窗。
2.  **自托管重回主流**：随着云成本降低和部署工具的进化，开发者们重新发现“代码握在自己手里”才最安全。
3.  **AI 训练的合规性洗牌**：未来的 AI 可能必须证明自己的训练集是“干净”的，或者至少是给过钱的。

**总结一下：** 技术可以进步，但尊严不能被蹂躏。GitHub 如果还想当“程序员的港湾”，可能得先学会收起那副“我都是为了你好（所以请买 Copilot）”的傲慢嘴脸。
