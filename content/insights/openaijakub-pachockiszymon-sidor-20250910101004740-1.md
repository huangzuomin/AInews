TL;DR：
> Jakub Pachocki和Szymon Sidor这对从波兰高中走出的搭档，以其十几年的默契和卓越的技术实力，成为OpenAI幕后推动Dota AI、GPT-4和推理突破的关键力量。他们一个洞察科学方向并引领前沿理论，一个不知疲倦地实现工程落地，共同将看似不可能的AI愿景变为现实，塑造着AI的未来轨迹，被Sam Altman誉为“OpenAI未曾遇到过他们解决不了的问题”的可靠基石。

当Sam Altman在他的博客中罕见地致谢两位幕后英雄——Jakub Pachocki和Szymon Sidor时，整个AI社区的目光都被吸引到了聚光灯之外。在OpenAI的故事里，我们习惯了听到Altman的商业远见、Ilya Sutskever的科学哲学，以及Greg Brockman的工程魄力。然而，正是这对来自波兰的搭档，用他们深厚的默契、卓越的智慧和近乎偏执的实干精神，一次次地将“不可能”的标签撕下，塑造了这家全球最前沿AI公司的核心技术底座。他们是OpenAI的“隐形脊梁”，驱动着一个又一个让世界惊叹的AI奇迹。

### 波兰双星：不为人知的AI脊梁

他们像科幻电影中那些不露声色的天才，默默耕耘在代码和算法的深处。Jakub Pachocki与Szymon Sidor的友谊和合作始于波兰高中时代，那时，两人就已是编程竞赛场上的常客，彼此的才华和对问题的独特视角在一次次算法挑战中得到磨合。这份跨越十余年的默契，后来成为OpenAI最宝贵的财富之一。

“OpenAI还没有遇到过他们解决不了的问题。”Sam Altman寥寥数语，却掷地有声，这不仅是对他们技术能力的最高褒奖，更是对他们精神内核的精准捕捉——一种对未知永不言弃的探索欲，和将抽象设想变为现实的强大执行力。他们不追求镁光灯，却在每次关键的技术突破中留下了深刻的印记，从强化学习的早期试验，到大模型的推理能力飞跃，他们的身影几乎贯穿了OpenAI的核心里程碑。

### 挑战不可能：从Dota到GPT-4的工程奇迹

回望OpenAI的发展史，有几个瞬间无疑是里程碑式的震颤。2019年，AI在《Dota 2》世界冠军面前取得胜利，这被视为强化学习领域的一次史无前例的壮举。当时，业界普遍认为强化学习难以规模化，复杂博弈更是遥不可及。然而，OpenAI偏偏选择了迎难而上。

这场胜利的背后，是Jakub Pachocki和Szymon Sidor共同推动的Rapid分布式训练系统。正是他们，将“大规模训练到底”的想法从纸面概念落实到工程实践，最终成就了OpenAI Five。这不仅是强化学习的胜利，更为后续GPT模型的训练打下了坚实的基础。Jakub在接受《时代周刊》专访时曾这样描述他们的工作：

> “尽管它看起来只是数学，但它实际上更像自然科学，我们正试图去理解这个现象。”[^1]

这种对AI本质的深刻洞察，摆脱了技术冰冷的想象，也透露出他将AI视为一种自然现象，需要耐心观察、实验和理解的独特视角。

几年后，GPT-4的诞生再次让世界惊叹，它首次让人感受到大模型似乎真的具备了“推理能力”。在这个核心突破中，Jakub和Szymon再次扮演了关键角色，他们深入参与了GPT-4的预训练阶段，确保了模型的推理能力能够达到前所未有的高度。

### Jakub Pachocki：从天才少年到首席科学家的进化路径

Jakub Pachocki的个人轨迹，几乎与OpenAI的成长节奏同频共振。出生在波兰格但斯克的他，从小就展现出非凡的编程天赋。高中阶段，他便横扫了IOI、ACM-ICPC、Google Code Jam等顶尖赛事，更在2012年斩获Google Code Jam全球总冠军，被波兰媒体誉为“这个国家走出的最聪明头脑之一”。[^2]

他随后进入华沙大学深造，并赴美国卡内基梅隆大学攻读博士，专注于理论计算机科学与算法优化。在哈佛、伯克利等机构的研究经历，进一步拓宽了他的学术视野。

2017年，Jakub加入了尚处于起步阶段的OpenAI。他很快就成为了团队的“顶梁柱”，主导OpenAI Five的算法研究和基础设施搭建，将强化学习的规模化训练变为现实。随着公司将重心转向大语言模型，他又在GPT-4的预训练阶段承担核心角色，直接领导了相关开发工作，帮助团队在推理能力上取得突破。[^3]

2024年5月，当联合创始人Ilya Sutskever离开OpenAI后，Jakub被正式任命为首席科学家。Altman称他为“这一代最伟大的头脑之一”，而外界也普遍认为，他代表着OpenAI下一阶段的科学方向。[^2] Jakub本人对未来的描述更为冷静而富有远见：

> “今天你可以和模型对话，但它仍然只是一个需要引导的助手。我认为未来的主要变化，是让AI能够自主工作数小时甚至数天。”[^1]

他所设想的，是一个能够“持续思考的科学家”——主动处理问题、推动科学发现的AI。从竞赛舞台上的少年天才，到引领全球最前沿科研的首席科学家，Jakub的轨迹几乎没有断档，他既是技术奇才，也是一个始终把“突破不可能”当作常态的践行者。

### Szymon Sidor：沉默的实干家与工程基石

如果说Jakub是那个负责定方向、探索边界的领航员，那么Szymon Sidor就是那个稳住船体、确保航行顺利的工程师。他和Jakub一样，来自波兰，高中时便是同窗好友，一起在编程的海洋中摸索，建立了深厚的默契。

Szymon先后在剑桥大学和麻省理工学院继续深造，研究机器学习与计算机科学。毕业后，他选择在Google、Dropbox等科技巨头积累了丰富的大规模系统调试和工程研发经验。2016年，他作为最早一批研究工程师加入OpenAI。

Szymon始终保持着低调的作风，但他的贡献却无处不在。从强化学习的分布式训练，到GPT-4的预训练，再到最新推理模型的迭代，你总能找到他埋头调试、解决复杂工程难题的身影。在一次播客节目中，当被问到OpenAI是否拥有世界上最顶尖的调试人才时，Szymon只是带着一丝腼腆的笑容回答：“我就不具体说名字了。”[^4] 这种谦逊中透出的工程师特有的实干气质，是Szymon人格魅力的缩影。在OpenAI内部，他常常是最晚离开实验室的那个人。Jakub曾评价Szymon是“_indefatigable_”（不知疲倦的），并坦言自己所有的灵感如果没有Szymon的工程实现，很多想法可能只会停留在纸面上。

### 黄金搭档：AI时代的沃森与克里克

在科技史上，总有一些组合被反复提起：沃森与克里克发现DNA双螺旋，布林与佩奇创立Google。对OpenAI而言，Jakub Pachocki与Szymon Sidor的名字，也在悄然写进这份名单。他们从高中时代起便建立的深厚合作，让他们在科研和工程上形成了天然的互补。

Jakub偏向战略与理论，是推动强化学习规模化、GPT-4预训练和推理模型研究的核心科学家，他不断追问“我们能做什么？”而Szymon则更偏向工程落地，他在分布式训练系统、调试与优化中发挥关键作用，负责回答“我们如何才能做到？”正是这种理想的结合，让许多看似天马行空的研究构想，得以在短时间内真正跑起来。

Altman的那句“OpenAI还没有遇到过他们解决不了的问题”，并非夸张。无论是Dota AI的震撼问世，还是GPT-4在推理能力上的革命性突破，背后都有这对搭档的身影。在外界眼中，OpenAI的故事常常被简化为几个响亮的名字，但在OpenAI的内部，这对波兰拍档才是支撑公司科研脊梁的黄金组合，是最可靠的工程师。

或许未来的某一天，当AI真能像Jakub设想的那样，成为“能够持续思考的科学家”，人们回头就能看到，这段历史并不只是关于算法和算力的较量，而是关于两个从波兰高中走出的年轻人，如何以他们的智慧、默契和不知疲倦的努力，一次次地把不可能推向现实。这，才是Altman想让外界看见的，关于OpenAI真正王牌的故事。
