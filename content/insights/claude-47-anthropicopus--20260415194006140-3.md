### TL;DR： 
> Anthropic 开启“疯狂周”模式：Claude Opus 4.7 或本周空降，Claude Code 迎来史诗级更新，甚至能让你合上笔记本后 AI 依然在云端 007。不过，想体验最强模型得先“交出证件”，这一波身份验证让不少老玩家直呼：AI 也有“实名制”了？

生产队的驴都没有 Anthropic 这么忙。自从今年年初 Claude Cowork 发布后，Anthropic 的更新频率基本维持在“一天一个新花样”。

这不，就在本周，重磅炸弹又来了。不仅有传闻中的旗舰模型 Claude Opus 4.7，还有让程序员们又爱又恨的 Claude Code 大改版。当然，最让大家“心头一紧”的，还是那则低调更新的身份验证通知。

### 云端“值班员”：关机也能 007？

Claude Code 这次最亮眼的更新，莫过于新增的 **Routines**（日常任务自动化）功能。

简单来说，这玩意儿就是一个保存在云端的 Claude 配置包。以前你用 AI 编程，还得开着电脑盯着它跑；现在好了，Routines 支持在 Anthropic 的托管基础设施上独立运行。你合上笔记本去蹦迪，Claude 还在云端帮你修 bug。[^2]

它的触发方式非常“硬核”：
- **定时触发**：每天早上 9 点准时给昨晚的 issue 贴标签，简直是早报小秘书。
- **API 触发**：系统一报错，立马拉起任务，还没等架构师醒过来，修复建议已经躺在 Slack 里了。
- **GitHub 触发**：只要有人推代码（Push）或者提 PR，Claude 自动开启审查模式。

> **调侃式点评**：以前我们管这叫 Cron Job，现在换了 AI 皮囊，它成了“有脑子”的值班经理。不过 Pro 用户每天只能跑 5 次，这“体力限制”多少有点让牛马们想念无限续杯的本地脚本。[^1]

### 桌面端大改版：Cursor 还有机会吗？

除了内里的“心脏”变了，Claude Code 桌面端的“皮囊”也彻底整容了。现在的它不再是一个简陋的对话框，而更像是一个完整的工作台。

侧边栏、多对话并排、文件预览、甚至是类似 Git 的 Diff 视图，Anthropic 几乎把 VS Code 和 Cursor 的家底都搬上来了。[^1] 最有意思的是那个像素吉祥物，点击它竟然会有“鞭子抽打”的效果——这种官方玩梗的调侃感，真是把“AI 苦力”的氛围渲染到了极致。

前 OpenAI 首席科学家 Karpathy 曾预言，未来的软件形态将不再以文件为单元，而是以 Agent 为核心。[^1] 看着现在的 Claude Code，你很难不感叹：它正走在一条脱离“插件模式”，独立成为智能体 IDE 的快车道上。

### 突击查证件：想用 Opus 4.7？先刷个脸

就在大家为新技术狂欢时，Anthropic 的一则帮助中心更新给不少人泼了冷水：**官方开始对部分使用场景引入身份验证。** [^1]

目前，已经有网友发现，在尝试订阅最高档的 Max 会员计划时，会被要求上传身份证件。Anthropic 的理由很冠冕堂皇：“强大技术要负责任地使用，我们需要知道谁在用。”[^1] 但在社交媒体上，这被普遍解读为针对中国用户的精准“实名制”拦截。

这事儿其实挺扎心的。一方面，传闻中的 Claude Opus 4.7 和全新的 AI 设计工具本周就要上线，甚至导致 Figma 和 Adobe 的股价一度闪跌[^1]；另一方面，门槛越垒越高，普通用户想尝鲜的难度呈指数级上升。

对于国内开发者来说，这种“猫鼠游戏”已经成了日常。既然官方账号卡得严，不少人开始转向中转方案，甚至直接用国产模型“平替”。目前 GLM 4.7 等模型已经能较好地适配 Claude Code 的命令行环境，这大概就是所谓的“大厂神仙打架，小民自有妙招”。[^4]

### 搞钱与算力：Uber 已经用光了预算

为什么 Anthropic 这么急着搞身份验证和调价？说白了还是因为**太贵了**。

由于 AI 编程工具的使用量飙升，Uber 的 CTO 透露，他们 2026 年才刚过几个月，就已经把一整年的 AI 预算花光了。[^1] 为此，Anthropic 近期调整了企业版定价，从按“人头”收费转变为按“流量”收费。对于重度依赖 AI 的大厂来说，成本翻个两三倍简直是轻轻松松。

一边是算力饥渴导致的成本激增，一边是 Opus 4.7 呼之欲出的技术压力。Anthropic 这头“科技巨兽”正在一边加速，一边建立更加严密的围栏。
