### TL;DR：
> Claude Opus 4.6 推出“氪金加速包”，速度快了2.5倍，价格直接翻了6倍！这波“用钱买命（时间）”的操作让开发者集体破防，直呼它是“token界的爱马仕”，贫穷再次限制了我的Debug速度。

就在北京时间2月8日凌晨，当大多数打工人还在梦乡时，Anthropic 突然发动“背刺”，给自家的王牌模型 Claude Opus 4.6 穿上了“红舞鞋”——**极速模式（Fast mode）正式上线** [^1]。

这个模式主打一个“简单粗暴”：性能一滴没变，智力还是那个味儿，但速度直接拉满到原来的 **2.5 倍**。在 Claude Code 终端里优雅地敲下 `/fast`，那个代表速度的小闪电图标一亮，你就进入了“钞能力”领域。但这道闪电，可能不仅劈开了效率，还劈穿了你的钱包。

### 6倍溢价！这是一场关于“急人之所急”的降维打击

为什么说网友们破防了？因为这个 Fast Mode 的定价，简直是让 OpenAI 看了都直呼“内行”。

在标准模式下，Opus 4.6 的 API 定价是输入 5 美元/百万 token，输出 25 美元/百万 token。这本来就不便宜了，结果 Fast Mode 直接把价格推到了：**输入 30 美元，输出 150 美元** [^2]。

> **调侃式点评：** 这种“加量不加价”的反向操作，让 Fast Mode 成功坐稳了“史上最贵模型”的宝座。

更绝的是它的计费逻辑。Fast Mode 不走你现有的订阅额度，而是**完全独立的按量计费**。即便你账户里躺着几百美元的固定配额，只要开了闪电图标，每一秒钟流走的都是真金白银。

如果你要处理长上下文（Long Context），那场面更刺激。Opus 4.6 支持 100 万 token 的超长上下文，可一旦输入超过 20 万 token，Fast Mode 的价格会再次翻倍——**输入 60 美元，输出 225 美元！** [^1] 有网友感慨：“产生亏损和破产，从未像今天这样快。”

### 凭什么敢卖这么贵？因为Opus 4.6真的在“吊打”全场

虽然价格贵得离谱，但不得不承认，Anthropic 这次是有底气的。目前的 Opus 4.6，基本就是大模型界的“六边形战士”。

在最新的 Artificial Analysis 智能指数榜单中，Opus 4.6 以 53 分的综合成绩强势登顶，把 GPT-5.2 都甩在了身后 [^3]。它不仅在代码、文本、专家三大竞技场断层领先，最让开发者尖叫的是它的**自我纠错能力**和**工程突破**：

*   **智能体天花板：** 它能自主判断任务难度，简单的部分快速推进，复杂的部分深度思考，甚至会推翻自己之前不合理的路径 [^3]。
*   **100万Token“大海捞针”：** 在长上下文测试中，Opus 4.6 的得分高达 76%，而同门的 Sonnet 4.5 只有可怜的 18.5%。这代差，基本上就是“量子计算机 vs 算盘” [^3]。
*   **硬核实操：** Anthropic 曾用 16 个 Opus 4.6 组队，在没怎么用人帮手的情况下，用 Rust 语言撸出了一个能编译 Linux 内核的 C 编译器 [^3]。

所以，当 AI 工程师 Dan McAteer 说出“Fast Mode 真的快到飞起，一分钟就能修个 Bug”时 [^1]，你就明白为什么有人一边骂贵，一边又忍不住想点那个闪电图标了。

### 速度本身，就是 AI 时代的“终极货币”

6 倍价格换 2.5 倍速度，这笔账算起来肯定亏。但对那些在生产环境里“救火”的架构师，或者急着上线产品原型的创业者来说，**时间才是最昂贵的成本**。

Anthropic 的工程师 Alex Albert 认为，速度感在某种程度上就是智力感的延伸 [^4]。当模型响应变得即时，人类的思维流才不会被打断。

目前，Anthropic 为了安抚大家，在 2 月 16 日前还提供了一次 50% 的限时折扣 [^2]。这更像是一次市场压力测试：Anthropic 想知道，在智力已经卷到边际效应递减的今天，到底有多少人愿意为“快”这一个维度，支付数倍的溢价。

在这个 token 贵的像金粉一样的时代，Fast Mode 的出现标志着一个新阶段：**AI 不再只是工具，它正在变成一种按秒计费的高端生产力服务。** 

至于你点不点那个 `/fast`？这取决于你的 Bug 够不够急，或者你的预算够不够硬。
