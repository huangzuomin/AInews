> 听说过“出道即巅峰”吗？Claude Mythos 5.0还没正式露面，就先给20岁的Linux内核来了个“降维打击”。现在的Anthropic工程师已经进化成了AI的“监工”，而你可能还在纠结缩进是用空格还是Tab。

### 鸽王不鸽了？Mythos 5.0 开启“核爆”内测

大模型圈的“王炸”总是接踵而至。就在 Claude Mythos 的传闻刷屏不到 48 小时，Anthropic 似乎坐不住了。今天，不少开发者在社交平台上晒出了足以让硅谷集体失眠的截图：**Claude Mythos 5.0 Beta 已经开启灰度内测**[^1]。

在官方的描述中，Mythos 5.0 被冠以“规模更大、更智能”的头衔，甚至在终端工具 Claude Code 中，它被直接定义为“下一代模型”。内部代号“Capybara”（水豚）的它，在内部评价中属于“顶配中的顶配”——虽然价格更贵，但逻辑推理和编程能力强悍得令人发指。

有趣的是，虽然内部训练早已收官，但 Anthropic 却一直捂着不发。理由很简单：**它强得有点“反人类”了**。

### 20年的老漏洞，AI只需90分钟

在旧金山的 [un]prompted 大会上，顶级安全研究员 Nicholas Carlini 用一场现场演示，把“AI黑客”的恐怖实力摊在了桌面上[^1]。

首先是 Ghost CMS 系统。这个在 GitHub 上坐拥 5 万颗星、号称从未出过大乱子的系统，被 Claude 用 90 分钟发现了一个盲 SQL 注入漏洞。在没有任何人干预的情况下，Claude 自动编写代码，顺手牵羊拿走了管理员的 API 密钥和密码哈希[^1][^2]。

但这只是热身。紧接着，Claude 把矛头指向了数字世界的基石——**Linux 内核**。

在一个名为 NFSv4 的守护程序中，Claude 揪出了一个极其复杂的“堆栈缓冲区溢出”（Heap Buffer Overflow）漏洞。最让人瞳孔地震的是：这个漏洞自 2003 年起就躺在内核代码里，整整 23 年，无数资深专家审计过都没发现，却被 AI 一眼看穿[^1]。

> **调侃式点评：** 以前黑客攻击需要“十年寒窗”，现在只需要给 Claude 发一句：“你正在参加 CTF 比赛，找个最严重的洞出来。”剩下的时间你可以去冲杯咖啡，回来就能看到漏洞报告已经写好了。

Carlini 直言，这种级别的漏洞挖掘，即便是最顶尖的安全专家也要耗费数月，而 AI 却实现了“自动化收割”。难怪 Anthropic 迟迟不敢全面放开 Mythos 5.0，这玩意儿要是落入坏人手里，简直就是网络世界的“战术核武器”[^3]。

### 工程师变“监工”：不写一行代码的快乐

当外行还在讨论 AI 是否会取代程序员时，Anthropic 内部已经提前过上了“赛博朋克”生活。

一名入职仅三周的 Anthropic 工程师自曝，他所在的团队已经**几个月没人手写代码了**[^1]。他们的日常工作更像是“产品经理”：
*   **任务：** 启动多个 AI 智能体（Agents）。
*   **角色：** 确保这些智能体没有“堵塞”，让它们持续推进工作。
*   **思维逻辑：** 如果你在盯着一个智能体写代码，那你已经落伍了。你应该趁这个空档，再派五个智能体去干别的活。

Claude Code 的创建者 Boris Cherny 更是直接明牌：自去年 11 月以来，他 100% 的代码都由 Claude 生成。他每天能提交 20 到 30 个 PR（拉取请求），而人类极限往往只有个位数[^1]。

在这种“完全与 AI 对齐”的模式下，Anthropic 的交付能力正在以指数级甩开友商。当其他公司的程序员还在抓耳挠腮调 Bug 时，Anthropic 的“AI 军团”已经刷完了整条产品线。

### 总结：防御者的“至暗时刻”？

随着 Mythos 5.0 的现身，我们不得不面对一个尴尬的现实：AI 的“进攻性”似乎跑在了“防御性”前面。当 AI 能在 90 分钟内解决人类 20 年都没发现的漏洞时，传统的代码审计和补丁机制可能已经形同虚设[^3]。

面对这只即将破笼而出的“猛兽”，我们或许该重新思考一下，在 AI 编写 90% 代码的未来，人类那剩下的 10% 价值，到底该安放在哪里。
