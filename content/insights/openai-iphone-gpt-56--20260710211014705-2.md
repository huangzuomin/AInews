TL;DR：
> OpenAI 今晚放大招：GPT-5.6 不仅性能碾压前代，还学苹果搞起了产品分级——Sol（太阳）、Terra（地球）、Luna（月亮）。最骚的是，旗舰版 Sol 定价只和上代标准版持平，把友商 Claude 搞得有点尴尬。但别急着用，美国爸爸要先审查，目前只对“信得过”的伙伴开放。

朋友们，OpenAI 这次是真的把大模型做成了 iPhone 产品线——不是开玩笑，是认真的。

就在大家还在消化 GPT-5.5 的时候，OpenAI 冷不丁端出了 GPT-5.6，而且一口气发了三个版本：Sol、Terra、Luna，对应太阳、地球、月亮。听起来像天文课，实际上就是旗舰版、标准版和青春版。按照官方说法，Sol 是家族大哥，性能最强；Terra 是日常打工人，性价比拉满；Luna 则是跑量小能手，便宜又大碗。这波操作，有没有让你想起 iPhone 的 Pro Max、Pro 和 SE？[^1]

## 定价：卷王来了，Claude 被按在地上摩擦

不过最让人意外的不是名字，而是价格。

GPT-5.6 Sol 每百万 token 输入 5 美元、输出 30 美元。眼尖的朋友会发现：这不就是 GPT-5.5 标准版的价格吗？没错，OpenAI 把新一代旗舰定在了和上一代中端一样的价位，而 GPT-5.5 Pro 还要 30/180 美元，贵了整整六倍。这波操作，堪称“加量还降价”。[^2]

Terra 更狠，性能接近 GPT-5.5，价格直接砍半。Luna 只要 1/6 美元，适合那些对成本敏感的体力活。

对比之下，Claude Fable 5 要 10/50 美元，直接被 GPT-5.6 系列干翻。OpenAI 官方还公布了基准测试，在 Agent's Last Exam（ALE）上 Sol 拿了 56.3 分，比 Fable 5 高 13 分，成本却只有四分之一。杀人诛心啊。[^3]

## 性能：不只是快，还更省

GPT-5.6 在编程、网络安全、生物研究上都有明显提升。特别值得一提的是，OpenAI 这次重点强调了一个叫 ALE 的基准测试，测试的不是刷题，而是模拟真正的职场牛马——能不能独立完成端到端的工作。Sol 在这项测试上直接碾压对手。

此外，Sol 还引入了两种新的推理模式：**Max 模式**让模型花更多时间深入思考，**Ultra 模式**则能同时调动四个子智能体，像一个“AI 项目经理”带着团队干活。在 Terminal-Bench 2.1 上，Ultra 模式得分 91.9%，比单打独斗强不少。[^4]

更让人心动的是，OpenAI 表示会用更少的 token 做到同样的甚至更好的结果。在 GeneBench v1 上，Sol 不仅比 GPT-5.5 强，消耗的 token 还更少。对于每天跟 API 费用打交道的开发者来说，这比任何花哨的功能都实在。

## 安全：双刃剑，政府盯上了

这次发布还有一个有趣的背景：GPT-5.6 是应美国政府要求“有限预览”的。也就是说，目前只有大约 20 家经过审批的合作伙伴能通过 API 或 Codex 使用，普通用户还得等几周。

OpenAI 花了大篇幅讲安全，称 Sol 是他们最强的网络安全模型，在漏洞发掘上表现出色，但强调没有越过自己的 Critical 门槛。它更像一个能帮防守方找漏洞的工具，而不是攻击者的武器。不过，政府显然不放心，先小范围试试。[^5]

## 整合产品：ChatGPT-Work 登场

除了模型本身，OpenAI 还发布了 ChatGPT-Work，把 Chat、Work 和 Codex 整合在一起。这有点像字节把豆包、TRAE 和即梦合并，可见大模型公司正在从单点工具走向平台生态。未来你或许不用再在几个工具之间来回切换，一个 ChatGPT 就能搞定聊天、写代码、做设计。

## 结尾：国内玩家呢？

不过，OpenAI 这套定价在 DeepSeek、豆包等国产模型面前还是贵得离谱。DeepSeek V4 每百万 token 输入只要 0.44 美元，输出 0.88 美元，Luna 都比它贵好几倍。马斯克说得对：真正决定胜败的不是最聪明的模型，而是谁能用最低成本解决真实需求。

GPT-5.6 确实看到了这一点，但前有 DeepSeek 追兵，后有美国政府审查，OpenAI 这场 AI iPhone 之旅，注定不会太平。但无论如何，这波“分层定价+性能升级”的操作，已经给行业扔下了一颗深水炸弹。
