### TL;DR： 
> AI 大神 Jeremy Howard 开启“暴走模式”，直言马斯克和 Dario Amodei 对软件工程的理解太肤浅。他认为现在的 AI 编程工具就像给开发者发“电子鸦片”，让人在“老虎机”式的爽感中逐渐退化，最终欠下一屁股还不起的“认知债”。

最近，AI 编程圈的“氛围感”快被拉满了。Anthropic 的 Claude Code 刚被捧上神坛，甚至有人吹它能用 Rust 写 C 编译器，仿佛人类明天就能集体退休。

但就在这一片“赢麻了”的欢呼声中，一位元老级人物坐不住了。Jeremy Howard，fast.ai 创始人、Kaggle 传奇、ULMFiT 论文（定义了预训练+微调范式）的亲爹，直接在播客中开炮：**“Claude Code 这条路线全错了！”** [^1]

不仅如此，他还顺带给硅谷两位顶流贴了标签——马斯克和 Anthropic CEO Dario Amodei。Jeremy 的评价简短有力：**“这帮人根本没当过现代软件工程师。”**

### 技术大揭秘：编程 vs 软件工程，傻傻分不清楚？

在 Jeremy 看来，很多人（包括那两位巨头）都犯了一个低级错误：把“写代码”等同于“软件工程”。

马斯克曾预言未来 LLM 能直接输出机器码，人类不再需要库和编程语言；Dario 则觉得初级工程师很快会被 AI 彻底自动化。Jeremy 对此冷笑一声：这就好比说只要有了自动打字机，就不需要作家和建筑师了一样。[^1]

> “编程的本质是另一种风格迁移。而软件工程的内核是组件设计、理解系统如何运作，并在此基础上持续迭代。AI 现在做的，本质上只是在训练数据的片段间进行‘插值’。”

拿那个“震惊全网”的 Claude Code 编写 Rust 版 C 编译器来说，Jeremy 找 LLVM 创始人 Chris Lattner 一对表，发现真相有点尴尬：LLVM 的逻辑早就躺在 AI 的训练数据里了。AI 做的不过是把现有的 LLVM 逻辑转换成 Rust 语法。

这叫什么？这叫**“高级搬运”**。Jeremy 直言，想要做出真正原创性的成果，绝对不能依赖 LLM，因为它只会给你一个基于过去经验的“非线性平均值”。[^2]

### 开发者变笨了？小心你的“斜率”在归零

最让 Jeremy 感到“不人道”的，是 AI 正在侵蚀开发者的成长空间。他提出了一个扎心的观点：**“一点点斜率就能弥补大量截距。”**

*   **截距：** 你现在掌握的知识和技能。
*   **斜率：** 你的个人能力提升速度。

现在的 AI 工具（如 Cursor、Claude Code）都在追求“全自动”，开发者只要输入 Prompt，然后点点鼠标。这看起来效率飞起，但其实是在逃避“必要之难”。[^1]

就像学习中文需要用 Anki 强迫大脑在遗忘边缘徘徊一样，软件工程的精髓在于微步迭代和实时交互。Jeremy 认为，这种“自动驾驶”模式会让处于中间水平的开发者失去建立直觉的机会。[^4]

> “这就像在小学里给孩子发计算器，却告诉他们不需要学算术了。短期内你确实算得快，但你这辈子都别想理解数字背后的逻辑了。”

更可怕的是，这种“认知债”最终会由企业买单。高管们以为省了人头费，实际上却在为公司埋下毁灭的种子：团队成员停止成长，留下一堆连 AI 都修不好的、只有 AI 才看得懂的代码垃圾。[^2]

### 行业“地震”：是工厂化编程，还是电子老虎机？

面对 Jeremy 的炮轰，硅谷另一位大牛 Steve Yegge（Vibe Coding 倡导者）则持有截然不同的“激进”看法。Yegge 认为，如果你到 2026 年还在用传统 IDE 写代码，那你已经不是合格的工程师了。[^3]

在 Yegge 的世界观里，我们正在进入**“工厂化编程”**时代。哪怕 AI 会胡编、会失忆，只要你会“调教”Agent 编队，你的产出就是别人的 10 倍。

但 Jeremy 把这种“Vibe Coding”比作**老虎机**：
> “你输入指令，拉下把手，期待三颗樱桃并排。偶尔赢一把，你觉得 AI 太牛了。但这具备赌博的所有特征：高度随机、虚假的控制感、伪装成胜利的失败。”[^2]

他怀念的是 Smalltalk、Mathematica 那种“人机深度交互”的黄金时代，计算机是人类思维的延伸，而不是一个把人类踢出局的黑盒。

### 未来预测：下一个“风口”是拒绝平庸

Jeremy 并不反对 AI，他自爆有 90% 的代码也是由模型代劳。但他坚信，AI 真正的挑战不是写更多代码，而是如何设计一种新的协作方式，让人类在其中变得更聪明，而不是更平庸。[^5]

对于我们这些普通打工人来说，这场神仙打架透露出一个信号：**如果你只是把 AI 当成逃避思考的工具，那你欠下的认知债，迟早要还。**

毕竟，当所有的代码都变成了“一次性消耗品”，唯一值钱的，可能就是你脑子里那个 AI 永远无法插值出来的、独一无二的原创思维模型了。
