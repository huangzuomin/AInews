马斯克这会儿人在北京，深夜还得在X上给自家亲儿子站台，打工人看了直呼：这老板也够卷的。

但更卷的其实是xAI。在核心团队上演“胜利大逃亡”的动荡期，在并入SpaceX的重组风声里，他们居然紧锣密鼓地甩出了一款重磅新品——**首个Coding Agent，Grok Build**。[^1]

简单来说，这就是一个**专为硬核程序员打造的终端版AI编程助手**。它不跟你玩花里胡哨的网页聊天，而是直接杀进命令行，试图成为你工位上最懂你的AI搭子。

### 这玩意儿到底是个啥？Grok版的“Claude Code”实锤了

外界对这款产品的预期其实早就埋下了伏笔——别忘了，马斯克此前可是花了600亿美元鲸吞了Cursor团队。[^1] 这次Grok Build的发布，基本上就是把“要在Coding领域死磕Anthropic和OpenAI”的野心摆在了明面上。

那它到底凭啥对标Claude Code？我们扒了扒它的技能树，发现确实有点东西：

*   **并行工作的Subagents（子智能体）**：面对复杂的大型项目，Grok Build不会一个人死磕。它会像一个项目经理一样，把任务拆解并分派给多个并行运行的“小弟”。更妙的是，这些“小弟”干活的进度是**完全透明**的，你能在主界面上实时围观它们的一举一动。[^1]

*   **兼容现有工作流，主打一个无痛迁移**：最骚的操作来了——你要是已经习惯了Claude Code的工作流，没关系，Grok Build直接放话：**保证你无！痛！迁！移！** 什么 `AGENTS.md`、`skills`、MCP servers……一键导入，秒变自家配置。[^2] 这波“挖墙脚”的操作，只能说马斯克深谙互联网精神。

*   **计划模式（Plan Mode）**：在动手写代码之前，它会先像个老练的架构师一样，跟你开个“计划评审会”。你可以针对特定的代码块留下行内注释，甚至把整套方案推倒重来。计划获批后，每一次改动都会以清晰的 `diff` 形式呈现，让你对代码的“前世今生”了如指掌。[^1]

*   **极客友好**：xAI的工程师在介绍时直言：“我们习惯用vim，习惯用快捷键，并将alt-screen视为主界面。”[^1] 翻译过来就是：我们很硬核，我们的产品也很硬核。它不仅支持鼠标，还完美兼容vim操作方式，还有“Hunk Tracker”让你能回溯到对话中的任意时间点。

简单总结，Grok Build就是 **“Claude Code”的即视感 + GitHub Copilot的迁移便利性 + 马斯克式的硬核审美**。

### 动荡中的豪赌：一边拆家，一边盖楼

说真的，现在的xAI看起来有点“精分”。

一边是核心联创相继离职，原团队分崩离析，连公司本身都要并入SpaceX，logo都准备换新了。[^1] 这阵仗，怎么看都有点像“大厦将倾”的前兆。

但另一边，Grok的迭代脚步愣是没停。从之前登上OpenRouter排行第一的 `Grok Code Fast 1`，到如今直接对标Claude Code的Grok Build，xAI在代码领域的进攻性极强。[^3][^4] 尤其是“氛围编程”（Vibe Coding）概念的走红，让AI编程助手成了兵家必争之地。[^4]

马斯克这盘棋，看得人眼花缭乱。表面上是在“拆家”，内核里却是在通过收购Cursor团队进行“换血”，把宝全都压在了AI编程这个赛道上。

### 300刀/月的价格，值不值？

最后聊点现实的。想体验Grok Build，门槛不低——它面向**SuperGrok Heavy**订阅用户开放，原价**300刀/月**。现在促销价是前6个月**99刀/月**。[^1]

300刀/月是什么概念？比ChatGPT Pro还贵。这价格足以劝退99%的个人开发者。它的目标用户，显然是那些能把这笔钱转化成效率的企业级团队和极客大佬。

所以，这究竟是马斯克在xAI废墟上重建的一座新堡垒，还是又一次心血来潮的昂贵玩具？新的Grok模型据说正在Colossus 2集群上训练，加上Cursor团队的加持，故事远没到结尾。[^1] 我们这些围观群众，搬好小板凳，看看这位“科技圈顶流”还能整出什么新活儿就行。
