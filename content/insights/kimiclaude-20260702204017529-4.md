每周都有 Anthropic 的新乐子看，已经成了最近一个月科技圈的保留节目。[^1]

故事要从6月初说起。Anthropic 刚秘密递交IPO文件，转头就发万字长文，警告自家最新模型 Claude Fable 5/Mythos 5 能力强到“应该被限制使用”。[^1]

同一时间，大客户 AWS 也送上助攻，给美国政府递了份秘密报告：“是的，Fable 5 发现和利用零日漏洞的速度，远超人类修补速度，会导致严重的网络安全风险。”[^1]

一唱一和间，这两份原本用来自夸的报告，转头成了美国政府强制封禁新模型全球访问的“投名状”。结果这次不仅是其他国家用户不能用，连 Anthropic 内部的外籍员工都被禁了。[^1]

PR 过度的 Anthropic 不得不立刻修改口径，表示 AWS 说的漏洞发现能力，GPT-5.5 也能做到，这才换来有限松绑。[^1]

**但故事到这里还没结束**——6月30日，Anthropic 再发新文，表示 AWS 说的问题，其实 Claude Opus 4.8、GPT-5.5，以及 **Kimi K2.7** 也全都能实现。[^1]

是的，这次 Anthropic 不仅拉上了老对手 OpenAI，连国内的 Kimi 也被它拉上了。[^1]

### 国产模型，这次真的不一样了

过去两年，如果你问一个国内 AI 从业者“中转站”是什么，答案清一色是：帮国内用户连接海外 Claude 和 GPT 的灰色通道。[^1]

那时，围绕中国大模型的标签非常固定：便宜、能用、但上限不高。做个 Chatbot 还行，复杂任务表现就差强人意了。[^1]

但这个叙事，从今年年初开始悄悄翻转了。**一批“中转站”开始反向操作：把 K2.6、DeepSeek V4 在内的国产模型 API 中转出去，销往全球。**[^1]

当然，我们不推荐、不提倡该行为。但这足以说明，全球客户采购中国模型的原因，已经从“便宜”变成了“性价比+技术领先”。[^1]

《经济学人》在盘点2026年AI市场时，专门分析了这一转变：中国模型在海外的认知，正在从“廉价替代品”向“可被严肃采用的技术供给”迁移。[^1]

用户在用脚投票。

Coinbase 首席执行官 Brian Armstrong 在X平台发文盛赞 GLM 5.2 和 Kimi K2.7：91%的员工根本不需要所谓的极限模型能力，不如把默认模型切到这些高性价比选手。最终效果：**AI支出削减近一半，Token使用量以指数级增速增长。**[^1]

这可不是个例。过去一年，公开发生的国际大厂切换国产模型的案例包括：

- Airbnb 将主力客服模型从 GPT 切换至千问
- AI公司 Lindy 将模型从 Anthropic Claude 迁移至 DeepSeek V4
- 查马斯・帕里哈皮蒂亚旗下公司将核心业务从 Anthropic Claude 迁至 Kimi K2
- Cloudflare 将AI安全Agent等生产任务切换为 Kimi K2.5
- Notion 团队接入 Kimi K2.6，并表示这是首款具备顶级智能体能力的开源模型[^1]

### 到底哪里不一样？

不久前，英伟达在 GTC 2026 上展示最新芯片推理性能时，中国模型只有两家入选：DeepSeek 和 Kimi。[^1]

技术层面，Kimi是最早押注MoBA改造Transformer注意力机制的玩家，也是最早把Muon系优化器推到万亿参数级训练的团队之一。[^1]

认知层面，当大多数同行还在Chatbot赛道上卷上下文长度、拼榜单分数时，Kimi已经把Agent定为核心战略方向。[^1]

从K2开始，Kimi就让AI真正为人类完成任务；到K2.5发布时，Agent能力已经进化到集群级别——**能根据任务需求现场调度多达100个分身，并行处理1500个步骤。**[^1]

不一样，源于国产模型在认知上的领先和技术上的突破。

### Anthropic 让中国模型又爱又恨

从业务结构上看，哪个中国模型公司更像Anthropic？行业大佬和投资人的答案惊人一致——Kimi。[^1]

这种相似不只是表面上的技术路线，还包括商业内核的高度趋同。

**首先是增速的相似。** Anthropic 半年内ARR增长超3倍。Kimi的轨迹几乎复刻：2026年1月K2.5发布后，20天收入就超过2025年全年；截止6月底，相较3月初又实现连续3倍加速增长。[^1]

**其次是收入结构的相似。** Kimi的API收入占比已达70%左右，团队规模却只有约300人。没有定制化项目，没有重人力的交付团队，完全是产品主导的高毛利增长模式。[^1]

**翻译一下：** 那套Anthropic用来讲给投资人听“估值合理”的叙事，Kimi同样可以讲，而且讲得更轻。[^1]

**甚至，Anthropic在Coding场景的崛起路线，也被Kimi半被动地复刻了。**[^1]

众所周知，Anthropic营收超越OpenAI的核心在于Coding场景。而巅峰时期，Cursor贡献了Anthropic约40%至50%的收入。[^1]

但Anthropic发布Claude Code后，仅用了半年多就冲到25亿美元年化营收，抢走了大量Cursor用户。再加上收紧第三方访问权限，按理说Cursor应该一蹶不振了。[^1]

**但Cursor不仅没死，还靠着Kimi 2.5训练出来的编程模型Composer 2还击**——多项编程基准测试中甚至超过了Claude Opus。[^1]

再然后，SpaceX以约600亿美元全股票交易收购了Cursor。[^1]

左手是Kimi贡献的基模能力，右边是SpaceX的超算集群提供海量算力——颓势边缘的Cursor，**又靠着国产模型奇迹般地复活了。**[^1]

### 这盘棋，下到哪儿了？

**Kimi不仅是海外各大应用厂商讲述性能和成本的最佳叙事组成，也成了Anthropic在上市前夕讲述其“独一性”故事的绊脚石之一。**[^1]

同样是API收入主导的高毛利模式，同样借助Coding逆袭超车。Anthropic上市前最后一轮投后估值达到了9650亿美元，但Kimi新一轮投前估值也达到了315亿美元。[^1]

如果把眼光放得更长远些，无论是DeepSeek、智谱还是Kimi，**只要这几家头部大模型真的能做出Opus、Mythos级别的模型，那么他们的价值，还有逐渐向Anthropic看齐的空间。**[^1]

就像查马斯在All-In Podcast上说的：“这是开源模型第一次在综合能力层面真正撼动闭源体系。”[^7]

他把这个时刻称为“**Kimi K2.5时刻**”。[^7]

而Kimi K2.5的API定价只有Claude的五分之一，跑分上两者却几乎持平。[^7]

当开源、低成本、出色表现结合在一起，开发者获得的，是极高的性价比和充足的自由。[^7]

以前是中国开发者用“中转站”去接海外模型。现在是海外开发者用“中转站”来接中国模型。[^1]

这场面，你见过吗？
