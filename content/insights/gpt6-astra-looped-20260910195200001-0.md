TL;DR：
> GPT-6 Astra 把 OpenAI 的主战场从聊天搬进专业工作流：ChatGPT Work、Codex、API 三线齐发，定价 $10/$50 每百万 token。真正值得架构师注意的是 Raschka 的独立分析——ARC-AGI-3 从 7.8% 到 99.9% 的跃升让 looped transformer（循环复用同一层计算）成为本季最值得关注的研究方向，但他也明确排除了"循环架构即隐藏思维链"的流行联想。

### 产品信号：OpenAI 的定价开始“按场景分层”

GPT-6 Astra 已在 ChatGPT Work、Codex 与 API 同步提供，定价为每百万输入 token 10 美元、输出 50 美元。输出价是输入价的 5 倍，这个比例延续了"重生成、重推理"场景的定价逻辑，也说明 OpenAI 默认 Astra 的主要负载是长链条的智能体任务而非简单问答。配合企业控制项的发布，OpenAI 显然在把"专业工作场景"当成独立的品类来经营，而不是通用模型的附属功能。

### 架构焦点：looped transformer 到底是什么

Raschka 在评测中给出了本轮最重要的技术注脚：Astra 在 ARC-AGI-3 上拿到 99.9%，而前代 GPT-5.6 Sol 只有 7.8%——数量级的差距很难用"数据更多"解释。他从架构视角拆解了 looped transformer 的研究脉络：让同一组权重循环复用多次计算，用"深度上的循环"换取更强的多步推理能力，参数量不需要指数增长。

更重要的是他的独立判断：循环架构的工作原理与外界盛传的"隐藏思维链"传闻并无关联。这为一场正在发酵的舆论争论划下了技术基线——循环计算提升的是计算图本身的表达能力，不是把思维链藏起来不给你看。

### 展望

Astra 与 DeepSeek V4.1-Flash 同日发布，一个往高端专业场景走、一个往极致性价比走，推理市场的分层已经肉眼可见。对使用者而言，真正的问题是：你的智能体负载属于哪一层。
