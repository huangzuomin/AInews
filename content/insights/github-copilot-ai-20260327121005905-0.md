### TL;DR： 
> 以后在 GitHub 写代码，你可能不只是在搬砖，还在给 AI 当“免费私教”。GitHub 宣布 4 月 24 日起默认拿个人用户的交互数据喂大模型，想保住隐私？官方表示：退出按钮就在那儿，能不能找到全看你本事。[^1]

各位打工人、代码搬运工请注意：你们最爱的“同性交友平台” GitHub 最近整了个大活儿。

当地时间 3 月 26 日，GitHub 发布了一则让开发者圈子瞬间炸锅的公告：从 2026 年 4 月 24 日起，GitHub Copilot 将正式开启“全员喂饭”模式。[^1] 简单来说，除非你是个眼疾手快、能精准找到退出按钮的“隐私达人”，否则你跟 Copilot 的每一句调情（交互数据），都将成为它进化的养料。

### 谁是“幸运儿”，谁是“免死金牌”持有者？

这次政策调整非常有意思，精准地体现了什么叫“柿子捡软的捏”。

受影响的群体主要是：**Copilot Free（白嫖党）、Pro 和 Pro+（个人氪金大佬）**。如果你是这些账户的一员，那么恭喜你，你的代码片段、光标轨迹、甚至你还没写完的注释，都会被默认纳入训练范围。[^3]

而那些真正掌握着公司核心机密的 **Copilot Business 和 Enterprise 用户**，则稳稳地拿到了“免死金牌”。[^1] GitHub 的解释很直白：合同签了，不能乱动甲方爸爸的数据。至于个人开发者？对不起，解释权归平台所有。

> **调侃式点评**：这就是典型的“个人为集体做贡献，企业为利润保平安”。

### 它到底“偷看”了你多少东西？

别以为它只是看看你最终写出来的代码，GitHub 这次列出的收集清单详尽得让人后背发凉：[^4]
- **输入与输出**：你发给 Copilot 的提示词，以及它给你的建议。
- **上下文背景**：你光标周围的代码片段（这就是 AI 的“余光”）。
- **文件结构**：文件名、仓库路径、导航模式（它想知道你这房子的户型图）。
- **甚至还有点赞和吐槽**：你对建议的每一个反馈，都是在帮它纠错。

GitHub 还玩了一个文字游戏，叫**“静态存储”**。[^1] 他们说，存放在私有仓库里的代码如果是“静止”的，我们就不看。但只要你一唤醒 Copilot，嘿嘿，那就不是静止了，数据立刻就开始流转。这就像是说：我不偷看你日记，但只要你打开日记准备写，我就站你肩膀上读。[^2]

### 技术大揭秘：GitHub 为什么要这么做？

面对铺天盖地的吐槽，GitHub 的态度倒也坦诚：**“我变强了，但也需要你薅秃了”**。

官方表示，他们已经在微软员工身上实验了一年，效果拔群，建议采纳率显著提升。[^1] 现在的 AI 模型已经不满足于只读那些完美的开源代码了，它需要看“真实世界”的纠结、改错和胡言乱语。

而且，GitHub 并不是一个人在战斗。在回应“为什么非要默认开启”时，GitHub 顺手把 **Anthropic、JetBrains 和微软**全拉了出来当挡箭牌，潜台词就是：**“哥几个都这么干，我这叫行业标准。”**[^3]

### 开发者：这按钮藏在马里亚纳海沟吗？

政策一出，GitHub 社区的 👎 瞬间堆成山。大家最愤怒的点不在于收费，而在于那种**“默认开启、藏起退出键”**的姿态。

一位愤怒的开发者直言：“我按着邮件里的说明去点设置，发现点了个寂寞，那个列表项只会展开，根本没有开关！”[^2] 更有网友吐槽，真正的退出选项被放在了页面的最底部，且表述方式极其模糊，仿佛在玩一场“大家来找茬”。

> **用户引语**：“这是我做过最快的退出操作。如果有其他平台，我真的想搬家了。” [^3]

对于很多需要满足 SOC 2 合规要求的开发者来说，这简直是灾难。如果团队里某个员工忘了关这个开关，公司的核心逻辑可能就通过 AI “分享”给了全世界。

### 写在最后：代码自由还是 AI 养料？

从 4 月 24 日开始，普通用户将正式迎来这个规则。虽然 GitHub 承诺数据不会卖给第三方，也不会给 OpenAI 这种竞争对手用，但这种“先斩后奏、默认授权”的做法，确实消耗了不少社区的信任。

如果你想保住自己的代码“初吻”，请务必在 4 月 24 日前，深潜到 GitHub 的设置页面，找到那个被藏起来的 **“Privacy”** 选项，手动把它掰到 **“Disabled”**。[^5]

毕竟，你可以给 AI 当老师，但它至少得先问问你愿不愿意。
