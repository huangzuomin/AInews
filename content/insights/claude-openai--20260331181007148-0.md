### TL;DR：
> Claude 不再满足于只当“键盘侠”，现在直接上手抓鼠标，开启了接管电脑的“狂飙”模式。而 OpenAI 也不甘示弱，反手扔出一个“套壳”插件直接空降 Claude 家门口，上演了一出“你的工具很好用，但下一秒就是我的了”的修罗场戏码。

北京时间昨夜，大模型界的“卷王” Anthropic 再次对开发者们精准投喂了重磅更新：Claude Code 正式引入“Computer Use”（计算机操作能力）。

简单来说，Claude 现在不仅能帮你写代码，还能像个真正的“电子苦力”一样，直接打开你的 macOS 终端、跑起你的编译器、甚至盯着你的 UI 截图找茬。这种从“只动口”到“真动手”的转变，让不少熬夜看直播的码农直呼：“这下真的可以去送外卖了。”

### 技术大揭秘：Claude 到底是怎么“动”你电脑的？

以前的 AI 编程工具，撑死是个“高级输入法”。你写个 Bug，它给你修个 Bug，但剩下的编译、运行、测试，还得你自己像个老农民一样手动耕耘。

现在的 Claude Code 配合 Computer Use，直接把这套流程闭环了。它通过一个名为 **MCP（Model Context Protocol，模型上下文协议）** 的“秘密外交官”与你的系统对话。[^1]

*   **视觉驱动的“大家来找茬”**：它能看懂 Electron 应用的界面，不需要你配置复杂的 Playwright 框架，它自己点点点、截截图，就能告诉你注册流程在哪断了。
*   **分层决策的“省钱术”**：Claude 也很精明，它会优先用命令行（CLI）解决问题，只有在命令行搞不定的时候，才会掏出最通用的（也是最慢、最贵的）GUI 操作来垫底。[^2]

> **调侃一下：** 这就像是你请了个保姆，以前她只负责写菜谱，现在她直接拿着你的银行卡去菜市场，顺便把碗也刷了。当然，刷碗的钱（Token）得你出。

### 权限与“钱包”：很酷，但谁在乎？

虽然技术上燃炸了，但社区的反馈却像极了“冰火两重天”。

在 Reddit 上，用户们的情绪非常稳定——稳定地表示不满。首先，这套功能目前是 **macOS 独占**。Windows 和 Linux 的开发者们感觉自己像是被大厂遗忘的“编外人员”。[^3]

其次，也是最核心的问题：**Token 消耗**。
由于 Computer Use 需要频繁截图和长上下文交互，每一次“优雅的操作”背后都是钱包在滴血。有网友神评论道：“这功能很酷，但我希望有一天我攒够了 Token，能让它帮我跑一次，哪怕就一次。”

> **深度洞察：** 目前这种“补贴式”的 AI 代理时代终将结束。当 20 美元的订阅费撑不起 Claude 接管电脑的算力成本时，未来的定价可能会让你觉得，请个真人实习生甚至更划算。[^1]

### OpenAI 的“反向渗透”：我就蹭蹭，不进去？

就在 Anthropic 还在宣传自家的“全栈自动化”时，OpenAI 却玩了一手极其“阴险”的操作。

OpenAI 连夜发布了 **codex-plugin-cc** 插件。这个插件骚就骚在，它不是个独立工具，而是直接安装在 **Claude Code** 里的。[^2]
它的逻辑是：你尽管用 Claude 操作电脑，但到了关键的代码审查、风险评估环节，你可以直接输入 `/codex:review`。这时候，Codex 就会像个“影子政府”一样站出来，对 Claude 的劳动成果指点江山。

最绝的是命令 `/codex:rescue`。当 Claude 的逻辑陷入死循环、任务卡死时，开发者可以直接把控制权移交给 Codex。这波操作直接把 Claude Code 变成了 OpenAI 的“宿主”。[^4]

> **点评：** 这种“在你家客厅里摆我的沙发”的行为，充分展示了 OpenAI 在生态争夺战中的老辣。既然用户爱用 Claude 的界面，那我就把大脑装进你的界面里。

### 未来预测：2026 年的“代理人战争”

根据最新的行业动态显示，2026 年将成为 **Agentic AI（代理智能体）** 的基建元年。[^2] 不管是 Anthropic 的 MCP 协议，还是 OpenAI 的 Agent Loop 架构，都在试图定义一套标准，让 AI 能够更丝滑地接管人类的生产力工具。

目前的这一场恶斗，本质上是关于“谁能成为开发者唯一入口”的战争。Claude 赢在了“手脚快”（Computer Use），而 OpenAI 赢在了“路子野”（套壳插件与多模型协作）。

对于普通开发者来说，这场大厂互搏最直接的好处就是：虽然 Token 越来越贵，但那个“不用敲键盘、只需下圣旨”的时代，真的越来越近了。
