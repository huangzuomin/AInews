TL;DR：
>GPT-5.6 刚发布就把 Fable 5 按在地上摩擦：跑分更高，价格只要三分之一。Anthropic 一边疯狂延后 Fable 5 的免费截止日期，玩“永远够不到的胡萝卜”梗，一边被开发者发现 Claude Code 的吞 token 速度堪比碎钞机。消费者的钱到底烧在了哪里？是在模型智能上，还是 Anthropic 精心设计的“平台税”里？

### 永远够不到的胡萝卜

Anthropic 又给 Fable 5 的免费使用期按了一次“续命键”。

7 月 19 日，这已经是第三次延期了。从 7 月 7 日到 7 月 12 日，再到现在的 7 月 19 日，这剧情像极了那个经典冷笑话：为了不让驴吃到胡萝卜，主人把它绑在棍子上，一直伸到驴的面前，每当驴要咬到，就又往前挪一格。[^1]

有开发者调侃，Anthropic 这是把“限时免费”玩成了“恒久远”的营销策略。但玩笑归玩笑，大家心里都清楚，这不是因为 Anthropic 大方，而是它正在打一场不得不打的算力仗。

一个名为“永远够不到的胡萝卜”的梗开始在技术社群流传：Fable 5 仍然挂在所有付费计划里，但每当终点临近，胡萝卜就又被往前挪了一截。[^1] 对于 Claude 和 Claude Code 的重度用户来说，这种体验已经逐渐变成一种循环：额度耗尽，等待重置；截止日期临近，等待延期；新规则公布后，再重新计算自己还能用多久。[^1]

### 卷王来了：GPT-5.6 把桌子给掀了

就在 Fable 5 反复横跳、吊着用户胃口的时候，OpenAI 上周五直接掀了桌子，把 GPT-5.6 家族（Sol、Terra、Luna）砸向市场。这不仅是发布，这简直是冲着 Anthropic 的命门去的。[^2]

数据不会骗人，甚至还带着点残忍的幽默感：

- 在 **DeepSWE** 编程测试中，GPT-5.6 Sol Max 用 8.39 美元拿下了 73% 的得分率；而 Fable 5 花了 22 美元，才拿到 70%。同样的活，便宜了 62%，还干得更好。[^4]
- 在 **Agents’ Last Exam** 上，Sol 创下了 53.6 分的新高，比采用自适应推理的 Fable 5 高出 13 分。[^1]
- 即使只使用 Medium 推理强度，它也比 Fable 5 高出 11 分，而预计成本只有后者的四分之一。[^1]

更扎心的是 API 价格。在几乎相同的得分下，Fable 5 花了 3,771.84 美元，GPT-5.6 Sol 仅需约 1,400 美元——**接近三倍的价格差**。[^1] 输入 10 美元/输出 50 美元 vs. 输入 5 美元/输出 30 美元，OpenAI 这个定价简直是贴脸输出。[^4]

开发者 Corey 直接在社交媒体上开怼，字字都是反讽的顶级艺术：

> “我真的搞不懂 OpenAI 对 GPT-5.6 的策略。我找不到它涨价 50% 的日期，也找不到它被移出订阅套餐的日期。更奇怪的是，OpenAI 员工的说法居然还和官方文档一致。很明显，这里面一定有什么问题。”[^1]

感受到了吗？这嘲讽直接拉满了。OpenAI 员工接着回复：我们套餐额度全部可用于 GPT-5.6，价格不变。Corey 接着补刀，说 Anthropic 应该招一个 **“VP of rug pulling”（专门负责突然收回权益、割韭菜的副总裁）**。[^1]

### 隐形的账本：你的订阅费到底烧在哪了？

如果说 Fable 5 延期还能用“算力不足”当挡箭牌，那最近开发者扒出的 Claude Code 成本内幕，则让 Anthropic 的辩解直接没法看了。[^1]

有人做了个极致“降维打击”的实验：用同样的机器、同样的模型，让 Claude Code 和开源替代品 OpenCode 完成同一个超简单任务——提示词是 **“Reply with exactly: OK”**（只回复“OK”），只有 22 个字符，没有任何代码需要阅读、没有任何文件需要修改。[^1]

结果触目惊心：

> 在用户提示送达模型前，Claude Code 已经加载了约 **32,800 个 token**，而 OpenCode 只用了 **6,900 个**。前者是后者的将近 **5 倍**。[^1]

这 32,800 个 token 里，大约 **24,000 个** 是 Anthropic 塞进去的工具定义。27 个工具，从 CronCreate、Monitor 到 Task 系列，还有 worktree 管理和推送通知，全给你安排上了。你付不付钱？付。你用不用？那是你的事。

> “这 32,800 个 token 全部是 Anthropic 自己塞进去的‘平台开销’——你为它付了钱，但它没有为你完成任何实际工作。”[^1]

再看**缓存效率**。OpenCode 的请求前缀逐字节相同，一次写入、后续几乎免费读取。Claude Code 则在会话中途反复重写数万 token 的缓存前缀，同一任务上缓存写入量最高达到 OpenCode 的 **54 倍**。缓存写入按溢价计费——额度仪表盘飙升的速度，比实际完成的工作快得多。[^1]

还有一个吃钱大户：**子智能体（Sub-agents）**。Hacker News 上一位用户分享了他的经历：给 Claude Code 一个稍大的任务，它立刻启动了 7 个子智能体，预算还没等任何一个完成工作就烧光了。同样的任务让主智能体顺序执行，完全没问题。[^1]

数据也证明了这一点：一个直接完成时消耗 121,000 token 的任务，分散给两个子智能体后飙升至 513,000 token——**4.2 倍**。每个子智能体启动一次就要消耗一套完整的系统提示和工具定义，父智能体还要再读一遍它的全部输出。[^1]

这意味着什么？用户花同样的钱，用 Claude Code 能完成的实际任务，可能只有开源工具的几分之一。剩下的钱全烧在了 Anthropic 自己设计的脚手架、工具定义和反复重写的缓存上。更“绝”的是，Anthropic 根本不会告诉你这些——用户看到的只是“额度用完了”、“该等重置了”。[^1]

### 阳谋：牌桌上的人，不想打价格战

把所有线索串起来，你会看到一幅更清晰的商业图景。

Anthropic 为什么要反复推迟 Fable 5 的免费截止日期？所谓“算力不足”，可能根本不是全部真相，而是一种精心设计的**战略缓冲**。[^1]

一旦 GPT-5.6 正式站稳脚跟，Anthropic 或许会突然“找到”足够的算力，重新把 Fable 5 放回套餐——或者，干脆再也不放回去了。[^1]

有分析认为，Anthropic 可能正在有意推动一种新的行业模式，让未来最先进的 SOTA 模型不再包含在订阅套餐里，而是只通过 API 的方式提供。

> “这自然也会给 OpenAI 留下同样的操作空间——一旦这种做法成为行业标准，两家公司都能避开价格战，维持更高的利润。”[^1]

双方都在推进可能达到 1 万亿美金估值的 IPO，价格战对谁都没有好处。公开的嘲讽、价格的差距、跑分上的你追我赶，看起来是水火不容，实际上却是心有灵犀——不能让用户觉得顶级模型太便宜。

当然，这终究只是基于公开信息的推演。但无论如何，结果都一样——**消费者永远是被动的，是唯一没有坐上牌桌的那一方。**

当我们看着 Fable 5 这根胡萝卜一次次被往前挪，看着自己的订阅额度在 Claude Code 的脚手架和子智能体中飞速燃烧，我们或许该明白：这场 AI 军备竞赛的最终账单，总是由坐在牌桌下的我们支付的。
