### TL;DR： 
> 微软 Copilot 最近在 GitHub 搞了个“大活儿”：它在帮开发者修改代码 Pull Request (PR) 时，竟私自塞入 Raycast 等产品的推广链接。虽然微软紧急辟谣称这是 Bug 而非蓄意打广告，但这种“智能不够，贴纸来凑”的骚操作，还是让全球开发者直呼：“代码库不是电线杆，Copilot 请停止你的街溜子行为！”

如果你觉得现在的互联网广告已经无孔不入，那微软 Copilot 可能会刷新你的认知。想象一下，你正严肃地在 GitHub 上维护着价值几个亿的开源项目，正当你纠结于一个变量命名时，AI 助手优雅地走过来，帮你改了个错别字，然后反手在你的代码评审页面贴了一张“办证/刻章”——哦不，是“下载 Raycast，快速启动 Copilot”的小广告。[^1]

这事儿不是科幻小说，而是上周真实发生在澳大利亚开发者 Zach Manson 身上的“惊悚片”。

### 案发现场：AI 助手的“私货”诱惑

整件事的起因简单到离谱。Manson 的同事用 Copilot 顺手改了一个 PR 里的拼写错误，结果 Copilot 在提交时，竟然在 PR 描述的最下方精准插入了一行带链接的文案：**“在 macOS 或 Windows 上快速启动 Copilot 编程智能体，就用 Raycast！”** [^2]

> **调侃点评**：这感觉就像你请个保洁来家里打扫卫生，她干活确实利索，但临走前在你家客厅白墙上贴了个“XX 搬家公司”的二维码。

更绝的是，这并非孤立事件。有心人顺着这段广告词在 GitHub 上搜了一圈，好家伙，同样的“牛皮癣”出现在超过 1.1 万个 PR 当中。[^4] 深入查看原始 Markdown 代码会发现，这些广告前面竟然还带着隐藏的 HTML 注释标签：`START COPILOT CODING AGENT TIPS`。

这说明什么？这压根不是 AI 产生了什么“我想卖货”的幻觉，而是产品团队预设好的模板。虽然 GitHub 官方事后谢罪，称这是由于某个 Bug 导致原本只该出现在“Copilot 创建的 PR”里的提示，错误地出现在了“人工创建的 PR”里。[^5] 但广大开发者显然不买账：**在我的代码库里，不管谁创建的，塞广告就是不行。**

### 微软 Copilot 的“整烂活”进化史

其实大家之所以反应这么大，是因为 Copilot 已经不是第一次表现得像个“还没毕业的实习生”了。在过去的一年里，这位市值万亿公司的 AI 助手，可谓是贡献了不少笑料和槽点：

1.  **“跟 Windows 不是很熟”**：在一次官方宣传视频中，博主问 Copilot 如何调大文字，Copilot 建议调整“屏幕缩放比例”。结果用户发现，Windows 其实有专门的文字大小调节选项，而 Copilot 的方案会把整个 UI 弄得一团糟。[^6]
2.  **“幻觉级教学”**：在微软的“Windows 学习中心”里，Copilot 生成的 Win 11 功能配图完全是胡编乱造，图里的小组件长得和真实系统不能说一模一样，只能说毫无关系。[^6]
3.  **“隐私裸奔大赏”**：别忘了曾经闹得沸沸扬扬的 Recall 功能，它在后台疯狂截图并把数据存在**完全没加密的明文数据库**里。要不是开发者及时曝光，你的银行密码可能早就成了 Copilot 的“午餐”。[^6]

### “智能体”还是“广告代理商”？

面对质疑，GitHub 开发者关系副总裁 Martin Woodward 连夜发帖称：“我们没有、也不打算在 GitHub 中加入广告。” [^5] 翻译一下就是：这真的是个意外，请大家相信我们的清白。

但正如科幻作家 Cory Doctorow 所言，平台的衰落往往伴随着“对用户好 -> 坑用户利商业客户 -> 连商业客户一起坑”的循环。[^6] 

当 AI 助手开始未经允许修改用户的 PR 描述，当“产品提示”与“商业推广”的界限变得模糊，这种行为逻辑背后的傲慢才是最令社区感到不安的。今天它能帮你推个好用的启动器，明天它是不是就能在你的代码注释里塞一段它觉得“更好用”的付费库链接？

**写在最后：**
AI 确实正在改变编程，但开发者需要的，是一个能帮我处理逻辑、寻找 Bug 的冷酷工具，而不是一个会在代码评审里跟我套近乎、顺便推销全家桶的“社交达人”。微软，收收味儿吧，大公司的这口“AI 泔水”，我们是真的咽不下了。
