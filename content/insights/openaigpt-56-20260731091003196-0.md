TL;DR：
> 好家伙，OpenAI今天突然对GPT-5.6全线「大放价」，入门款 Luna 直接打骨折，输出价格比上一代最便宜的模型还便宜。背后的原因居然是5.6自己在给自己「优化代码省钱」，这波「左脚踩右脚」的操作，直接把价格战推向了白热化，压力全给到隔壁A社了。

如果你还在犹豫要不要给 API 续费，OpenAI 直接朝你脸上甩了一张「骨折价」海报。

就在今天，GPT-5.6 三款模型集体「大放价」。不是那种虚张声势的营销，而是实打实的 **「打骨折」**。

### Luna打骨折，Terra降两成，Sol加速度

先来看看这波价格调整有多猛：

- **GPT-5.6 Luna（入门款）**：输入从 $1/百万Token 降到 **$0.2**，输出从 $6 降到 **$1.2**。换算成人民币，输出直接从 40 块跌到 8 块，比一顿外卖还便宜。
- **GPT-5.6 Terra（日常款）**：降价 20%，输入 $2，输出 $12。
- **GPT-5.6 Sol（旗舰款）**：价格不变，但新增了 **Fast mode**，速度最高飙到标准模式的 2.5 倍，价格翻倍，智能水平不变。

最值得玩味的是 Luna。降价后，它的输出价格 **比上一代最便宜的 GPT-5.4 nano 还要便宜 0.05 美元**。

但更重要的是 **定位变了**。以前的便宜模型（nano）只能干干分类、信息抽取这些「打杂」的活。而 Luna 虽然便宜，却被 OpenAI 定位为 **「Agent 主力干将」**——能调用工具、处理长上下文、执行多步工作流。

**简单说，OpenAI 正在把曾经昂贵的「智能体大脑」，卖到过去「工具人」的价格。**[^1]

而且，OpenAI 已经动手了。他们在 ChatGPT 和 Codex CLI 里，悄悄把负责后台代码审查的 Auto-review 模型从 GPT-5.4 换成了 GPT-5.6 Luna。OpenAI 预计，就这一个替换，**成本将降至原来的约十分之一**。[^1]

### 左脚踩右脚：GPT-5.6 是如何给自己降本的？

看到这里你可能要问了：OpenAI 疯了？真做慈善？

当然不是。OpenAI 给出的理由，才是今天这出戏最「科幻」的部分。

**降价的原因，是 GPT-5.6 Sol 参与了自家生产系统的优化。**

没错，模型亲自下场帮公司省钱。

GPT-5.6 Sol 干了三件事：
1. **重写 GPU Kernel**：你可以把 GPU Kernel 理解为模型在显卡上跑的「底层代码」。以前是工程师小心翼翼地手写，现在 5.6 自己上阵，重写、优化。效果立竿见影：**端到端服务成本直接下降 20%**。[^1]
2. **改进推测解码**：以前模型是一个字一个字往外「挤」，现在 5.6 学会了「批量预判」——先猜一串可能的 Token，再让主模型一起验证。猜得越准，效率越高。**Token 生成效率提升 15% 以上**。[^1]
3. **参与训练监控**：在训练出现异常时主动介入。

用 OpenAI 自己的话说：「GPT-5.6 Sol 参与自身改进，效率取得了飞跃式提升，故特此回馈新老用户~」

这套说辞听起来是不是有种「老板给你画饼」的既视感？但区别在于，人家真把饼烙出来了，并且还把价格打下来了。**左脚踩右脚原地飞升这套，OpenAI 你是真玩上了。**[^1]

*当然，OpenAI 也特意强调了：整个过程依然由人类主导（Human in the Loop）。目标怎么定、代码能不能上线，还是得人点头。所以，暂时还不用担心 AI 突然觉醒，把老板的服务器账单直接清零跑路。*

### 「降价飞轮」开始转动，压力给到A社

这波操作的意义，远不止「便宜」两个字。

它构成了一个完美的 **「降价飞轮」**：

1. **模型优化系统**：5.6 自己改写 GPU Kernel、改进解码逻辑，直接降低了运行成本。
2. **成本下降 -> 价格下降**：省下来的钱，全部变成 API 价格表上的折扣数字。
3. **价格下降 -> 使用场景扩张**：以前因为成本太高而不能频繁执行的代码审查、后台监控、多步验证，现在变成了常规 Agent 工作流的一部分。
4. **使用量暴增 -> 推动下一轮效率优化**：更多的调用意味着更多的数据和反馈，反过来又能让模型更好地优化自身。

这是一个典型的 AI 原生商业模式闭环：**模型参与提高运行效率，成本下降；价格降低后，模型进入更多高频工作流；调用规模扩大，再推动下一轮效率优化。**[^1]

这一套组合拳打下来，压力就直接给到了「A 社」（Anthropic）。

过去一年，Claude 的 API 定价一直是「高质量」的代名词，大家对于价格差异的容忍度还算高。但现在，OpenAI 直接把高端 Agent 模型的价格打到了地板价，还搞出了个「系统自我优化」的叙事。

用户会想：同样是 Agent 模型，Luna 现在比 Claude 便宜一大截，而且 OpenAI 这迭代速度肉眼可见的快，A 社跟不跟？

如果不跟，市场份额会被蚕食；如果跟，利润空间就得被压缩。

行业的价格战，已经从「拼参数」正式进入 **「拼成本、拼生态、拼飞轮」** 的白热化阶段了。

*这一通操作下来，现在压力直接给到A社：轮到你了。* [^1]
