### TL;DR：
> 别看了，Anthropic 把 OpenClaw 的“白嫖”后路给断了！结果这只“龙虾”不仅没凉，还当场黑化，进化出了模仿人类的“梦境记忆”和影音全能大招。这波啊，是“前任”狠心分手，结果逼得“龙虾”转头就跟 GPT-5.4 领了证。

这年头，AI 圈的“分手戏”比娱乐圈还精彩。就在 4 月 4 日深夜，Anthropic 毫无征兆地向所有用户群发了一封“分手信”：Claude Pro 和 Max 订阅用户的额度，以后别想再在 OpenClaw 这种第三方工具里“白嫖”了。[^1] 

消息一出，社区瞬间炸锅。原本以为 OpenClaw（由于 Logo 是一只红龙虾，被亲切称为“龙虾”）要因为断了“口粮”而歇菜，没想到创始人 Peter Steinberger 也是个狠人。他不仅没哭，还仅用三个短句完成了最强硬的回应：“Anthropic 把我们封了。GPT-5.4 变强了。我们继续前进。”[^2] 随后，OpenClaw 2026.4.5 版本光速上线，这一波“反杀”，直接把 AI Agent 的天花板又往上顶了顶。

### 搞钱还是搞命？Anthropic 的“自杀式”请客结束了

为什么 Anthropic 突然在这个节骨眼上“掀桌子”？说白了，还是因为这届网友太能“薅”了。

根据此前泄露的研究数据，Anthropic 简直是在做慈善：一个 200 美元月费的 Max 订阅用户，如果通过 OpenClaw 这种 24 小时待命的 Agent 疯狂跑任务，实际消耗的算力成本可能高达 5000 美元。[^3] 这种“吸血泵”式的调用，让 Anthropic 的服务器不仅 CPU 干烧了，钱包也快烧穿了。

所以，Anthropic 决定“拆桥”：想用 OpenClaw？可以，别拿订阅额度来凑合，请乖乖充值 API，按量付费。[^4] 

### 技术大揭秘：这只龙虾会“做梦”，还会拍片？

被断了“免费奶”的 OpenClaw 并没有摆烂，反而掏出了两个足以让友商流口水的王炸功能：**原生影音生成**和**「梦境」记忆系统**。

首先是大家最喜欢的“不务正业”。以前的龙虾只是个代码和文档搬运工，现在的龙虾已经是个导演了。新版本内置了 11 家视频提供商的接口，包括谷歌 Lyria、Runway，甚至支持本地 ComfyUI 工作流。[^1] 你只要动动嘴，龙虾就能一边写代码，一边顺手给你剪个宣传片，甚至配好 BGM。

但最硬核的还是那个名为 **「Dreaming」** 的记忆机制。这玩意儿简直是给 AI 装了一个“人脑模拟器”。它把 AI 的记忆整理分为三个阶段：
- **轻度睡眠（Light）：** 整理刚发生的琐事，看看哪些是废话。
- **快速眼动（REM）：** 提取主题，进行反思。
- **深度睡眠（Deep）：** 决定哪些是“真理”，然后把它们永久刻进 `MEMORY.md`。[^1]

有趣的是，这套系统的权重设计非常“鸡贼”：比起某件事出现了多少次（频率），它更看重这件事在不同场景下是否都被用到（相关性）。[^1] 这就意味着，你的 AI 助手终于不再是那个“转头就忘”的渣男，它会在半夜三点静悄悄地“进化”，精准把控你的长期项目需求。

### 行业“地震”：开源 Agent 掉进了大厂的“围城”？

这出“分手复合又反戈”的戏码，背后其实是开源 Agent 普遍面临的“大厂困境”。

OpenClaw 说是开源，但它的“灵魂”一直寄居在 Claude 身上。当 Anthropic 为了省钱（或者为了推自家的 Claude Code）突然改政策时，OpenClaw 的命脉就被人掐住了。[^3] 虽然 OpenClaw 迅速接入了 GPT-5.4、Qwen 和 MiniMax 等一众备胎，甚至 Steinberger 本人也已经入职 OpenAI，但这并不能解决根本问题：如果哪天 OpenAI 也不让白嫖了呢？

现在的情况是：Anthropic 虽然松了口，允许 CLI 层面的技术集成，但“打钱”是硬指标。[^1] 而 OpenClaw 则通过接入尽可能多的模型来对冲风险。

这只龙虾跑得确实快，甚至学会了在梦境中反思，但只要它脚下的“地基”（底层模型）还是别人的，这场关于“自由”与“成本”的博弈就永远不会停歇。
