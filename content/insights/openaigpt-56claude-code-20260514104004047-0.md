TL;DR：
> OpenAI的迭代速度简直像开了8倍速，GPT-5.5的余温还没散，GPT-5.6就带着内部代号“偷跑”了。更刺激的是，为了跟Anthropic的Claude Code抢程序员，奥特曼直接祭出了“免费送两个月”的撒钱大法。这场AI编程大战，卷得连硅谷都看呆了。

### 爆点一：GPT-5.6，你这也太快了吧？

各位，注意了，GPT-5.5才发布三周，屁股还没坐热呢，GPT-5.6的“内测邀请函”就已经飞出来了。[^1]

知名爆料人Leo扔出了一个大瓜：GPT-5.6的开发已经进入全速冲刺阶段，首批检查点（checkpoint）甚至已经在内部跑起来了。[^1] 按照这个节奏，下个月正式亮相几乎是板上钉钉的事。

这是什么神仙速度？网友们纷纷表示：**“这迭代速度，我的脑子还没跟上，钱包就已经被掏空了。”**

更“炸裂”的是，就连内部代号都被扒了个底朝天——什么“ember-alpha”、“beacon-alpha”，听起来就像是某个科幻大片里的秘密武器。[^1] 还有大神在OpenAI的Codex日志里，发现了指向GPT-5.6的路由记录。这说明什么？说明OpenAI的亲儿子Codex，已经开始拿GPT-5.6做测试了。[^1]

**OpenAI这波操作，简直就是在说：“别看我，我在造更强的自己。”**

### 大战前夕：你提速，我补贴，谁怕谁？

就在GPT-5.6曝光的同时，OpenAI的产品端也没闲着，提前放了个大招——“ultrafast模式”。[^1]

这玩意儿有多快？官方说法是，专门为“延迟敏感型任务”提供最快响应，速度直接拉满2到3倍。[^1] 注意，这不是什么阉割版小模型，而是旗舰模型的正经加速。[^1] 对于开发者来说，这意味着以后写代码、跑Agent循环、搞浏览器自动化，体验简直是“起飞级”的。

然而，这场大戏的真正高潮，是OpenAI和Anthropic的正面互怼。

就在OpenAI放出“ultrafast模式”之前，Anthropic也不是吃素的，直接亮出了Opus 4.7 Fast模式，号称比Codex更快、上下文更长。[^1] 这火药味，隔着屏幕都能闻到。

紧接着，Anthropic率先出招：从6月15日起，给付费用户每月提升50%的编程额度。[^1]

OpenAI的反应堪称“教科书级别的反击”——**直接砸钱！**[^1]

奥特曼亲自下场，发布了一条“重磅级补贴”：在接下来30天内，任何从其他平台（说白了就是Claude Code）切换到Codex的企业，直接送2个月免费使用权！[^1]

按Pro计划200美元/月来算，这等于白送了400美元。这哪是竞争，这分明是“怼脸开打”。

> **调侃式点评：** 这波操作，我只能说：**“钞能力”果然是最朴实无华的公关手段。**

### 开发者成了最大赢家？背后的飞轮正在自转

神仙打架，凡人遭殃？不，这次是**开发者成了最大赢家**。[^1]

OpenAI这边刚喊出“免费两个月”，那边Anthropic就提额50%。两边为了抢程序员，已经开始“卷”价格战了。有网友统计，OpenAI的Codex周活跃用户已经突破300万，而Claude Code的用户数也在爆发式增长。[^1][^2]

但如果仅仅把这场大战看作是“抢用户”，那就太肤浅了。

把GPT-5.6的加速迭代和这场编程大战放在一起看，你会发现一个更可怕的趋势——**AI的自我加速和商业化，正在形成一个正反馈飞轮**。[^1]

- **模型在加速进化：** GPT-5.3-Codex是OpenAI首个“参与自身训练”的模型。到了GPT-5.5，OpenAI内部85%的员工都在用Codex写代码。GPT-5.6的开发，大概率也有GPT-5.5的深度参与。[^1]
- **编程工具在释放产能：** 当数百万开发者把AI编程工具当作日常效率神器，AI生成的代码又反哺回AI的训练和部署。[^1]

用大白话说就是：**AI在帮OpenAI造更强的AI，然后更强的AI再去造更牛的编程工具，编程工具又帮开发者造更多的代码……** 这个循环一旦启动，速度只会越来越快。

Sam Altman此前曾放话，OpenAI的目标不再是AGI（通用人工智能），而是直指ASI（超级人工智能）。[^1] 如今看来，当模型迭代速度由AI自身驱动，当AI编程工具成为AI开发的基础设施，当两家万亿级公司用“补贴战”加速这一切的普及——

#### 通往ASI的飞轮，已经开始了自转。

对于咱们普通吃瓜群众来说，除了看戏，或许也该留个心眼了：**当AI开始自己造自己，我们程序员（或者说所有脑力劳动者）的“饭碗”，还能撑多久？**
