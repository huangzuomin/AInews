Cursor搞了个“Sand”智能体，还没发布就被SpaceX 600亿买走？ChatGPT Work和Claude Cowork坐不住了！

温故智新AIGC实验室

TL;DR：

Cursor，那个帮程序员写代码的AI工具，居然偷偷搞了个叫Sand的办公智能体，想跟ChatGPT Work和Claude Cowork抢饭碗。结果产品还没捂热，母公司就要被SpaceX以600亿美元全股票收购。这剧情反转，比马斯克的火箭还刺激。

1. 从写代码到当秘书：Cursor的“野心”藏不住了

Cursor火了，靠的是帮程序员写代码。但这家公司显然不满足于只当个“码农加速器”。最近外媒爆料，Cursor正在开发一个叫 Sand 的通用AI智能体，目标是帮你搞定那些烦人的日常工作——回邮件、管短信、整理表格，甚至处理工程任务。简单说，就是想当你的 AI管家。1

而且人家已经内部测试了，员工们成了第一批“小白鼠”。Cursor CEO Michael Truell 直接放话：下一步要锁定非开发者客户。说白了，就是看上了你们这些不敲代码但同样需要AI打工人。

这操作，像不像一个写代码的突然跑去开餐厅？但别急着吐槽，人家可不是心血来潮。Cursor这几年在AI基础设施上砸了不少钱，积累的技术能力现在要挪到更大的战场了。用他们自己的话说：“我们已经搞定了复杂的AI底层，现在该拿这些能力去赚更多人的钱了。”

2. 三大AI助手混战：谁才是打工人真正的“摸鱼神器”？

Sand的对手可不简单。目前这个赛道上已经挤了三位大佬：

  • Claude Cowork：Anthropic家的大手，今年1月就上线了，号称“动手型”助手，能在你电脑上帮忙干活，一度引发“SaaS末日”恐慌，连印度IT公司的股价都被吓跌了。
  • ChatGPT Work：OpenAI刚推出的职场智能体，由GPT-5.6驱动，能跨应用执行复杂任务，支持插件连接Slack、Google Drive等，甚至你可以手机分配任务，它默默干完。定价还搞按量计费，明摆着要抢企业客户。2
  • Sand：后来者，主打代码执行的可靠性，更擅长结构化任务（比如表格逻辑、CRM流程），但在对话场景和用户规模上明显落后。1

有网友直接吐槽： “通用智能体这条赛道早就挤满了，Cursor的差异化可能只剩下代码执行的可靠性，但用户规模（约100万付费开发者）和品牌信任度，跟ChatGPT（7亿用户）和Claude比，差得不是一星半点。” 1

不过，Sand还没正式发布，鹿死谁手还不好说。但可以肯定的是，这场AI助手大战，打工人是最大赢家——竞争越激烈，工具越便宜越好用。这不，网友已经开始期待：“SpaceX和Cursor的首个联合发布，应该会非常炸裂。”

3. 600亿收购背后的真相：马斯克到底在下一盘什么棋？

就在Sand内测的同时，一个更大的瓜来了： SpaceX 要花600亿美元全股票收购 Cursor！ 3

你没看错，是造火箭的SpaceX，不是OpenAI也不是微软。马斯克想干嘛？表面上看，是为了打造“全球最有用的AI模型”，但背后的算盘可精着呢。

用AI工程师 Martin Szerment 的话说：“在收购背景下，事情的意义已经发生变化：这不再是一家初创公司按自身路线自然扩张，而是一个从一开始就为融入SpaceX算力体系和企业版图而打造的产品。”1

外媒分析指出，这笔收购更像是 “救火” 。马斯克的xAI（Grok）在编程赛道上被Claude和ChatGPT按在地上摩擦，连他自己都承认编程工具落后。而xAI的联合创始人两个月内全跑光了，就剩马斯克一个光杆司令。Colossus数据中心利用率只有11%，只能靠出租算力给Anthropic和Google赚钱。4

所以，买下Cursor，等于买下一支现成的AI编程团队和100万开发者用户。更重要的是，Cursor跟SpaceXAI早有合作——从今年4月起就开始租用SpaceX的算力训练模型。1 这笔收购一旦完成，SpaceX就从一个火箭公司，摇身变成AI办公智能体的玩家，直接跟Anthropic和OpenAI正面刚。

有分析师评论： “未来2到3年，纵向整合的重要性将超过单一AI智能体的功能差异。谁掌握了算力、编程工具和办公代理层，谁就能在价格上压死纯模型公司。” 1

4. 开发者们慌了：AI编程独立公司还有活路吗？

但最扎心的，是Cursor被收购背后的悲情故事。

Cursor的商业模式其实很脆弱——它全靠调用Anthropic的Claude API吃饭，巅峰期占了Anthropic营收的40%-50%。结果Anthropic自己推出Claude Code，还从服务器端封杀了第三方访问。Cursor一夜之间断供，被迫自研模型，结果被扒出套壳月之暗面的Kimi K2.5和Claude Code SDK，两次被打脸。4

“应用层没有护城河” ，这句话在Cursor身上体现得淋漓尽致。20亿美元ARR、数百万开发者、七成财富500强客户，供应商翻脸的瞬间，什么都没挡住。

有媒体感叹： “在AI Coding这个赛道上，‘独立公司’这个词已经不存在了。” 4 要么被收购，要么被平台吃掉。Cursor找对了东家，下一个可能已经在排队了。

不过对于普通用户来说，这未必是坏事。Sand未来能不能活、会不会被SpaceX砍掉还是未知数，但竞争越激烈，我们越能用上更聪明、更便宜的AI助手。这瓜，还挺甜。
