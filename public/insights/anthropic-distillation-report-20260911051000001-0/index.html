Anthropic 披露“蒸馏攻击”：近 2 亿次交互、五个活动，点名阿里、月之暗面与 DeepSeek

TL;DR：

Anthropic 发布报告指控多家中国 AI 公司对 Claude 发起持续的"蒸馏攻击"：累计识别近 2 亿次相关交互，横跨五个活动，被点名的包括阿里、月之暗面与 DeepSeek。这是蒸馏攻击首次被当事方系统性量化披露——无论各方如何回应，"前沿能力会通过使用端外流"从此有了公开的实证基线。

事件本身：蒸馏攻击第一次被摊在阳光下

根据 TechCrunch 报道，Anthropic 的报告称其识别出针对 Claude 的持续蒸馏攻击，累计涉及近 2 亿次相关交互、划分为五个活动，并点名阿里、月之暗面与 DeepSeek 等中国 AI 公司。蒸馏（distillation）指用强模型的输出训练自家模型——当 API 的使用条款禁止这类用途时，它就从"常见工程实践"变成了"攻击行为"。这份报告的价值在于把长期停留于传闻的现象，第一次给出了规模化的量化画像。

需要冷静看待的三个层面

技术上，蒸馏攻击与防御是同一枚硬币：模型厂商希望输出有用，而"有用到可以被模仿"正是蒸馏的原料。检测手段（交互模式识别、批量账号画像）与规避手段（分散请求、改写输出）之间存在持续的攻防升级，2 亿次的数字本身就说明检测方动用了大规模聚类能力。

商业上，这份报告的发布时机与内容选择本身就是竞争行为的一部分——它既是安全披露，也是对 API 客户的信任声明，同时为其对华竞争叙事提供了弹药。读者应注意"指控方报告"这一信源属性：被点名公司的回应与第三方独立核实，是判断真相必要的前置步骤，本报告并未包含这些。

治理上，它提出了一个行业级问题：当模型能力本身就是资产，使用端条款的执行边界在哪里？API 审查、输出水印、用量画像会否成为下一代模型服务的标配——以及这些手段对正常用户的误伤如何校准。

展望

预期三个后续：被点名方的正式回应、其他头部厂商是否发布各自的蒸馏检测报告（如果蒸馏普遍存在，沉默反而是异常值），以及 API 服务条款纠纷的首次公开执法案例。这条线值得长期跟踪。
