搞研究不如搞钱？OpenAI元老集体“跳船”，奥特曼在线表白老黄求带

温故智新AIGC实验室

TL;DR：

OpenAI 内部“红色警报”拉响，o1 推理之父等一众元老级高管扎堆离职，原因直指公司“重商轻研”。资源全给了 ChatGPT 亲儿子，Sora 等项目成了“边缘人”，面对谷歌的步步紧逼和老黄的暧昧态度，OpenAI 这波真的有点悬。

绷不住了，OpenAI 这回是真的闹“大地震”了。

最近硅谷的瓜田里，OpenAI 绝对是产量最高的。不是因为发了什么逆天模型，而是因为家里的人快跑光了。看看这份新鲜出炉的离职名单，个顶个都是那种“少了他模型可能就得降智”的灵魂人物：

  • Jerry Tworek：原研究副总裁，o1/o3 的亲生父亲，GPT-4 的核心贡献者，在 OpenAI 待了将近 7 年的“活化石”。
  • Andrea Vallone：模型策略团队一把手。
  • Tom Cunningham：商业规划与经济预测负责人。
  • Matt Knight：首席信息安全官（CISO）。

这种密度的离职潮，简直是把“公司药丸”四个字写在了公屏上。面对外界“OpenAI 已经变成赚钱机器、抛弃理想”的质疑，现任高管 Mark Chen 紧急出来灭火，表示基础研究依然是核心。但事实真的如此吗？1

实验室变成了“代工厂”？

这场危机的导火索，其实是一个很现实的问题：你是想搞“星辰大海”，还是想搞“碎银几两”？

从 Jerry Tworek 的离职访谈来看，大神的离开并不体面。据传他曾为自己的研究项目申请更多的算力和人力，结果被领导层一盆冷水扣下来：不给。理由也很简单，OpenAI 现在的资源要优先供应给大语言模型（LLM）的迭代。2

这种“All in LLM”的战略让内部产生了一道巨大的裂痕。现在的 OpenAI，ChatGPT 的优先级被调到了“至高无上”的地位，所有资源被打乱重组，统统喂给这个最赚钱的亲儿子。

“我想去探索一些在 OpenAI 很难开展的研究方向。” —— Jerry Tworek

这话翻译一下就是：这里已经没法搞原创性突破了，大家都在缝补旧衣服。3

更有意思的是，原本被视为黑科技的 Sora（视频生成）和 DALL-E（图像生成）团队，因为跟 ChatGPT 的直接相关性较低，在公司里甚至开始被边缘化。想申请点算力积分？对不起，请排在 ChatGPT 后面。

算力短缺：谁才是真正的“金主爸爸”？

为什么 OpenAI 变得这么“抠门”？说白了还是因为算力荒。

虽然背靠微软，但 OpenAI 毕竟还是家初创公司，家底没法跟谷歌、Meta 这种自带印钞机的巨头比。根据 OpenAI 最近透露的逻辑，由于算力和收入之间存在 Scaling Law（规模法则），即“烧得越多，赚得越多”，公司不得不把有限的 GPU 资源集中在最能变现的项目上。4

结果就是，研究员们发现自己变成了“打工人”，每天都在为了提高模型 1% 的效率而卷生卷死，而不是去思考如何实现真正的 AGI。

这种焦虑也传导到了外部合作上。萨姆·奥尔特曼（Sam Altman）最近在 X 上疯狂表白英伟达，甚至想拉着老黄达成千万美元级的深度合作。但老黄似乎在玩欲擒故纵，有消息称他私下吐槽 OpenAI 现在的商业节奏有点乱。1 如果连英伟达的 GPU 供应都不能稳住，OpenAI 的“红色警报”恐怕还得再响一阵子。

谁在笑，谁在哭？

就在 OpenAI 内部为了“搞钱还是搞研究”吵得不可开交时，老对手谷歌正带着 Gemini 3 Pro 虎视眈眈。

Jerry Tworek 在离职后直言不讳地指出，谷歌之所以能追上来，很大程度上是因为 OpenAI 自己的“掉球（Fumble）”。[4] 在他看来，OpenAI 因为背负了太重的商业化压力，反而导致动作变得迟缓且路线同质化。而像 Anthropic 这种规模更小、执行力更强的对手，正在代码 Agent 等方向上弯道超车。

现在的 OpenAI 就像是一个正在转型的“巨型工厂”，它成功地把智能变成了可分发的商品，但代价是失去了一部分最初那股“改变世界”的极客味儿。

Mark Chen 虽然嘴硬说“会有上百个探索项目顺利开展”，但明眼人都看得出来，OpenAI 的重心已经从“实验室”变成了“公益公司（PBC）”式的商业实体。1 3

这场关于“灵魂”与“钱包”的博弈，最终谁会胜出？咱们只能一边吃瓜，一边等奥尔特曼的下一条推特了。
