OpenAI这是要“掀桌子”？ChatGPT秒变“App Store”，你的手机App要“失宠”了！

温故智新AIGC实验室

TL;DR：

OpenAI Dev Day 2025直接“王炸”，Sam Altman大手一挥，ChatGPT从聊天机器人原地升级成“AI操作系统”！以后App可能不是下载，而是直接在ChatGPT里**“摇一摇”就出来。你手机里那些吃灰的App们，这下真的要瑟瑟发抖**了。

起猛了！OpenAI又来**“搞事情”了！在最近的OpenAI Dev Day 2025上，CEO Sam Altman简直是“语不惊人死不休”，直接放话：ChatGPT不只是聊天工具，它要成为一个能运行App、管理任务、连接外部服务的全能AI操作系统**！这波操作，简直就是给整个互联网生态下了一剂猛药，瞬间把大家的“网感”拉满！

两年前的首届开发者日，OpenAI还像个初出茅庐的“后浪”，两年后，它直接变成了**“卷王之王”**：开发者人数从200万翻番到400万，ChatGPT周活跃用户从1亿飙升到8亿，API每分钟处理的Token数量更是暴涨20倍，达到惊人的60亿！1 这增长速度，简直是坐上了火箭，把一众“友商”甩在了身后。当大家以为OpenAI会“闷声发大财”时，10月7日的Dev Day再次让全球科技圈为之震动。Altman一口气甩出四张“王炸”：GPT-5 Pro、ChatGPT App Store、AgentKit、Sora 2，每一张都足以引发一场行业“地震”。

ChatGPT变身“AI操作系统”：你手机里的App不香了？

首先，最“炸”的莫过于那个让人直呼**“未来已来”的Apps SDK。这玩意儿可不是什么“半吊子”插件，它让开发者能在ChatGPT里直接构建应用！想象一下，你的ChatGPT不再只是跟你“唠嗑”，它直接变成了一个“App Store”，而且还是“对话即应用”**的版本！23

这可不是简单的跳转链接，它是真真切切能在ChatGPT界面里运行的App，有界面、有交互、能登录、能支付，全套流程都在这里完成。大会现场，Canva、Booking、Coursera、Zillow这些响当当的大牌应用都第一时间亮相，简直是给足了OpenAI面子。

想做宣传海报？在ChatGPT里吼一声“帮我做一张海报”，它会立马@Canva，秒跳出完整的设计界面，让你直接在ChatGPT里“开干”。想在纽约找个带庭院的房子？一句话搞定，ChatGPT直接调出Zillow模块，地图、价格、户型信息一目了然。整个体验顺滑得像德芙，根本不需要在不同App之间**“猴子捞月”般切换，就像这些应用本身就是ChatGPT的“亲兄弟”！3 这种“统一入口”的模式，难道不是在宣告：“各位App，你的独立时代，可能要走到头了！”**

AgentKit：人人都能“搓”AI智能体，程序员要失业？

紧接着，OpenAI又秀了个更**“骚气”的东西——AgentKit。这简直是为那些想“搓”自己专属AI智能体的朋友们量身定制的低代码/无代码工具。拖一拖、连一连、设参数，一个能“做任务”的AI Agent就这么诞生了！大会上，OpenAI的体验团队仅用8分钟，就搭好了一个智能体，专门为DevDay官网提供问答服务，这速度，简直是“科技与狠活”**的完美结合！4

AgentKit可不是玩票的，它有三大核心模块，简直是智能体的“大脑、骨架和皮肤”：2

  • Agent Builder：智能体的“可视化大脑”，拖拽节点就能连接任务流程，所见即所得。
  • Connector Registry：智能体的“工具箱”，让AI能接入数据库、调API、访问外部资源，十八般武艺都能学。
  • ChatKit：智能体的“交际花”，把它嵌入界面或App，就能拥有丝滑的聊天交互体验。

除此之外，还有一个Evals（评估系统）模块，专门用来给智能体“打分”，看看它表现得好不好。这个“可视化+模块化+安全护栏”的组合，就是要让**“做一个智能体”从程序员的特权变成人人都能做的“家常便饭”**。

说到这儿，Codex也要出来“刷存在感”了。这次大会，Codex正式进入GA（通用可用）阶段。内部爆料更是劲爆：OpenAI团队每周约70%的代码提交，都靠这位“神助攻”搞定！4 现场演示中，工程师只说了一句“给我弄一个控制舞台灯光和摄像头的界面”，Codex立马把前端UI搭起来、后台服务写好，甚至还去GitHub找协议文档，连手柄控制、语音指令都整合进去了。整个过程，工程师一行代码都没写，简直是**“躺平式编程”的福音！3 Codex的目标很明确：自然语言 + 智能识别 = “语义编程”。你说啥，它懂、它做。程序员的“手写代码”劳动，未来很可能被“指令—转换—验证”这种流程“降维打击”**。

底层“硬核”：GPT-5 Pro、Sora 2，AI军备竞赛没停！

当然，光有应用和工具还不够，最底层的“硬核”基座，依然是模型们。这次亮相的，有GPT-5 Pro API、gpt-realtime-mini语音模型，以及Sora 2视频模型。

  • GPT-5 Pro：带着40万token的上下文窗口和**“超神”推理能力**登场，这上下文窗口，相当于能“一口气”读完一本厚厚的《辞海》还不带喘气！2
  • gpt-realtime-mini：它大幅削减了语音模型的成本，让语音交互变得**“平民化”**，以后和AI语音聊天，可能比和真人打电话还便宜。
  • Sora 2：则让视频生成不仅能**“以假乱真”，还能实现可控、音画同步，彻底把视频从“重资产”变成了“指令可控产出”，以后拍电影，可能只需要“动动嘴”**了。4

这些技术力量串联起来，简直就是OpenAI要打造一个**“入口—平台—应用—智能体”的超级闭环生态**。ChatGPT从“我回答你问题”转型到“你说什么，我让后台服务帮你做”，这不只是一次升级，更像是一次对现有互联网格局的**“宣战”**！

“野心”背后的“坑”：OpenAI能稳住吗？

看到这里，你可能要问了：OpenAI这**“野心”大到没边儿，真的能撑得住吗？“老狐”（原作者署名）也跟大家“扒一扒”**这背后的几点“有趣观察”。

首先，这个**“统一入口”模式，必须得赢得应用开发者们的“芳心”。Canva、Coursera、Booking这些头部应用，真的愿意把自己“搬家”到ChatGPT生态里吗？它们自己辛辛苦苦打造的App Store、流量入口、用户数据，那可都是“核心资产”，是轻易不能拱手让人的“金饭碗”。让自己变成ChatGPT中的一个子模块，就意味着放弃部分独立控制权。中长期来看，这种“入口重构”中的利益博弈，才是真正的“风口浪尖”**。

其次，AgentKit这种中间态工具，说实话，极容易被边缘化。如果你既不像微软、谷歌那样有强大的业务场景**“撑腰”，也不想做纯底层模型，而只是在这个中间层做信息整合或垂直解决方案，能不能站住脚？市场里可是“群雄逐鹿”，有太多成熟工具和专精厂商。AgentKit必须明确自己的定位，否则很可能面临“前有狼后有虎”**的尴尬局面。

再者，OpenAI自己下场做工具、做生态，有没有可能和它原本的模型客户发生冲突？这不就是**“裁判也当运动员”的“窘境”嘛！客户即是潜在竞争者，这种定位的信任壁垒，需要极高的透明度和制度保证**，否则，**“塑料友谊”**说翻就翻。

除此之外，监管和隐私也是不能回避的**“大坑”。Apps SDK在欧盟目前就没被包含进预览名单里。不同国家/地区的监管制度、数据流通限制、隐私保护政策，简直是“五花八门”，在生态扩张阶段，这些都可能成为OpenAI的“紧箍咒”。更何况，应用深度集成意味着更多的敏感权限调用和数据交互，一旦安全边界、数据隔离没做好，分分钟“出乱子”**。

最后，模型竞赛还没打完，“神仙打架”依然激烈。谷歌、Meta、Anthropic这些巨头都在模型和生成体系上“下重注”；开源模型阵营和低成本模型也在局部场景里**“高速迭代”。OpenAI虽然现在“风头正劲”，但未来谁能保持技术+生态的双重领先，依然是个“未知数”**。

普通人：未来我们怎么“玩”AI？

即便挑战重重，从这次大会透出的信号来看，AI竞争的下半场，确实在从“谁模型更强”变成**“谁能搭一个用起来舒服、低门槛、安全可控的生态”。技术红利在退潮的时候，体验红利、生态红利才是决定胜负的“王道”**。

对于我们普通人来说，这意味着什么？简单说，以后你写文章，不用装很多工具插件；你做设计，不必在Canva+PPT间来回切换；你找房子，不用开好几个房产App+地图App；你开公司，也能自己搭智能客服、数据分析机器人。你只需要构思一个创意、拟定一个流程，就能在几分钟里把它变成“活着”的智能体。未来，创意可能比技术更重要！

今天的ChatGPT，可能还只是这个未来“入口OS”的**“萌芽期”。真正的ChatGPT终极形态或许是，当它不再只是“你问它答”，而是“你说出要求，它自己组织资源帮你办事”。那个时候，你打开ChatGPT，就像打开了你的“数字中枢”**：你不去想“去哪个App”，你只说“我想做什么”，剩下的就交给它！

未来AI入口的争夺才刚刚开始，而OpenAI已经**“先手下了重注”。下一步会怎样？可能是Apps SDK在更多地区上线，也可能是第三方开发者爆发，更可能是智能体生态全面起飞。在这个过程中，胜者环伺、格局重组都是大概率事件。但有一点很明确：通往AI入口的道路，比我们想象的更野、更快**！

所以，当你下次打开ChatGPT，别惊讶它主动推荐你从未见过的App模块，也别惊讶界面里多了个“小助理”，它甚至可能记得你最近的行程、任务和偏好。这就像从App Store时代迈向AI Store时代：不再是孤立工具，而是协同行动；不再只是你操控它，而是它主动为你服务。我们正在迎来一个前所未有的**“入口时代”，这波YYDS**！
