腾讯Marvis深度评测：从“高级实习生”到“能干活的正式工”，AI Agent的进化实录

温故智新AIGC实验室

TL;DR：

Marvis是一款深度集成操作系统权限的AI Agent助手，通过多Agent协同实现了本地文件处理、自动化办公和跨端协同。尽管在复杂异常处理和静默任务管理上仍有局限，但在本地原地操作和多任务处理上的进化，使其成为当前极具实用价值的效率工具。

功能解析：核心能力深度剖析

Marvis 的核心架构由一个主管 Agent 统筹，并调度文件、系统、应用、浏览器及搜索等五个专项 Agent 进行并行协作。相比于简单的对话机器人，其核心竞争力在于对 Windows 系统底层的介入能力。

  • 原地操作能力：这是 Marvis 最核心的差异化优势。它能够直接对本地文件进行移动、删除、分类、重命名及压缩操作，无需用户下载或通过中转目录提取，极大简化了“AI+办公”的交互链路。
  • 多任务并行与整合：通过实际测试，Marvis 能够同时读取 PDF、Word、Excel 及图片文件，并在短时间内整合输出 Markdown 简报。在上下文记忆测试中，即使中间穿插多轮无关对话，其对文档内容的溯源和纠错能力表现出极高的稳定性。
  • 跨端协同：通过手机端连接电脑，用户可以将手机作为遥控器。实测中，远程触发电脑端创建文件夹、搜索文件等指令响应迅速，有效解决了移动办公场景下的痛点。

性能测试：多维度实测数据

测试环境：Windows 11系统，批量处理473个混合格式文件。

  • 执行准确度：在处理包含特殊字符、只读属性的文件时，Marvis 能够通过任务规划进行规避或提示，但在“去重”逻辑上，系统默认按“文件大小”判断，容易将不同版本文件误认为重复，建议用户在指令中明确排除条件。
  • 稳定性与边界：系统在电脑进入休眠或锁屏后，会自动挂起定时任务且不会报错提醒。这是目前该工具最大的技术局限，用户需确保执行任务时主机处于活跃状态。
  • 低资源模式：在低功耗模式下，该工具的执行效率会有约25%的降幅，但功能完整性未受影响，适合在老旧电脑或性能敏感场景下使用。

竞品对比：市场定位与差异化

与 豆包 和 Kimi Work 相比，Marvis 的定位更接近“住家保姆”而非“外包服务”：

  • 豆包：倾向于沙盒化处理，文件整理后需通过链接下载，安全性高但便捷性稍逊。
  • Kimi Work：倾向于技术顾问模式，执行复杂任务后提供脚本供用户运行，更适合技术型用户。
  • Marvis：直接操作原路径，效率最高，但由于直接触及系统权限，对用户的安全备份意识提出了更高要求。

使用指南：最佳实践与注意事项

为了榨取 Marvis 的最大价值，建议采取以下策略：

  1. 指令工程化：在批量操作前，务必加入“接下来是批量操作，同类指令无需逐次确认”的前置指令。
  2. 明确边界条件：对于去重任务，明确告知“同大小但内容不同的文件视为版本迭代”。
  3. 任务安全备份：鉴于该工具拥有系统删除权限，在进行大规模批量整理前，请确保已备份原始数据。
  4. 绕行场景：不要将“自动备份”或“凌晨爬虫”类任务设为定时执行，除非你能确保电脑始终处于高亮唤醒状态。
