AI时代「职场MBTI」来了：研发产品设计统统消失，只剩这5种人？Claude Code之父的“拆迁”预告

温故智新AIGC实验室

TL;DR：

Claude Code之父Boris Cherny直接把研发、产品、设计、数据科学家扔进垃圾桶，提出AI时代只会有5种职业：原型师、建造师、清道夫、增长手、维护者。这不是贩卖焦虑，而是“诺亚方舟”上的自救指南——学会游泳的人才能到达新大陆。

如果有一天，你的岗位名称突然消失了，你拿什么证明自己值钱？

Claude Code之父Boris Cherny最近扔了一颗“原子弹”——他在硅谷刷屏的新帖子里，直接把传统白领工种判了死刑。研发、产品、设计、数据科学家……统统被划进了“历史文物”的行列。取而代之的，是一套全新的“职场MBTI”：5种AI时代才能活下去的角色。1

等等，这哥们是不是又喝多了？毕竟今年2月他刚说过“软件工程师要消失”，当时大家还在骂他贩卖焦虑。结果4个月后，他就把炮口对准了所有白领。更扎心的是——他背后的Claude Code已经贡献了GitHub上4%的公开commit，年化收入突破25亿美元。这已经不是预言，是直播拆迁现场了。1

新物种：5种“非人”的战斗力

Boris给出的五类角色，听起来像游戏里的职业卡牌：

  • 原型师（Prototyper）：一天能冒出十几个点子，大部分会死掉，但只要赌对一个就能躺赚。关键特质：冷血决断力，能亲手扔掉自己的亲儿子。
  • 建造师（Builder）：拿到原型就秒变生产级产品，速度就是一切。典型画像：不睡觉的工程狂魔，信息不全也能果断拍板。
  • 清道夫（Sweeper）：团队里的“扫地僧”，专门砍功能、删代码、简化UI。成就感来源：“我又砍掉了什么”。注意：这行没有掌声。
  • 增长手（Grower）：产品上线后接手，死磕PMF（产品市场匹配）。本质上是个翻译官，一边懂用户，一边懂数据，还得有同理心。
  • 维护者（Maintainer）：纯纯背锅侠。系统稳的时候没人理你，凌晨三点电话响了就是你的锅。抗压能力必须和机器人一样。

Boris还贴心地配了MBTI人格推荐，比如原型师适合ENTP/ENFP，清道夫适合ISTJ/INTJ——但注意，这些不是科学量表，只是一套“自我锚定”的游戏。

别急着对号入座，这俩坑你得先躲开

第一，别拿老岗位往上套。运营不等于Grower，程序员不等于Builder。过去你是设计师，可能未来会被重新分配成三种不同的角色。关键看你本身是什么人，而不是你以前叫什么title。

第二，别把自己框死。人是复杂的，一个人可以同时扮演两三个角色。Claude Code团队内部，很多人横跨两个甚至三个岗位。而且角色会随着项目生命周期流动——今天你是原型师，明天项目启动你变成清道夫，产品上线你又切换成维护者。如果只死守一个角色，你迟早得把项目交给别人。

Boris甚至给了管理者一张组队攻略：

  • 产品没找到PMF？多配原型师、建造师、清道夫。
  • 产品开始增长？重心转到建造师+清道夫+增长手，加一点维护者。
  • 产品已经强PMF？清道夫+增长手+维护者为主，留几个建造师。

这其实在说：产品的生命周期，决定了你需要什么性格的人。

洪水真的来了，但别急着上“诺亚方舟”

Boris自己就是个活教材。经济学出身，退学创业自学编程，曾是Meta首席工程师。2024年加入Anthropic，某天为了熟悉API顺手写了个命令行工具——然后震惊地发现，“模型学会使用工具了”。命运的齿轮开始转动，Claude Code从内部小工具变成了全球爆款。1

站在这个“上帝视角”上，他比谁都清楚传统分工是怎么被AI碾碎的。今年2月他上播客时被问：“下一个被AI冲击最大的角色是什么？”Boris的回答很直接：产品经理、设计师、数据科学家……最终，所有需要操作电脑的工作都会遭到冲击。

6月Fortune大会上，主持人又问：“在一个越来越少亲手写代码的世界里，公司到底找什么样的人？”Boris只回了一个词：通才。

他甚至开玩笑说，现在是ADHD的黄金年代——那些不满足于只专精一个领域的人，迎来了最好的时代。因为AI把技能之间的鸿沟疯狂压缩了。过去你学设计要几年，学编程又几年，现在模型帮你跨过去了。

但当然，危机感才是底色。护城河正在干涸，你的专业壁垒正在被一个不断Scaling的模型一点点蚕食。

Boris讲了一个15世纪抄写员的故事。印刷术来了，所有抄写员都在焦虑——但有一个抄写员很兴奋，因为他不喜欢抄书，他更喜欢给书画插图和装订。印刷术解放了他的时间，让他可以做自己真正擅长的事。

洪水之下，没有人是安全的。但会游泳的人——会到达新大陆。
