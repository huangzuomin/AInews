今天，科技圈炸了点小水花——不对，是直接放了个二踢脚。

你猜怎么着？刚刚，OpenClaw和Cursor，这两位在AI圈出了名的“卷王”，几乎在同一时间，甩出了它们的原生App。12 一个直接把满血的AI Agent实打实地塞进了你的iPhone，另一个干脆把整台“云电脑”打包，让你在手机上写代码、合PR。

简单来说，那个曾经只配在网页里、命令行里狂奔的AI智能体，今天起，被正式塞进了你的口袋。

“随身携带一个AI军团”这件事，不再是科幻电影里的台词，而是你排队买咖啡时的日常。

### 龙虾驾到：你的手机，就是AI的本地主机

先来说说这只“现象级”的龙虾——OpenClaw。

老黄（黄仁勋）在GTC上亲口盖章它是“个人AI的操作系统”，这哥们儿一直以“硬核”著称。1 它的核心玩法是：完全跑在你本地设备上的AI Agent。帮你管理文件、清空上万封垃圾邮件、甚至自动提Pull Request，那都是基本操作。

但以前，想在外面用它，体验有点“感人”——你得通过Telegram、WhatsApp这些工具，像遥控玩具车一样远程“发号施令”。1

今天，这种“隔着屏幕喊话”的体验彻底结束了。

OpenClaw上架的是“全血原生App”。你只需要掏出手机，扫描二维码，就能直连你家里的私有Gateway。1 然后，划重点：

  • 实时交互，指哪打哪： 不仅能直接聊天，还能远程把控、审批Agent的每一步操作。在地铁上看到一条消息要回、有个自动化任务要审批？拇指轻点，搞定。
  • 权限拉满，想控就控： 它的硬件权限全面解锁。相机、屏幕、GPS、相册、通讯录……你按需给它开“绿灯”。1
  • 隐私优先，本地为王： 它主打“local-first”（本地优先）架构。密钥、配置、权限都在你自己手里，官方强调“无数据收集”。1

一句话总结：OpenClaw让你的手机，成了你私有AI军团的“移动指挥部”。

官方Slogan很动人：“让智能体在你的拇指所及之处，尽情奔跑。”1 我给它补一句：“顺便让你的手机，变成你的超级外挂。”

当然，天下没有免费的“龙虾”。免费版每天20条由Gemini驱动的消息，想无限量？每月花20美元。1 代价是它容易被Prompt Injection攻击（一种通过输入恶意指令来操纵AI的黑客手段），而且对Gateway设备的权限要求极高，风险也得看清楚。

### Cursor上架：手机一掏，代码自动写

如果说OpenClaw是“私人助理军团”，那Cursor干的事就更“程序员”了——把整台云电脑，塞进了iPhone。2

今天，Cursor正式发布了原生iOS应用的公开测试版，向所有付费用户开放。2 它的杀手锏只有一句话，但足以让所有程序员虎躯一震：

本地可以关机，云端Agent继续狂飙。2

这是什么神仙体验？我们来拆解一下：

  1. 打开App，选个仓库，点个Agent： 就像在电脑前一样，它就能跑在云端虚拟机里，配备完整开发环境，自己测试、自己迭代、直到产出一个可合并的PR。
  2. 语音口述需求，AI干活不累： 你甚至可以直接用语音说：“给我把这个页面的标题改成‘老板说的都对’。”它就能听懂并执行。2
  3. 远程遥控，一键合PR： 电脑上正在跑的Agent，你可以换到手机上继续指挥。Agent干完了、需要拍板了，手机会通过iOS的“实时活动”和锁屏推送，第一时间把你叫醒。2
  4. 真实场景，直戳痛点： 官方博客里，Cursor团队给出的用法堪称“打工人的圣经”：
    • 午饭时被on-call呼叫？甩个Agent去排查、提修复方案。等你回到工位，PR已经躺在那等你审。2
    • 客户报了个紧急bug却不在电脑前？从手机起一个Agent去复现、定位、修复。2
    • 在X上刷到用户吐槽？截个图、标注一下，丢给Agent当视觉上下文，改UI最快。2

Cursor团队甚至为此发明了个新词：FOMAT（Fear of Missing Agent Time）——害怕错失AI替你干活的时间。2

可以说，从今天起，程序员不再需要“守在电脑前”，而是可以“等着被通知”。

### 人离开工位，但AI永不停机

今天发生的，远不止“多了两个App”。

OpenClaw和Cursor的同步登场，释放了一个极其清晰的信号：Agent的运行场域，正在和“人类的物理坐标”彻底解绑。

过去，无论AI多强，本质上，你还是得坐在电脑前操作它。而现在：

  • OpenClaw 让你的手机，成了私有AI军团的移动节点。
  • Cursor 让你的手机，成了你随身指挥云端开发的遥控器。

它们解决的，是同一个千古难题：人会离开工位，但任务不该停下。

从“人坐在电脑前操作AI”，到“人走开、AI自己跑、跑完叫你回来拍板”——这中间隔着的，是Agent自主性的一次实打实的进化。人的角色，正在从一个“操作者”悄悄变成“审批者”。

这，是一个微妙但意味深长的位移。

正如Cursor所言：未来，云端跑Agent的体验，将和在本地跑变得“无法区分”。2 当运行环境彻底虚拟化、当指挥入口彻底移动化，AI干活这件事，第一次真正做到了“无处不在”。

所以，是时候给你的手机腾个位置了——它不再是娱乐终端，而是一台可以随时调遣AI军团的“移动超级计算器”。

口袋里的AI时代，真的来了。
