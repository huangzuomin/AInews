AI工具深度评测：Claude「Record a skill」——从指令式交互到流程自动化的进化

温故智新AIGC实验室

TL;DR：

Claude 新增的「Record a skill」功能通过录制用户操作与语音解释，将琐碎的桌面办公流程“蒸馏”为可重复执行的自动化脚本。该工具显著降低了工作流自动化的门槛，特别适用于跨应用、非标准化的繁琐重复性任务。

功能解析：从“写手册”到“做示范”

Claude 推出的 Record a skill 功能，本质上是 AI 从“理解指令”向“模仿行为”的范式转移。与传统的编写 SOP（标准作业程序）不同，该功能允许用户在开启录制后，通过实际操作并配合语音描述思路，让 AI 学习并理解任务逻辑。

核心逻辑在于，它不仅记录了鼠标的轨迹和点击坐标，更通过语音录入整合了用户的“隐性知识”——即为何执行某项操作、遇到异常如何处理等判断逻辑。这种交互方式有效地解决了传统自动化方案（如 API 调用或脚本开发）门槛过高的问题，让非技术背景的办公族也能定制专属的工作自动化流程。

性能测试与实测体验

在实际应用中，该功能的表现呈现出鲜明的特点：

  • 执行逻辑捕捉：在测试整理配图任务时，Record a skill 能够较好地识别文件分类规则。与其依赖硬编码路径，它更倾向于理解“文件名前缀”这一语义逻辑。
  • 异常处理能力：这是该功能的亮点。当录制时明确告知“遇到重名文件先暂停并询问”后，AI 在后续执行中表现出了比传统宏定义更强的鲁棒性。
  • 响应与稳定性：受限于当前模型对屏幕UI的解析能力，在高负载或复杂界面切换时，存在偶发的响应延迟。此外，目前该功能主要支持 Mac 平台，Windows 用户尚无法使用，限制了其普及度。

测试结论显示：该功能在处理如“定期报表清洗”、“OA系统内数据迁移”等跨界面长流程任务时，表现出极高的潜力。但在极短、简单的任务上，手动操作的效率依然优于触发 AI 流程。

竞品对比与市场定位

与 OpenAI 的 Codex (Record & Replay) 相比，两者均旨在通过 AI Agent 解决“自动化孤岛”问题。

  • Claude 的优势：侧重于“听懂理由”。它将语音录入作为核心输入，使得生成的 Skill 更具可解释性和灵活性。
  • Codex 的优势：侧重于“精准重现”。其在界面元素捕捉的稳定性上表现较优，且更强调任务背景的预设。

两者在方向上是一致的：即通过用户行为的“蒸馏”，将个人化的工作习惯转化为可调用的 AI 资产。

使用指南：最佳实践与注意事项

为了获得最优的执行效果，建议用户遵循以下原则：

  1. 语音胜于动作：在录制时，清晰的思维表达比精准的鼠标移动更重要。明确指出“哪些内容是变量”、“什么条件下执行分支任务”。
  2. 分阶段测试：不要指望一次录制就能完美覆盖所有场景。建议采用“三轮测试法”：先测试基础路径，再故意制造重名等异常，最后测试不同素材下的泛化能力。
  3. 安全预警：由于该功能涉及屏幕录制及鼠标键盘控制，在录制过程中务必关闭敏感应用（如网银、密码管理器），防止隐私数据泄露。
