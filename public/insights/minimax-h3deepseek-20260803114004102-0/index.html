天下苦闭源久矣！MiniMax H3开源，多模态界的“DeepSeek”登场

温故智新AIGC实验室

TL;DR

MiniMax H3把视频生成的门槛彻底打碎了：2K分辨率、视频编辑能力全球第一、开源、价格只要同类旗舰的三分之一。闭源模型们的好日子，怕是要到头了。

“天下苦闭源模型久矣”——这句话在AI圈流传已久，尤其在视频生成领域，Seedance、可灵等闭源模型掌控着定价权，用户要么接受昂贵的API，要么排队等白名单，中小团队连口汤都喝不上。

但就在2026年7月31日，MiniMax H3的发布彻底打破了僵局。不仅性能直接杀入全球第一梯队，更关键的是——它开源了，而且价格只有同类旗舰的三分之一。

市场用真金白银投了票：港股MINIMAX-W当天涨幅超10%，报HK$249.4。

性能“卷王”：视频编辑全球第一，文字也能“入画”

先看硬实力。在权威的Artificial Analysis视频模型榜单中，截至2026年7月31日，H3在视频编辑能力项排名全球第一，文生视频第二，图生视频第三，综合能力稳稳站在第一梯队。12

这个成绩意味着什么？意味着它不仅能“生成视频”，还能像专业剪辑师一样理解你的创意。举个具体例子：给H3一张人物参考图、一段希区柯克式镜头运动的参考视频、一条参考歌声的音频，它能读懂“让图里的人物按参考视频的镜头运动、用参考音频里的歌声唱歌”这样的复合指令，一次生成带原生双声道的2K成片。这种“跨模态复合参考”能力，此前是Seedance的招牌，现在H3也拿下了。3

更让人惊艳的是复杂文本保持能力。想象一下：品牌logo放在玻璃杯上，模型要理解玻璃的折射；放在墙上，要理解墙的曲率；镜头推拉时，字体还不能畸变。H3做到了。这不再是简单的“生成字体”，而是模型对整个场景有了深度理解。你在视频里看到的片头标题、动态海报、UI字幕，从此告别歪歪扭扭的“AI味儿”。4

支撑这些能力的是H3的技术架构——Contextual Omni Representation（上下文全模态表示），它把文本、图像、视频、音频拼成统一上下文，让模型理解它们之间的关系，然后直接生成带原生双声道的2K视频。自研的H3-VAE把画面压缩率做到极致，同样视频用更少的token表达，序列长度直接省了4倍——训练和推理的成本自然就下来了。5

价格“屠夫”：2K视频一刀砍到8毛，还包“后期”

如果说性能是开胃菜，那价格就是主菜。

过去半年，行业主流商用模型默认分辨率还在1080p打转，H3直接默认输出2K。更狠的是，它定价0.8元/秒，仅为Seedance 2.0的三分之一。15 怎么做到的？核心就是技术降本：别人家想输出2K/4K，通常先低分辨率生成，再用超分模块放大，这相当于“猜”细节，猜完经常糊。H3不一样，它把低清画面当参考，结合原始多模态上下文，直接用模型本身的能力恢复细节——所以文字、纹理不翻车，成本却低得多。

但最让后期从业者“颤抖”的是另一个能力：一站式成片。

以前你要做一个电商广告，流程是：文生视频拿到产品画面 → TTS合成旁白 → 剪映套字幕 → AE做打光特效和价格跳动。现在H3一步到位：你输入产品和脚本，它直接输出带运镜、配音、字幕、特效的成片，所有元素跟画面空间、光线、节奏完美对齐。这不是简单的“生成素材”，这是把AE、Premiere、剪映的活儿全包了。

参考Adobe 2025财年，创意云业务全球收入约145亿美元，视频后期占大头；国内视频后期外包市场也在300～500亿元。如果H3的AI原生后期能力持续兑现，吃掉其中10%～30%不是梦。就像官方说的：“视频模型将能够理解更完整的创作意图，处理更复杂的内容需求，并逐步从'生成一段视频'，走向真正参与内容生产的全过程。”——这口气，是要当视频界的“Uber”，吃掉传统软件的“出租车”。

开源“王炸”：闭源模型的“诺曼底”时刻到了？

H3发布当天，MiniMax同步宣布将开源。这在视频生成领域是头一回——所有主流玩家（Seedance、可灵、Sora、Veo）全都是闭源。理由很简单：训练成本太高，闭源API最赚钱。

但闭源模式的问题也显而易见：涨价、排队、白名单、中小团队被挡在门外，甚至催生了账号倒卖和拼单的灰色生意。B端客户更痛苦——影视公司不敢把品牌IP扔进公有云API，广告主受不了品牌视觉每次生成都随机漂移，游戏公司不可能将核心资产交给第三方模型。这一批“最贵、最有粘性”的客户，闭源模型根本接不住。

H3的开源+可本地部署，正好破了这个局。企业可以私有化部署，数据主权不再是个问题。同时，0.8元/秒的价格把商用起步价压到了最低，开发者生态也能真正参与进来。

这不就是多模态领域的“DeepSeek时刻”吗？年初DeepSeek用开源文本模型重塑了市场格局，现在MiniMax在视频赛道复制了同样的剧本。历史总是惊人的相似——技术的量变积累到一定程度，就会引发质变。当年Netflix吃掉Blockbuster，Uber吃掉出租车公司，Airbnb吃掉连锁酒店，现在，AI要吃掉那些不AI的软件。

当然，牌桌不会因为一款模型就彻底重排。但H3至少证明了一件事：MiniMax在下行情绪中，依然有能力掀翻游戏。港股市场的真金白银，已经投出了第一票。

对于广大创作者和开发者来说，这可能是2026年最“香”的开源礼物。而对于那些还捂着闭源模型不放的厂商——醒醒，天花板快被捅穿了。
