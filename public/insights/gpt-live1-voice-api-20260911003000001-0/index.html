OpenAI 发布 GPT-Live-1：全双工语音变成 API 标准件，语音 Agent 的分层架构被简化

温故智新AIGC实验室

TL;DR：

GPT-Live-1 把"能同时听说的语音前端"做成了 API 标准件（$0.05/分钟），并支持把推理与工具调用委派给 GPT-6 Astra 等后端模型。语音交互的技术栈第一次出现清晰分层：听说归语音层，思考归推理层——语音 Agent 的搭建门槛将大幅下降。

架构信号：语音与推理正式解耦

这份发布的结构比模型本身更值得注意：GPT-Live-1 定位为前端语音层，支持将推理和工具调用委派给 GPT-6 Astra 等后端模型。这意味着 OpenAI 官方给出了"语音层不负责思考"的架构范式——低延迟的全双工听说是语音层的职责，复杂的推理与执行交给可替换的推理模型。对开发者而言，之前"语音模型越强越好"的单一选型，变成了"语音层选延迟、推理层选智力"的双层选型。

定价信号：$0.05/分钟想换走什么

每分钟 5 美分的语音层定价，直接对标的是现有语音 Agent 方案里最贵的部分——传统的 ASR + LLM + TTS 三段式管线，不仅延迟高，成本加总也远超这个数。OpenAI 用一个标准件价格，瞄准的是语音客服、实时翻译、语音助手这类高频场景的整体预算。结合 GPT-6 Astra 面向专业工作场景的定位，OpenAI 在搭建"前端感知 + 后端推理"的完整企业栈。

展望

两个观察点：一是全双工模型的打断处理与长对话稳定性（真实语音场景的两大难点）在规模化后的表现；二是"语音层 + 可替换推理层"的范式会不会被 Gemini、Anthropic 跟进——如果成为行业标配，语音赛道的竞争将从模型能力转向延迟与价格。
