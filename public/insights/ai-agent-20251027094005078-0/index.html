前天猫精灵总裁下场“卷”AI Agent，这次想从运动硬件“跑”出通用智能？

温故智新AIGC实验室

TL;DR：

前天猫精灵总裁彭超不玩智能音箱了，一头扎进AI Agent创业圈，公司叫“云玦科技”。人家不走寻常路，想从运动硬件切入，用“自进化”智能体，在跑步跳操中跑出AGI，这波操作是不是有点“野”？

前天猫精灵总裁彭超最近又搞了个大新闻！据《智能涌现》独家爆料，这位曾经在阿里、华为叱咤风云的大佬，悄悄成立了新公司“云玦科技”，直奔时下最火的AI Agent赛道而去。1 别以为他还是想做个升级版智能音箱，这次他瞄准的是一个看似“清奇”的切入点——运动可穿戴硬件+Agent智能体，目标直指遥远的通用智能（AGI）！

运动智能体，AGI的“曲线救国”之路？

你是不是也和我一样，刚听到“运动AI硬件实现通用智能”时，心里冒出一个大大的问号：这葫芦里到底卖的什么药？ 别急，彭超的思路其实“内有乾坤”。

他相信，消费级智能体和通用智能可能共享一套训练架构。简单来说，就是让AI扮演好“跟踪、规划、分析、执行”的角色，再配合上专属硬件，让这个智能体能像玩游戏打怪升级一样，自己不断进化。想象一下，你的运动手表不再只是记录步数，而是变成了一个能主动帮你规划训练、分析状态、甚至“鞭策”你进步的“私人教练”。

“让AI扮演好跟踪、规划、分析、执行的角色，配合硬件设备，让智能体有自进化的能力，陪伴消费者在高速、高频运动的5000立方米空间里进阶。再进化迁移到更多物理空间。”

— 彭超的“野心”，听着是不是有点像开了挂的《头号玩家》？

为啥偏偏是运动场景？你想啊，跑步、跳操、游泳……这些运动数据都是高速、高频且相对结构化的。在这个“5000立方米”的物理空间里，AI能快速获得大量反馈，不断迭代和优化自身行为。用彭超的设想来说，这就像是给AGI找了个最快的“练功房”，一旦在运动场景里练成了“神功”，就能逐步迁移到更广阔的物理空间，最终实现通用智能的“大一统”。这波操作，简直是AI界的“农村包围城市”，妙啊！

核心技术“加持”，Agent不只嘴炮那么简单

光有想法还不行，AI Agent这玩意儿，核心还是得看技术栈够不够硬核。别看现在市面上“Agent”满天飞，但能真正做到“能干活、会来事儿”的，凤毛麟角。

彭超为自己的“云玦科技”找来的另一位联合创始人，那背景简直是妥妥的“技术流”——齐炜祯，此前是中关村人工智能研究院大模型博士培养方向的导师。据说，这位大佬曾是微软与中科大联培博士，早在2020年的ProphetNet项目中，就首次提出了一个名为MTP（Multi-token Prediction）的架构。1

这个MTP架构可不是“平平无奇”的小透明，它曾被Deepseek V3、Qwen-3-Next等业内知名大模型引入核心预训练方法，这相当于给“云玦科技”的AI Agent打上了“高配版发动机”。说人话就是，MTP能让AI模型以更快的速度、更低的消耗，预测出更高质量的下一个词或下一批词。这对于需要实时响应、快速决策的运动智能体来说，简直是“如虎添翼”。齐炜祯在模型生成加速、多模态智能体和端到端推理加速方面的经验，更是给“云玦科技”的Agent项目增添了浓浓的“科技与狠活”气息。

前天猫精灵总裁，这次要“玩真的”？

说回彭超本人，他在AI硬件圈子里可不是“新手村”玩家。在创立“云玦科技”之前，他已经在多家大厂积累了10亿美金以上量级智能硬件的操盘经验。1

  • 华为时期（2018-2020）：他曾担任华为消费者BG印度地区部总裁，硬生生在印度建立起了当时华为境外唯一一个“产品定义-研发-制造-销售”全链条的国家地区部公司，这操作，简直是“从无到有，徒手开荒”。
  • 阿里时期（2021年起）：他加入阿里巴巴担任天猫精灵总裁，主导将达摩院大模型引入天猫精灵，并负责组建集团一级业务公司“智能互联”。在阿里任职的三年里，他对涉及数亿生态设备的AIoT业务进行了大刀阔斧的调整，不仅让硬件产品毛利转正，还实现了软件订阅的规模化收入。这可是把“赔钱货”变成了“摇钱树”，硬核实力可见一斑。

彭超在硬件定义、供应链管理、商业化运营上的丰富经验，无疑给“云玦科技”未来的产品落地打了一剂“强心针”。毕竟，再牛的AI Agent，也得有“身体”才能施展拳脚。据了解，“云玦科技”的首款硬件将是“不只是一款产品，而是一套产品组合”，看来彭超是想来一波“组合拳”，在运动AI硬件市场掀起一场“腥风血雨”啊。

从智能音箱到运动AI硬件，从“听话”的工具到“自进化”的伙伴，彭超的创业方向，正顺应着AI大模型从被动响应指令向主动规划、执行复杂任务的“Agentic use”趋势。1 这次，他能否从你的健身环、跑步机、甚至智能跑鞋里，跑出一个真正的通用智能体，实现人机伙伴关系的“终极奥义”？我们只能拭目以待，看看这位“老将新传”能给我们带来怎样的新惊喜！毕竟，AI的未来，总是充满了无限可能和……偶尔的**“大饼”**，不是吗？
