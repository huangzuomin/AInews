养虾还是养马？一场AI Agent的疯狂套利与“后龙虾时代”的反思

温故智新AIGC实验室

TL;DR：

一个叫“龙虾”的AI Agent火遍全网，大家疯狂“养虾”套利，结果被“爸爸们”封杀后迅速凉凉。现在，“养马”成了新潮流，但背后其实是AI行业的一次集体反思：我们到底要一个无所不能但随时可能“发疯”的AI，还是一个稳定靠谱的“打工人”？

从“排队代装”到“排队卸载”，只用了50天

三月的朋友圈，如果你没分享过一张红色小龙虾的截图，都不好意思说自己在科技圈混。OpenClaw，这个代号“龙虾”的AI Agent项目，以火箭般的速度窜红，GitHub星标一度超越React，微信指数飙到1.65亿，甚至催生了“全民养虾”的奇观[^1]。

那段时间有多魔幻？一个需要付费找人“代安装”的工具，竟然成了现象级产品。

不少小白用户花了几百块请人“装龙虾”，就为了体验那个传说中“24小时在线、帮你搞定一切”的数字员工。似乎一夜之间，每个人都想拥有一个能替你打工的AI。

但现实很快抽了所有人一记响亮的耳光。

仅仅50天后，风向骤变。Anthropic一封“封杀令”直接掐断了OpenClaw套利的命脉——禁止用每月200美元的Claude Max订阅费，无限量调用API进行套利[^1]。紧接着，OpenClaw的访问量腰斩，曾经一虾难求的盛况，变成了大规模的“退坑潮”。

本质是“套利”，而不是“革命”

很多人复盘OpenClaw的成功，归功于产品牛、生态好。但真相很残酷：它最大的魅力不是能力，而是漏洞。

OpenClaw干的事儿，本质上是一场“钻空子”的权宜之计。它通过模拟Claude客户端请求，让用户用固定的订阅费（比如200美元/月）去换取价值数千美元甚至上万美元的API调用。对于开发者来说，这不叫“使用AI工具”，这叫“薅AI厂商的羊毛”。

套利才是第一推动力。当Anthropic发现自己的账单被“龙虾”们吃得越来越空时，它以雷霆手段叫停，只给用户一天缓冲期。这场狂欢就此告终。所以，当“免费午餐”的底层逻辑被击穿时，再华丽的叙事也撑不起虚高的热度。

墙倒众人推，但“龙虾”到底输在哪？

除了套利模式终结，OpenClaw自身的硬伤也开始暴露。

  • 功能很酷，但太爱“动手”了：它不只聊天，它更会“动手脚”——删文件、发邮件、调用各种软件。普通AI出错最多给你个假答案，OpenClaw出错，可能直接把你辛辛苦苦写的代码删个精光。这谁敢放心用？[^1]
  • 门槛高到离谱：一个需要付费找人来安装的工具，本身就说明它离大众有多远。对普通用户来说，部署OpenClaw不是在装软件，是在挑战自己的智力极限。
  • 成本是“黑洞”：单次请求中，73%的token是固定开销，一次查询动不动就携带10万+的上下文窗口。对于普通用户来说，这简直就是钱多烧得慌。

就这样，OpenClaw从“效率革命”的神坛跌落，变成了“风险失控”的代名词。

后龙虾时代：谁在接盘？

OpenClaw凉了，但AI Agent的需求没灭。用户们像被踩了尾巴的猫，四处寻找新家。最后，它们主要流向三个方向：

  1. Hermes Agent——“养马”成了新时尚：这是目前最大的“龙虾难民”收容所。它聪明的地方在于，不搞“什么都能做”那一套，而是强调“自我进化”。它每次完成任务后，会把经验沉淀成“Skill”，下次直接调用。用得越久，它就越懂你，迁移成本自然就高了[^2]。圈内开始流行“不养虾，改养马了”。
  2. Claude Code——“特定场景的专才”：这是Anthropic官方发布的编程工具。它不搞花里胡哨的桌面控制，只专注于写代码，执行环境可控，结果可预期。这代表了极客们的一种价值分裂：我们不需要一个全能的狂人，我们需要一个稳定、听话的代码民工。
  3. 垂直行业Agent——回到“工具”的定位：飘在空中的“数字员工”故事不灵了，企业开始拥抱嵌入工作流的“工具人”。钉钉悟空、WindClaw这类产品，把Agent能力嵌入审批、报表等具体流程，目标明确，动作可控。

行业反思：AI Agent需要的是“镣铐”

Anthropic封杀OpenClaw，而OpenAI的奥特曼却高调宣布“ChatGPT用户可以登录OpenClaw”。这种看似矛盾的操作，暴露了AI行业对于Agent未来的路线分歧。

过去一年，大家对Agent的想象是“数字员工”，是能替主人“包打天下”的超级助理。但现实是，Agent越自主，越容易失控；任务链路越长，越容易偏离目标；权限越高，企业越不敢放权。

整个行业开始从“Autonomous Agent”（自主代理）转向“Human-in-the-loop”（人在回路中）。AI不再是试图完全替代人，而是回到“协助人”的位置。新一代Agent产品开始反向思考：限制权限、缩小场景、保留人工确认，反而更容易真正落地。

OpenClaw就像一台我们早年在电脑城配的“组装机”——性能强大，但死机、蓝屏是家常便饭。极客乐在其中，普通用户只想买个iPhone，按下开机键就完事。

今天，所有人都知道AI Agent会是下一代人机交互的入口。但大多数人并不想“养虾”，他们真正想要的，是一个已经被封装好、稳定、安全、开箱即用的产品。

OpenClaw用一场“套利狂欢”，让整个行业提前看清了一件事：AI Agent的未来，未必属于最自由、最强大的系统，而更可能属于那些最稳定、最安全、最容易被普通人使用的系统。
