史上最强AI模型被封杀？Anthropic和特朗普政府的“宫斗大戏”全解析

开场暴击：谈判破裂，Fable 5继续“凉凉”

就在北京时间6月15日，一场被媒体称为“华盛顿攻防战”的生死谈判结束了——没有结果。Anthropic的高管团队（包括Logan Graham、Dave Orr这些AI安全圈的大神）紧急飞往华盛顿，商务部长从法国G7远程参会，白宫AI主管David Sacks、CIA高层悉数到场。所有人都以为，凭借Fable 5和Mythos 5的顶级实力，Anthropic能说服政府放行。1

然而，结果令人瞠目结舌：谈判破裂，出口管制继续生效。两款目前全球最强大的AI大模型，依然被全网封杀。2

这到底是咋回事？一场“亚马逊式”的背刺

让我们把时间拨回6月12日，一个“载入史册”的周五。

Amazon CEO Andy Jassy直接给财政部长打电话，举报Anthropic的模型存在严重的“越狱”风险——说白了，就是有人能绕过安全护栏，让模型干坏事。3

两天后，美国商务部紧急下达出口管制令。Anthropic被迫在90分钟内切断全球访问，包括自己公司的非美国籍员工都被锁在门外。公司内部人士吐槽：“我们根本没有反应时间，政府指令含糊到离谱，但我们没法实时筛选用户国籍，只能一刀切。”1

更骚的操作在后面：白宫声称，Anthropic的Mythos模型曾被提供给一个“和中国有关联的组织”。虽然Anthropic反驳说那只是一家全球电信公司，且权限已撤回，但白宫的怀疑，已经像一颗种子扎下了根。4

真相：不是技术不行，是“情商太低”

随着更多内幕被挖出，这件事的本质变得有点——哭笑不得。

被举报后，Anthropic发了一篇博客，直接硬刚亚马逊的发现，说“你们夸大了风险”。然后，他们聘请了一位网络安全专家来审查——这位专家恰恰被特朗普政府视为“激进反对派人士”。更雪上加霜的是，这位专家随后被一位刚被特朗普炒鱿鱼的前网络安全官员公开庆祝。

“名人堂”联名信：大佬们怒了

就在谈判失败前一天（6月14日），美国网络安全界爆发了一场“大地震”。数十位顶级专家——包括前Facebook首席安全官Alex Stamos、世界顶级密码学家Bruce Schneier、约翰霍普金斯大学副教授Matthew D. Green、漏洞赏金体系奠基人Katie Moussouris，以及谷歌、Zoom、Sophos、Adobe等公司的安全高管——联名发表了一封公开信，要求政府立即解禁。1

他们的核心观点犀利到让人无法反驳：

  • 这些模型不是独一无二的武器。是的，Mythos很会挖漏洞，但GPT-5.5和一些开源模型也能做类似的事。
  • 封杀模型，受伤的是防守方，不是攻击方。这些模型最强的能力是代码审计——帮开发者找自己代码里的漏洞。这正是防御方对抗网络攻击的核心武器。
  • 其他国家正在快速追赶。公开信指出：“有些国家的开放权重模型只落后于美国最好的模型几个月。如果我们把最好的能力从防御者手中夺走，而对手在快速进步——这是极其危险的。”1

公开信的一段话堪称“灵魂拷问”：

不是我们所有人都认为AI监管是正确的方向。但如果“保护国家关键基础设施”的目标真的要包括监管模型，那么监管应该：

  1. 建立在科学评估基础上；
  2. 通过民主规则制定过程创建；
  3. 透明公正地执行，并给予合理的整改时间；
  4. 仅在确保美国公众安全所必需的最小范围内使用。1

Fable 5的命运，也是美国AI的命运

故事到这里，已经不仅是Anthropic一家公司的危机了。这场“华盛顿攻防战”的失败，折射出一个更深层的问题：当AI监管变成了“态度考试”，下一个被下架的可能是任何一家“不会说话”的公司。1
