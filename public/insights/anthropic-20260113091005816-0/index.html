Anthropic深夜整活：白领的饭碗，这次真的要被这个“数字同事”端走了？

温故智新AIGC实验室

TL;DR：

Anthropic 把给程序员用的“黑科技”魔改成了全员通用的 Cowork，打算让 AI 钻进你的文件夹里直接替你“搬砖”。虽然目前仅限 macOS 且还没 Linux 版被网友狂喷，但这波“数字同事”的进化确实让白领们感受到了来自大模型的“压迫感”。

如果你还觉得大模型只是个会写诗、会道歉的“聊天框”，那 Anthropic 刚放出的这个“王炸”可能会让你脊背发凉。

就在最近，Anthropic 团队在折腾开发者工具 Claude Code 时，发现了一个非常魔幻的现象：这帮程序员并没有乖乖地只用它写代码。相反，大家把它当成了“全能补丁”——有人用它整理乱七八糟的文档，有人拿它自动回邮件，甚至还有狠人让它监测植物生长和控制烤箱。1

Anthropic 的工程师们一拍大腿：既然大家都想找个“数字同事”，那干脆就把这套底层架构封装一下，推给所有人。于是，Cowork 闪亮登场。

拒绝“尬聊”：它不再是助理，而是你的“数字牛马”

长期以来，我们和 AI 的交互就像在玩一种很新的“文字游戏”。你发指令，它回文本；你再微调，它再生成。这种“对话式”模式在处理真正的办公流时，简直是生产力黑洞——你得反复复制粘贴，还得人工对齐格式。

Cowork 试图终结这种“无效沟通”。它的核心逻辑不是“聊天”，而是“协作”。2

简单来说，Cowork 就像是一个拿到了你工位钥匙的同事。在获得你的授权后（别担心，Anthropic 强调这不是全盘授权，而是逐个文件夹的点名确认），它能直接深入你的本地文件系统。1

  • 文件系统深度交互：它可以扫描你那个几百 GB 的“新建文件夹”，按照逻辑自动重命名并归类；能从一堆乱码般的截图里提取费用信息，直接生成报销单。
  • 多线程并发处理：你可以给它留一堆言，然后去喝咖啡。它会自己拆解任务、排队执行。就像 Anthropic 首席产品官 Mike Kryuikov 说的，这更像是在给同事留便条，而不是反复拉锯。3
  • 自带“技能包”与浏览器自动化：配上 Chrome 插件，它甚至能帮你执行需要访问网页的任务。4

这种能力的本质，是 Claude 从一个只会空谈的“文学青年”，变成了真正能操作真实材料的“熟练技工”。

“删库跑路”预警：能力越强，风险越狂？

当然，让 AI 拥有读写文件的权力，听起来就很像恐怖片的开场。

Anthropic 也没打算掩盖这一点。他们直接在产品说明里给用户打了“预防针”：如果你的指令有歧义，Claude 真的可能会执行一些不可逆的操作，比如把你辛苦攒的素材一键清空。1 为了防止这种“数字惨案”，Cowork 在执行任何重要操作前都会主动弹窗求确认。

更高端的风险在于**“提示注入”**。万一你在网上下载了个文档，里面藏着一段恶意代码诱导 AI 删掉你的硬盘，该怎么办？Anthropic 表示他们已经构建了多层防御，但也坦言“代理安全”仍然是整个 AI 行业的未解之谜。1

网友破防：不支持 Linux，你是看不起谁？

Cowork 发布后，社区的反应可以用“一半海水，一半火焰”来形容。

一方面，科技博主和早鸟用户们直呼“真香”，认为这才是 AI 真正进入工作流的正确姿势。5 但另一方面，Anthropic 的评论区也成了大型“破防现场”。

目前 Cowork 还是“研究预览版”，仅限 macOS 系统，且必须是 Claude Max 订阅用户才能体验。

“作为早期支持者，我感觉 Anthropic 最近的沟通越来越差了。”一位 Reddit 老哥开启了吐槽模式。 “只支持 macOS？Linux 党和 Windows 大军不配拥有数字同事吗？”1

这种“平台歧视”让不少开发者心碎了一地。虽然官方承诺后续会移植到 Windows，但对于那些习惯了在 Linux 环境下“指点江山”的极客来说，这种等待确实很煎熬。

未来预测：2026 年，你会和 AI 共享工位吗？

按照 Anthropic 的构想，2026 年将是“AI 参与者”的一年。3

未来的工作模式可能不再是你教 AI 怎么做，而是你把任务边界划好，AI 负责在里面折腾，最后给你一个确认按钮。Cowork 只是这种“人机协作”实验的第一步。

虽然目前的 Cowork 还有点像是个“早产儿”，功能不完善、平台有限制，甚至还有删文件的风险。但它释放了一个明确的信号：AI 正在从屏幕里的“纸上谈兵”，真正走向你的桌面，接管那些琐碎、无聊但又不得不做的行政杂事。

所以，白领朋友们，在感慨终于有人帮忙理文件之余，或许也该思考一下：如果 AI 真的能把这些事都干了，那我们要不要卷点更有技术含量的？
