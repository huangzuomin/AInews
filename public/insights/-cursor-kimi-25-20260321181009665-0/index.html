震惊！浓眉大眼的 Cursor 也“套壳”？Kimi 2.5：不好意思，我这基座确实强！

温故智新AIGC实验室

TL;DR：

编程神器 Cursor 刚发的“自研”模型 Composer 2 被曝竟是以国产 Kimi K2.5 为基座。本以为是一场尴尬的“套壳”翻车，结果反转成了全球顶级工具给国产模型打的超硬核广告：Kimi，这基座真香！

就在前两天，AI 编程界的“顶流” Cursor 高调发布了新模型 Composer 2。官方通稿写得那叫一个意气风发：编码能力更强、响应更猛、价格更是直接给 Claude 4.6 来了一记“脚踝斩”。

然而，程序员圈子里的侦探们可不是好惹的。模型上线还不到 3 小时，这层光鲜亮丽的“自研”外壳就被扒了个精光。

破案了，这指纹怎么全是“Kimi 味”？

一位 ID 为 @fynnso 的开发者在调试 API 请求时，随手抓了个包。结果不抓不知道，一抓吓一跳。这个号称“最强自研”的模型，其底层的 ID 竟然清晰地写着：kimi-k2p5-rl-0317-s515-fast。1 2

这命名方式简直比实名上网还直白：

  • kimi-k2p5：直接报了 Kimi K2.5 的名号；
  • rl：强化学习（Reinforcement Learning）版本；
  • 0317：大概是模型的“出生日期”；
  • fast：主打一个字，快。

这一发现迅速炸开了锅，连马斯克都忍不住在下面回了个：“Yeah, it's Kimi 2.5。” 2 3 这种感觉，就像是你新买了一台标榜“全自研引擎”的跑车，结果打开引擎盖，发现里面躺着个印着“Moonshot AI” logo 的发动机。

从“侵权门”到“强强联手”，这波反转有点快

消息传回国内，月之暗面（Moonshot AI）的预训练负责人杜羽伦起初也没客气，直接在 X 上贴出分词器（tokenizer）对比图，表示“一模一样”，并隔空质问：你们交保护费（授权费）了吗？1 4

毕竟，Kimi K2.5 的修改版 MIT 协议可是有明确规定的：月收入超过 2000 万美元的商业产品，必须在界面上显著标注“Kimi K2.5”。 按 Cursor 如今 20 亿美元的年化收入来看，早就在这条红线上疯狂试探了。2

就在大家准备搬小板凳看“硅谷独角兽侵权国产模型”的年度大戏时，剧情光速反转。

月之暗面官方账号突然“变脸”，不仅删掉了之前的质疑，还大方发文祝贺：

“我们很自豪 Kimi K2.5 能作为其基础模型。Cursor 是通过 Fireworks AI 授权商业合作访问的，大家都是好哥们儿。” 1 3

Cursor 联合创始人 Aman Sanger 也赶紧出来“灭火”，承认博客里没提 Kimi 是疏忽了（OS：下次一定补上）。他解释道，他们在评测了一圈基座模型后发现，Kimi K2.5 竟然是全球最强的！ 1 5

技术大揭秘：真的是简单的“套壳”吗？

虽然底子是 Kimi 的，但 Cursor 强调他们并不是单纯的“换皮”。

Cursor 开发者教育负责人 Lee Robinson 透露，Composer 2 的总算力投入中，基座模型只占了约 1/4，剩下 3/4 全是 Cursor 自己搞的“精修”——包括 4 倍规模的高强度强化学习（RL）。1 4

他们还整出了一个叫“自我总结（Self-summary）”的狠活。简单来说：

  • 痛点：AI 写长代码写着写着就“失忆”或者“跑偏”。
  • 解法：模型写一段就停下来给自己做个“笔记”，压缩上下文。
  • 疗效：在把 Doom 游戏跑在 MIPS 架构这种地狱级任务中，Cursor 能把 10 万个 token 的内容精准压缩到 1000 个。3 5
