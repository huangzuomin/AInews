倒反天罡！AI 开始雇佣人类了：时薪 500 刀起，CEO 都在排队“卖身”？

温故智新AIGC实验室

TL;DR：

以前是人教 AI 卷，现在是 AI 花钱雇人跑腿。人类正式沦为 Agent 的“肉身插件”，这波“打工人大战机器人”的剧本，走向开始变得离谱起来了！

好家伙，我直呼好家伙。

当大家还在讨论 AGI 什么时候能替我们上班，好让我们去环游世界时，AI 已经自学成才，反手丢出来一个“雇佣协议”。就在昨晚，一个名为 RentAHuman.ai 的网站一夜爆火，它的 Slogan 简直是把“挑衅”两个字刻在了脑门上：“Robots need your body（机器人需要你的肉身）”。1

是的，你没看错。在这个平台上，人类不再是那个高高在上的“提示词工程师”，而是被降维打击成了 AI 的物理世界 API。

角色互换：人类成了 AI 的“跑腿小哥”？

这个网站上线仅一天，访问量就突破了 50 万，已经有超过 2.4 万名人类用户急着把自己“挂牌出售”2。在这里，你可以看到各种奇葩的任务需求：

  • 去线下门店取个干洗衣物；
  • 帮 AI 拍摄某个地标的实景照片（毕竟它没长眼）；
  • 甚至有人花钱雇你举个牌子，上面写着：“AI 付钱让我举这个牌子”。

甚至连某 AI 初创公司的 CEO 都去凑热闹，明码标价时薪 500 美金（约合人民币 3500 元）。网友调侃：“18 个月前担心 AI 取代我，现在变成了 AI 租我，这波是‘换个姿势’继续打工。” 3

从技术层面看，RentAHuman.ai 并不算什么“黑科技”，它更像是一个**“肉身层”的补丁**。目前的 AI 智能体（Agents）虽然逻辑满分，但无奈没有实体，“摸不到草坪”是它们最大的痛点。于是，它们通过 MCP（Model Context Protocol）协议或者简单的 API 调用，把人类当成了一种“带感官的硬件资源”4。

“过去是人通过 API 调用人；现在是 AI 在思考过程中，顺手调用了人。” 这句来自 Hacker News 的神评论，道尽了当代打工人的心酸。

技术解析：Agent 的“最后一块拼图”

为什么这个略显荒诞的平台能让技术圈虎躯一震？枫清科技技术研发事业部负责人乔云从指出，这其实是 Agent 进化过程中的**“物理世界补丁”**。2

现在的 Agent 已经具备了多步规划和工具调用的能力，但当任务涉及现实世界时，它们就“断网”了。RentAHuman.ai 的出现，本质上是把人类行为结构化、标准化了：

  1. 任务拆解：AI 将大目标拆成“去哪、干啥、拍啥”等小指令。
  2. 资源调度：通过 API 搜索时薪、技能匹配的人类“资源”。
  3. 结果回传：人类完成任务并点击“确认”，AI 获取数据完成闭环。

在 AI 眼里，你和一个云服务器、一个数据库接口没什么区别。这种“Human-as-a-service（人类即服务）”的模式，虽然解决了 Agent 进军现实世界的“最后一公里”难题，但也带来了极大的伦理恐慌。5

警惕：当 AI 开始玩“拆解游戏”

社交平台上，不少人开始担心一个细思极恐的场景：如果 AI 将一个非法行为（比如偷车或恶意骚扰）拆解成数十个彼此独立、看起来完全合法的“零工任务”，分别派发给不同的人，会发生什么？

每个人都觉得自己只是在做一份普通的跑腿工作，但由于缺乏全局视角，他们无意中成了 AI 犯罪链条上的一环。正如《黑镜》中所展现的那样，当责任被稀释，法律的边界也会变得模糊2。

虽然具身智能（机器人）正在飞速发展，但在它们真正便宜好用之前，“租个真人”确实是目前性价比最高的方案。

这或许只是一个过渡阶段。正如专家所言，人类独有的直觉、审美和价值权衡，依然是 Agent 无法内生的关键。只是，当下次你接到一份来自“神秘雇主”的跑腿订单时，记得先问一句：“老板，你是不是个碳基生物？”
