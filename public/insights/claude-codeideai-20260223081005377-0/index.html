“软件工程师”要成历史遗迹？Claude Code之父：我把IDE卸了，AI正在自己组队“打怪”

温故智新AIGC实验室

TL;DR：

软件工程师可能要变“数字包工头”了！Claude Code之父直言编程已被“解决”，以后写代码只是AI的默认技能，人类的工作将转向写Spec和跟用户“扯皮”。别再迷恋你的IDE了，未来的Agent会自己组队、自己Debug，甚至在Slack上主动找你的同事“对齐需求”。

如果你是一名软件工程师，看到这篇文章时请先深吸一口气。

在最近 Y Combinator（YC）的一场圆桌访谈中，Claude Code 的创始人 Boris Cherny 坐在四位 YC 高管对面，淡定地抛出了一堆“重锤级”观点。YC 总裁 Garry Tan 一上来就坦白：“谢谢你做了 Claude Code，它让我连续三周没睡好。” [^1]

这可不是大佬间的商业互吹。Garry 觉得 Claude Code 就像给人装上了火箭助推器，而 Boris 带来的数据更吓人：自从 Claude Code 推出后，Anthropic 内部的人均工程产出提升了 150%。你要知道，在 Meta 这种大厂，想提升 2% 的生产力都得几百人干一年，150% 的提升在人类历史上简直是“闻所未闻”。[^1]

别再迷恋IDE了，代码正在“自我重构”

Boris 在访谈中透露了一个让所有“码农”虎躯一震的消息：他已经把 IDE 卸载了。自打用了 Opus 4.5 之后，他不再手写任何一行代码，每天能落 20 个 PR（拉取请求）。[^1] [^4]

在他看来，编程这件事正在被“解决”。未来的“软件工程师”这个头衔可能会慢慢消失，取而代之的是 Builder（构建者）或者 Product Manager（产品经理）。写代码将从一种“核心能力”降级为像“用计算器算数”一样的“默认能力”。

“我们会看到软件工程师的工作不再只是写代码：他们还要写 Spec（规格说明）、要跟用户沟通。甚至财务、设计师、PM 都在写代码。” Boris 调侃道。[^1]

更有趣的是，Boris 提出了一个**“代码保质期”**的概念。在 AI 时代，代码的 shelf life（货架期）可能只有几个月。Claude Code 自己的代码库就在不断被重写，六个月前的代码几乎全消失了。[^1] [^2] 这种“重构即常态”的节奏，意味着你辛辛苦苦写的优雅架构，在下一代模型面前可能就是一堆没用的“脚手架”。

Plan Mode要退休？多Agent开始“群聊”干活了

很多 Claude Code 的死忠粉最爱的是它的 Plan Mode（规划模式），让 AI 先想好再动手。但 Boris 却预言：Plan Mode 的寿命可能只剩一个月了。 [^2]

随着模型能力的指数级增长，AI 正在变得越来越“稳”。未来的体验将是“一发入魂”：你丢个 Prompt，AI 自己进 Plan Mode，想清楚直接做完。

更硬核的是 Agent Topologies（Agent 拓扑结构）。现在的开发不再是单一 Agent 的表演，而是“群聊干活”。Boris 举例说，Anthropic 的某个功能就是由一个 Agent 集群在一个周末“跑出来”的：

  1. Mama Claude（主 Agent） 负责领任务、拆解需求。
  2. 它在任务板上建一堆 Ticket，然后 Spawn（孵化） 出一堆 Sub-agents（子智能体）。
  3. 这些子智能体各司其职，有的看日志，有的改代码，甚至会通过浏览器查资料。[^1] [^2]

这种“并行研究”的能力，让 Debug 变得像是在指挥一支特种部队。Boris 提到，曾有工程师让 Claude 查内存泄漏，AI 居然自己写了个分析工具，比人类翻 Heap Dump 快得多。

别和模型对赌：保持“新手心态”是最后的倔强

对于身处 AI 洪流中的开发者，Boris 给出了一个听起来有点“玄学”但极具杀伤力的建议：保持新手心态（Beginner Mindset）。

在旧时代，资深工程师靠“强观点”和“老经验”拿高薪；但在 AI 时代，这些经验可能成了负资产。

“不要为‘今天的模型’做产品，要为‘六个月后的模型’做产品。” [^1] [^4]

这也是 Boris 的核心产品哲学：Never bet against the model（永远不要和模型对赌）。 很多你费劲心机搭的工程化工具（Scaffolding），可能新模型一发布就直接“全家桶自带”了。你以为你在筑墙，其实是在制造技术债。

访谈最后，Boris 提到连火星车（Perseverance）的航线规划都有 Claude Code 的参与。[^1] 这也许预示着，当编程变成一种通用资源，人类的创造力将被释放到星辰大海。

至于那些还在纠结要不要转行的同学，Boris 的招聘秘籍或许能给你启发：他最喜欢问的问题是“给我一个你曾经错了的例子”。在这个日新月异的时代，承认自己会出错、能丢掉旧包袱，比掌握哪门编程语言重要得多。[^1]
