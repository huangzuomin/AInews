钉钉这次“疯”得很清醒：发布 Agent OS，还给 AI 准备了“物理断电键”？

温故智新AIGC实验室

TL;DR：

钉钉这次直接把“办公软件”的皮撕了，想当 AI 时代的 Windows。不仅推出了专给 AI 住的操作系统 Agent OS，还配了个能“物理断电”的硬件，甚至放狠话：没效果不收钱，主打一个“AI 时代的判官”。

自打今年 3 月无招（陈航）回归钉钉后，这位“钉钉之父”似乎就进入了一种极其兴奋的“无人之境”。在 12 月 23 日的发布会上，他直言自己每天早起都特别兴奋，因为“时代要变了”。[1]

这种兴奋并非空穴来风。在不到四个月的时间里，钉钉从 1.0 版本“蕨”飞速迭代到了 1.1 版本“木兰”。[4] 如果说以前的钉钉是一个大家用来打卡、沟通、传文件的“超级 App”，那现在的钉钉正试图把自己变成一个 AI 时代的“底座”——一个专门给 AI Agent（智能体）跑的操作系统：Agent OS。

技术大揭秘：当 AI 也有了“宿舍”和“身体”

以前我们谈论 AI，大多是在聊某个大模型多聪明。但钉钉觉得，光有“大脑”不行，你还得有“宿舍”和“身体”。

这次发布的 Enterprise Agent OS，就是专门为 Agent 打造的“操作系统”。它向下兼容各种多模态大模型，向上开放各种原子能力（比如 AI 表格、语音、视觉等）。[1] 简单来说，以前开发一个 AI 助理像是在荒地里盖房子，现在钉钉把地基、水电、网线都铺好了，你只需要拎包入住。

为了让这群 Agent 能干活，钉钉还派出了两个“管家”：

  • DEAP 平台：让企业不用雇昂贵的 AI 算法工程师，零代码就能捏出自己的专属 Agent。
  • “悟空”总管：这就是个“智能协作中枢”。你一句话，“悟空”就能指挥一众 Agent 去约日程、筛简历、做 PPT。

更有意思的是，钉钉还发布了一个叫 DingTalk Real 的硬件终端。[2]

“这个终端是为 Agent 而生的，而不再是为我们人而生。” —— 陈航 [1]

点评： 终于，AI 也有了自己的“实体工位”，人类开始给 AI 攒主机了。

这个 DingTalk Real 解决了 AI 落地最头疼的安全问题。它内置了过程监控，甚至还有一个紧急“拔电”功能。[1] 万一哪天 Agent 逻辑跑飞了或者“产生幻觉”乱发指令，人类可以物理断电，确保安全。这种“软硬兼施”的做法，确实很有无招当年的“疯劲”。

行业“地震”：谁在用 AI 偷偷“减负”？

钉钉这次不玩虚的，一口气甩出了 20 多款行业专属 Agent，覆盖了印刷、招聘、差旅、制造等一堆传统行业。[4]

拿印刷行业来说，中小企业以前设计个包装周期长得离谱。钉钉推出的“AI 印”Agent，能实现 20 倍的设计加速，半日内印刷交付。而在制造业，友成控股的订单处理原本需要 7 个人干活，引入订单 Agent 后，处理一个订单的成本降到了 5 分钱，耗时缩短到 1 分钟内，团队直接精简到 2 人。[1]

这种“暴力降本”背后，是钉钉商业模式的“降维打击”：按结果付费。

“我一问，包括我自己，服务不重要，价格最重要，价格便宜是王道。” —— 陈航谈中小企业需求 [1]

在 AI 助理市场，钉钉推行“商业可交付性”标准，确保 AI 的结果不是“差不多”，而是“必须能用”。如果 AI 没招到人、没谈成订单，企业就不用为此买单。这种玩法，直接把 AI 从“昂贵的玩具”变成了“实惠的工具”。

未来预测：下一个“风口”是 AI 劳动力？

从 1995 年上大学到 1999 年毕业，无招感慨过去的产品大多是美国定义的（Windows、Mac、Android），但现在，AI 给中国企业级市场留了一个反超的窗口。[1]

钉钉的“野心”已经昭然若揭：它不想只做一个协同软件，它想成为 AI 时代的 Linux 或 Windows，构建一个“万千智能，繁花一体”的生态。[4]

未来的办公室里，可能一半的“员工”都是住在 Agent OS 里的智能体。而你，不再是那个在表格和流程里打转的“表格侠”，而是指挥成百上千个 Agent 的“战地指挥官”。

至于那些被 AI 替代掉的重复劳动？或许正如无招所说，AI 的价值是把人解放出来，去关注更有价值的创新。[1] 当然，前提是你要先学会如何和这些住在钉钉里的“悟空”们打交道。
