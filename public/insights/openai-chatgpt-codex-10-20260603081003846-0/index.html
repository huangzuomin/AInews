OpenAI 又掀桌了！ChatGPT 和 Codex 官宣“领证”，10亿人喜提万能打工分身

兄弟们，OpenAI 又把牌桌掀了！1

就在今天（6月3日），一场名为 “Intelligence at Work” 的线上发布会，产品负责人 Alexander Embiricos 上来就放了个大招：未来几周，我们要把 Codex 装进 ChatGPT！

好家伙，两个加起来坐拥近10亿用户的 AI，终于要“领证”了。一个主攻思考、写作、创作；一个负责“真正动手干活”——以前你老是纠结“这活儿到底用哪个APP”，现在 OpenAI 直接帮你终结选择题：别选了，全给你。

什么？你说你还没用 Codex？

去年 Codex 还是程序员的“高级玩具”，写代码一飞冲天。但今年画风变了——最新报告显示，Codex 周活狂飙6倍突破500万，其中知识工作者占比已达20%，增速是开发者的3倍。2

说白了，现在用 Codex 最多的根本不是码农，而是每天跟 Excel、PPT、Slack 打架的打工人。

你以为是写代码驱动增长？不，是“通用办公”在偷偷上分。年初 Claude Code 已经走红了一遍，如今 Codex 正在复刻那个剧本——只是这次，OpenAI 的野心明显更大。

Codex 三大杀器：插件、批注、一键变网站

为了把“智能上班”做到极致，OpenAI 一口气扔出了三枚炸弹：

1. Agent 插件：六个“AI同事”入职，自带110项技能 首批上线六个角色插件：数据分析、创意制作、销售、产品设计、公开市场投资、投行。合计接入62个企业应用，包括 Salesforce、Snowflake、Figma、Canva……你还在苦哈哈地手动对齐数据？人家一句话就让 Agent 写 SQL、画图表、一键转 deck。更骚的是，公司里任何人都能试任何岗位的活——能力的边界，被 Agent 悄悄抹平了。

Alexander 现场演示：对着 Codex 说“最近取消订阅量飙升，查一下怎么回事”，几分钟后一份完整报告就出来了；紧接着改了个图表样式，顺手让 Agent 把整份报告变成了一套幻灯片。1

2. Annotations（批注）：指哪改哪，拒绝推倒重来 想改报告里的一小块？以前你得把整段需求重新敲一遍，现在只需要选中，然后告诉它改什么。Agent 只动你圈的那块，其余不动。这个功能原先只在代码和网页里能用，现在扩展到了文档、表格和幻灯片。“哪里不爽点哪里”，协作模式从“你干完我再改”变成了“你干着我随手调”。

3. Sites：一句话，造一个能分享的App 这才是最具“未来感”的一击。一句提示词，Codex 就能把任何产出变成一个可交互的网页应用，生成 URL 发给 workspace 里的人。财务预测 → 全公司实时看的业务仪表盘；产品计划 → 团队可一起评审的可运行原型；发布材料 → 随时更新的“活的中枢”。更狠的是，做出来的 Site 不是静态的——Agent 带着全部业务上下文，自主地、持续地维护它。1

GPT-5.5：这个“省钱狂魔”才是幕后功臣

撑起这所有疯狂输出的底层引擎，是极度“精打细算”的 GPT-5.5。

Alexander 半开玩笑地说：“GPT-5.5 最恨的一件事，就是浪费 token。” 每个 token 里塞进的智能比任何前沿模型都多，但拿到同样质量的成品，token 只用 1/3。3

什么叫“智能足够便宜”？就是它能渗透进每一个工作角落。这才是“超级应用”敢喊出无处不在的底气。

暗流涌动：OpenAI 正面硬刚 Anthropic

这场发布会放在更大的棋盘上，是 AI 双雄争夺“工作层”的最新回合。年初 Anthropic 的 Claude Code 一战封神，紧接着上线 Cowork 抢到了先手。而今天 Codex 的三大升级，几乎逐条对标 Cowork。

但 OpenAI 的杀手锏不在产品层，而在分发层。把 Codex 揉进 ChatGPT，意味着近 10 亿周活用户一夜之间获得 Agent 能力。 Cowork 需要用户主动下载桌面端，Codex 选择“你打开 ChatGPT 就已经在用了”。2

同一天，OpenAI Frontier 正式上线 AWS Bedrock，全线模型杀入 Anthropic 经营多年的地盘。当“默认”本身就是护城河时，用户根本不需要做选择。

所以，这到底意味着什么？

能不能掰过来另说。但至少从今天起，“你用不用 AI 工作”已经变成了“你用谁家的 AI 工作”。
