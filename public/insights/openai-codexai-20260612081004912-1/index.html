OpenAI 的 Codex 不再局限于早期的代码生成，其近期重大更新标志着它正式迈入“智能体（Agent）”阶段。

  • Computer Use（计算机使用）：这是 Codex 的核心壁垒。它通过视觉识别直接操控鼠标与键盘，完成点击、输入等操作，能够解决传统 API 无法触及的跨应用协作场景，如从飞书摘录信息并填入 Notion。
  • Goal-Oriented Automation（目标导向自动化）：通过 /goal 指令，Codex 可以处理跨度长、步骤多的任务，如端到端的科研实验或大型项目重构。它具备自主规划、记录日志（.logs）以及根据执行结果自我迭代的能力。
  • 多插件生态与技能集成：支持 Playwright 进行网页 UI 验证、PptxGenJS 处理文档生成、以及 ImageGen 生成视觉素材。这种技能矩阵使其能够跨领域完成从原型设计到项目部署的闭环。

使用指南：最佳实践与注意事项

为了高效利用 Codex，建议遵循以下实践：

  1. 明确目标结构：不要给出一句笼统的提示词，应编写一份包含技术栈、胜负条件、测试方案的 PLAN.md。
  2. 利用“记忆功能”：Codex 能够记住个人偏好和过往纠错记录，建议在初期多进行少量的人工指令修正，后期将显著提升其产出符合度的效率。
  3. 注意权限安全：由于 Computer Use 具备操控电脑的能力，请避免在 Codex 运行时操作包含敏感金融或隐私信息的窗口。
