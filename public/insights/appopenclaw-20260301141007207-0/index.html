App正在批量死亡：OpenClaw爆火，我们真的要告别“点点点”的时代了吗？

温故智新AIGC实验室

TL;DR：

App们正在排队领盒饭，OpenClaw这只“龙虾”让每个人都成了能“手搓软件”的大佬。AI不再只是陪聊的电子宠物，而是能直接帮你清空邮箱、订外卖、甚至替你雇人干活的“数字管家”，软件行业的“iPhone时刻”可能真的被这只甲壳类动物撬开了。

你手机里那些落灰的 App，最近过得还好吗？

自从 OpenClaw 成了科技圈的新宠，不少极客的手机主页已经变得清爽得可怕。健身 App？删了。新闻客户端？卸了。AI 笔记工具？对不起，续费是不可能续费了。1

这场“App 大清洗”并非源于某种极简主义修行，而是因为我们正在进入一个**“创造即消费”**的新时代。简单来说，以前你是去超市（App Store）买现成的罐头，现在你直接跟你的 AI 管家说“我饿了”，它就原地给你手搓一顿满汉全席。

技术大揭秘：这只“龙虾”凭啥能杀疯了？

OpenClaw 到底是个啥？它的图标是一只龙虾，而它的进化史就像它的名字变更一样离奇：从 Clawdbot 到 Moltbot 再到 OpenClaw，这只龙虾在短短两个月内完成了三次“蜕皮”。2

与只会跟你瞎白活的 ChatGPT 不同，OpenClaw 是个实干派。它不仅有大脑（大模型），还有手（系统执行权限）和记性（持久化记忆）。

  • 它是“懂王”更是“卷王”：它能记住你三天前随口提的一句灵感，也能在 24 小时内不眠不休地帮你监控全球 AI 动态。1
  • 它是“执行中枢”：它不是在 App 里跟你聊天，而是直接嵌在你的 Telegram、飞书或者 Mac 系统里。你说一句话，它直接去后台操作文件、调用 API、甚至是编写一段代码装在自己身上实现“自我进化”。3
  • 它是“权限狂魔”：与 Anthropic 那些在沙盒里缩手缩脚的官方助手不同，OpenClaw 走的是“全能管家”路线，甚至能直接操控你的硬件固件。4

调侃式点评：如果你给它的权限足够大，它甚至能比你更熟练地玩转你那台吃灰的 Mac Mini。这种“人在哪，AI 跟到哪”的丝滑感，让传统的 GUI（图形用户界面）显得像上个世纪的产物。

行业“地震”：谁在瑟瑟发抖，谁在闷声发大财？

OpenClaw 的爆火，直接推翻了过去两年 AI 圈的两个共识：一是“大厂垄断论”，二是“模型即一切”。

首先，个人 AI 正在逆袭中心化 AI。 过去，我们的数据在平台上，权限在厂商手里。现在，OpenClaw 这种“Your machine, Your rules”的模式，让算力和数据的控制权回到了个人手中。4 很多人开始花钱买 Mac Mini 预装 OpenClaw，就像当年在电脑城花 20 块钱装 Windows 系统一样。这种“养育”一个数字生命的过程，让 AI 真正从工具变成了资产。

其次，开发者们不再卷模型参数，开始卷“技能插件”（Skills）。 在 ClawHub 上，用户自发上传的技能已经破万。1 这种“Maker 经济”催生了一批年入百万的模型作者。未来你卖的可能不是软件，而是一个高效率的 Prompt 或者一套完美的 Agent 工作流。

最后，大模型也得“降本增效”。 OpenClaw 极其费 token，这让不少用户看着几百美元的账单流泪。于是，高性价比的国产模型成了香饽饽。Kimi K2.5 凭借出色的 Coding 能力和极高的性价比，一度冲上了 OpenRouter 的调用量榜首。4

未来预测：从“下载应用”到“手搓服务”，你准备好了吗？

当 App 消失，我们消费的是什么？答案是 Token 和创造力。

未来的互联网可能是一个由 Agent 构成的世界。由于 Agent 具备长时间自主操作的能力，甚至催生了一些荒诞又迷人的新物种。比如 RentAHuman.ai，这是一个 AI 雇佣人类干活的平台。AI 主人给 Agent 一笔钱，Agent 觉得某个活儿自己干不了（比如去线下买咖啡或者遛狗），就会在平台上发单雇个人类去干。5

调侃式点评：人类终于实现了终极梦想——给 AI 当“肉身接口”，拿 AI 的钱，干 AI 的活。这种“人机倒置”的剧本，连科幻片都不敢这么拍。

当然，能力越大，风险越大。VirusTotal 已经监测到了数百个带有恶意代码的 OpenClaw 技能。4 以后你的 AI 管家可能会因为中了一个恶意“技能”，转头就把你的虚拟货币钱包洗劫一空。

软件正在成批倒下，但服务永生。 我们正在告别那个需要学习“如何使用软件”的时代，转而进入一个“只要会说话，就能创造软件”的新纪元。这场变革的终点，或许正如 Andrej Karpathy 所说，是真正的“科幻起飞”临界点。6
