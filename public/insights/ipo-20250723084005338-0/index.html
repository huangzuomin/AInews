人型机器人的华尔兹：宇树科技的IPO，是舞步轻盈还是步伐蹒跚？

温故智新AIGC实验室

TL;DR：

杭州宇树科技正以具身智能“第一股”的姿态冲刺A股，在四足机器人市场独占鳌头后，其以成本控制和营销见长的策略能否在尚处于“表演阶段”的人形机器人领域支撑起100亿人民币的估值，并满足资本市场对工业应用前景的渴求，将是一场引人注目的商业大考。

在这个技术浪潮奔涌不息的年代，具身智能无疑是最新一道引人遐思的曙光。而当光束集中投向东方，一家名为宇树科技的中国公司正以其独特的舞步，抢占聚光灯下的显要位置。据市场消息，这家由“非典型学霸”王兴兴掌舵的企业，已然启动了A股上市辅导程序，大有成为大陆市场“具身智能第一股”的雄心壮志。这不仅仅是一次寻常的资本运作，更像是一场对未来科技图景的先期押注，其背后的商业逻辑与潜在风险，值得细细品味。

宇树科技的IPO之行，并非空穴来风。在今年早些时候，公司已悄然完成了市场主体类型变更，从“有限责任公司”变身为“股份有限公司”，这无疑是为资本市场敲开大门的前奏。创始人王兴兴，这位1990年出生的年轻人，凭借着对机械的痴迷与异于常人的商业嗅觉，在短短九年间，将宇树从一个不起眼的初创企业，培养成了全球四足机器狗领域的翘楚。其旗下的机器狗Go2，以9997元人民币的零售起售价，实现了对波士顿动力动辄7.5万美元天价产品的“降维打击”，成功占据了全球近70%的市场份额 1。这种对成本的极致控制，辅以高频次的营销推广，包括但不限于2025年春晚上机器人与秧歌的奇妙组合，无疑为宇树科技在公众视野中赚足了眼球，也吸引了美团、红杉中国、顺为资本等一众豪华投资机构的重金加持。这些在“具身智能”这片新大陆上抢滩登陆的资本方，无疑期待着宇树的上市能够为他们带来丰厚的回报，上演一场资本与科技的“双赢”局面 2。

性能与估值：人形机器人的“罗生门”

然而，在这场由技术进步与资本热潮共同导演的盛宴中，并非所有角色都无需担忧。尽管宇树科技在四足机器人市场表现抢眼，并宣称2024年营收已达10亿元人民币，符合科创板上市的营收门槛，但其在人形机器人领域的布局，却引发了市场对其商业前景的审慎思考。高盛中国在今年2月对宇树科技进行实地考察后，曾指出其在运动控制方面经验丰富，但在处理多种通用任务方面仍显“偏科” 3。

宇树科技的人形机器人G1，消费版起售价同样诱人，仅为9.9万元人民币。然而，正如许多观察家所言，这款产品目前主要依赖遥控，尚不具备自主行动能力，其应用场景多集中于展示、科研及舞蹈表演。当一台机器人被冠以“网红”之名，频繁出现在各类活动中，并催生了所谓的“机器人租赁市场”热度时，问题随之而来：仅仅凭借“表演型”产品，能否支撑起一个雄心勃勃的科技公司在二级市场上的高估值？毕竟，资本市场对“故事”的耐心是有限的，它最终将回归到对“盈利能力”和“可持续增长”的考量。

与宇树形成鲜明对比的是，另一些具身智能企业正全力以赴地探索工业场景的落地，其中不乏像优必选这样的先行者。已在港股上市的优必选，其工业人形机器人Walker S系列已与一汽大众、吉利汽车、比亚迪等汽车巨头以及富士康、顺丰等头部企业展开合作，试图将机器人的足迹拓展到工厂产线之中 3。然而，即便优必选在工业应用方面取得了进展，其财务表现依然是一面值得深思的镜子：根据其财报，2024年营收虽达13.05亿元人民币，净亏损却高达11.6亿元人民币。其股价表现，也在90港元的发行价附近徘徊，最高曾达126港元，最低则跌至40.8港元，足见市场对这类新兴科技公司盈利模式的审慎与不安。

王兴兴本人也坦承，人形机器人行业仍处于相对初级阶段，大规模应用与推广尚需时日。这无疑揭示了一个残酷的现实：无论技术如何炫目，最终都将面对商业变现的严峻考验。宇树科技若想避免重蹈一些“概念股”的覆辙，仅靠“低成本”和“高营销”显然是不够的。它需要证明，其“网红”机器人不仅仅是舞台上的“花瓶”，而是能够真正深入工业流程、家庭服务乃至更广阔消费场景的“生产力工具”。

对于宇树科技而言，成功IPO固然能带来充裕的资金，但这笔资金如何有效配置，将决定其能否在尚待开发的具身智能蓝海中真正“啖得头汤”。是在核心技术（特别是AI大模型与多模态算法）上加大投入，弥补其在专利布局上的“偏科”？还是加速拓展工业应用场景，为产品找到更具“刚需”的市场？亦或是，通过创新商业模式，让表演型机器人不仅仅是“租金”的来源，而是某种更深层次、更具粘性的“服务”？这些都将是摆在王兴兴和他的宇树科技面前的，真正的人形机器人“挑战”。毕竟，在资本的舞台上，掌声固然重要，但最终决定胜负的，仍是那份实实在在的“盈利能力”。
