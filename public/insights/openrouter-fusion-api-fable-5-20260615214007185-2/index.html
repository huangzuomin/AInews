白月光下线，平替组团杀疯了：OpenRouter Fusion API 让多模型“开会”平替 Fable 5

温故智新AIGC实验室

TL;DR：

Fable 5 被禁后，OpenRouter 带着 Fusion API 闪亮登场，用“多模型群殴”战术，以一半成本打出了接近 Fable 5 的分数。与此同时，一场亚马逊举报、政府出手的抓马大戏也被扒了出来——原来最狠的刀，来自金主爸爸。

白月光下线，全网开始找平替

Fable 5 被停用那个周末，AI 圈直接炸了锅。开发者哀嚎、段子手狂欢、就连定好的开发者大会都临时把主角换成了 Opus 4.8——这感觉，像极了追剧追到一半主角突然被编剧写死。

悼念帖还没刷完，OpenRouter 就带着 Fusion API 杀了出来，文案相当嚣张：“市面上最聪明的拼盘模型，智力接近 Fable，价格只要一半。”1 这条推文阅读量飙到 518.5 万，网友们一边擦眼泪一边点开了试用链接。

AI 也讲究群殴战术？技术拆解来了

Fusion 本质上是一套「多模型协作」机制，跟传统单模型单打独斗完全不同。

它把同一个问题同时扔给多个模型独立研究，再让一个“裁判模型”交叉评审，最后由主模型综合产出最终答案。整个流程分为三步：

  1. 并行研究：多个参评模型（Panel Models）各自调用工具、搜索资料、生成答案；
  2. 交叉评审：裁判模型（Judge Model）对比所有答案，抓共识、找分歧、揪错误、补遗漏；
  3. 生成结论：主模型整合评审结果，输出最终回答。

简单说就是：一个人干不过一群人开会。而且这个“开会”还不是简单投票，而是深度交叉验证——有点像学霸小组成员各自刷题，然后对答案查漏补缺。

实测数据：半价打出 64.7%，只比 Fable 5 差 0.6 个百分点

OpenRouter 拿 Perplexity AI 发布的 DRACO 基准做了测试——100 道深度研究任务，涵盖学术、金融、法律、医疗、技术等 10 个领域，每道题 40 条评分标准，还有负分项（比如给出危险医疗建议直接扣分）。这套测试的含金量，比那些“你问我答”的排行榜硬核多了。

结果很有意思：

  • 最佳组合（Gemini 3 Flash + Kimi K2.6 + DeepSeek V4 Pro，由 Opus 4.8 裁判）拿到 64.7%；
  • Fable 5 单独作战：65.3%；
  • GPT-5.5 单独：60.0%；
  • Opus 4.8 单独：58.8%。

也就是说，用便宜模型组队打出的成绩，距离目前最强单模型只差不到 1 个百分点，价格却只要一半。2

更离谱的是，OpenRouter 还做了个对照组：让两个 Opus 4.8 组队，仍由 Opus 4.8 当裁判——一模一样的模型，结果成绩从 58.8% 飙到 65.5%，直接反超 Fable 5。仅仅多了一次独立思考和综合，分数就提了 6.7 个百分点。

OpenRouter 分析，大约 四分之三的提升来自综合环节本身，只有四分之一来自模型之间的多样性。同一个模型面对同一问题，也可能走出不同推理路径——调不同工具、搜不同资料、关注不同细节，最后凑一起就能发现遗漏、修正错误。这逻辑，像极了两个人做同一道数学题，各自解法不同，一核对就发现谁算错了。

DeepSeek V4 Pro：闷声发大财的“隐藏版大佬”

测试里还有一个彩蛋：DeepSeek V4 Pro 单独跑了 60.3%，几乎和 GPT-5.5（60.0%）、Opus 4.8（58.8%）平起平坐。而且它还是个“性价比选手”，让 OpenRouter 直呼意外。

不过 OpenRouter 也坦白：不同裁判模型可能带来 10～25 分的绝对分数波动，而且 Fable 5 因为内容过滤只完成了 93 题，所以对比并非完全公平。但相对排名通常稳定，“多模型开会”的效果已经实锤。

Fable 被禁的抓马剧情：金主爸爸亲手递刀

Fusion 爆火的前提是 Fable 的突然下线。而背后的故事，比技术本身还精彩。

据 The Information 报道，亚马逊 CEO 安迪·贾西亲自把 Fable 5 的“越狱”漏洞捅到了美国政府那里。亚马逊的测试人员发现，只要用特定方法绕过安全护栏，Fable 5 就能回答网络攻击相关问题。贾西把这份测试结果递给了相关高层。3

最魔幻的是：亚马逊从 2023 年起已经累计向 Anthropic 砸了 130 亿美元，还计划再追加 200 亿。最大金主，亲手把被投公司的旗舰模型送进了监管视野。

美国国家网络事务总监随后召开紧急会议，直接祭出 出口管制。Anthropic 的 Dario Amodei 拒绝修复这个“轻微发现”的漏洞，于是模型被全球限制访问。甚至 Anthropic 内部持外国国籍的员工（比如 Andrej Karpathy）也无法使用自家最新模型。4

接近美国政府的人士透露，这次出口管制大概率不会扩散到其他 AI 公司——更像是针对 Anthropic 的“精准狙杀”。

一句话「复活」Fable？别天真了

Fable 被禁后，网上流传出一份所谓的“Fable 5 系统提示词”。开发者 Jamieson O'Reilly 做了个实验：把这段提示词塞给 Opus 4.8，让它做“现代苹果风格落地页”，结果和原生 Opus 4.8 的输出确实风格迥异。5

他兴奋地发推：“我是不是解锁了 claude-fable-5-lite？”

可惜，提示词只能模仿姿态和语气，补不齐模型在训练、推理、工具使用、长上下文规划上的真实能力。这就像给普通演员穿上超级英雄的紧身衣，他还是打不过反派。

另一边，国内模型也在借势发声。智谱宣布 GLM-5.2 向全量用户开放，并喊话：“前沿智能不该只属于少数人，也不该被少数规则随时收回。”6

白月光之所以是白月光，往往是因为它已经离场。 但前沿智能未必只能寄托在一个模型身上。哪怕最亮的那盏灯被关掉，桌上还有很多盏小灯，把它们摆对位置，照样能照亮前路。
