养一只“小龙虾”AI：时薪70比我还贵，但我被它PUA得很爽

温故智新AIGC实验室

TL;DR：

最近科技圈全在卷“养虾”，名为 OpenClaw 的 AI Agent 涨粉速度快到连 Linux 看了都直呼内行。虽然它是能代操电脑的“电子牛马”，但安装报错能让你想撞墙，Token 烧起来时薪比打工人还贵。

这几周，如果你还没听说过“小龙虾”，那你可能真的离 AI 圈的 FOMO（社交恐惧症）中心太远了。

从 Claude Sonnet 4.6 的惊艳亮相，到 GPT-5.4 的突然袭击，AI 模型的迭代速度已经让打工人的脑干开始发麻。但真正让马化腾（Pony）都在朋友圈感慨“没想到会这么火”的，却是一个叫 OpenClaw（绰号“小龙虾”）的开源项目 1。

在 GitHub 上，这只红色的小龙虾正在以一种“拔地而起”的姿态狂刷 Star 数，甚至已经把 React 和 Linux 两个老大哥甩在了身后 1。大家不再满足于只会“动嘴”聊天的对话机器人，而是开始疯狂追求能真正“动手”干活的 AI Agent（智能体）。

电子牛马进场：这只“小龙虾”到底什么来头？

简单来说，OpenClaw 不只是一个对话框，它是一个拥有高权限的数字员工。它能直接操作你的浏览器、管理文件、甚至在你的服务器上执行命令 2。如果说以前的 AI 是坐在副驾指挥的“键盘侠”，那 OpenClaw 就是那个直接抢过方向盘、还能顺便帮你把外卖给点了的代驾。

现在的行业共识已经从单纯的“对话”转向了 Agent（智能体）+ Workflow（工作流）。你可以通过“扣子”这类工具串联多个大模型，而 OpenClaw 就是那只能够深入系统、帮你抓取数据、整理报表的强力触手。

有编辑为了“偷懒”打游戏，折腾到凌晨四点，终于给这只小龙虾装上了插件 1。效果确实惊人：五分钟内，它就能从反爬虫严密的网站里，把本周国内游戏畅销榜 Top 10 的 App ID、发行商信息整理得整整齐齐，顺便还能把最近三天的行业热门新闻汇总成一份“阅读简报”。

养宠日记：它是生产力工具，还是高贵的“吞金兽”？

别看小龙虾干活利索，想要把它“养”大，门槛可一点不低。

首先是安装报错。虽然网上的“保姆级教程”满天飞，但大多数新手一上来就会被一堆代码报错整得头皮发麻 13。很多所谓的教程最后都指向了“卖课”，让人不禁怀疑，到底是 AI 在进化，还是镰刀在进化？

这时候，聪明的极客已经学会了**“用 AI PUA AI”**：先装一个简单的 Agent（比如 Codex），然后把 OpenClaw 的文档甩给它，让它化身为勤勤恳恳的“电子包工头”，去帮你在电脑里把这只小龙虾给搭起来 1。

但真正的“背刺”来自账单。养这只虾，你是要发工资的——也就是 Token 费用。

  • 计费陷阱：别看单价标着 1 美元/百万 Token 好像很便宜，但 Agent 运行起来，输入输出、工具调用、上下文缓存全都在烧钱 1。
  • 薪资倒挂：有博主实测，为了修复几个插件 Bug，二十分钟就烧掉了四百万 Token，折算下来时薪逼近 70 元人民币 1。

“看到它的时薪比我还高，我悬着的心终于死了——它不是来取代我的，它是来当我的‘高薪甲方’的。” 1

未来预测：它会抢了我们的饭碗吗？

虽然小龙虾目前还存在时效性差、偶尔“幻觉”、配置复杂等问题，但它最可怕的地方在于成长性。

通过官方的 Claw Hub，你可以给它安装各种“技能插件（Skills）”：比如让它学会自我复盘的 Self-Improving Agent，或者是帮你管理 Obsidian 笔记的整合包 43。现在的它更像是一个“养成系胚子”，你喂它什么，它就能长成什么样。

目前来看，OpenClaw 还是极客们的昂贵玩具。一个真正成熟的大众 Agent，应该是不需要懂 API、不需要看报错、不需要担心 Token 突然烧光，而是直接告诉它“我要干什么”，它就默默搞定一切。

虽然这只“小龙虾”现在的身价确实有点贵，但它预示了一个不可逆的未来：人与 AI 的协作，正在从“问答模式”全面切换到“托管模式”。哪怕它现在还没法完全取代你，但它已经强到了让你没法假装看不见的程度 1。

决定产品上限的仍然是人的判断力。至于那 70 块钱的时薪……就当是给未来数字员工交的社保吧。
