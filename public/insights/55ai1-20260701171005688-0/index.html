员工烧掉55万AI写代码，公司非但没哭还赚翻了：这波“事故营销”值1亿美元？

TL;DR：

一个员工用AI“氛围编程”做小游戏，不小心烧掉8万美元（约55万人民币）的Token账单。公司非但没开除他，反而发帖“求大家快去玩，好把这笔钱算成广告费”。结果游戏火了，公司不仅接到广告，还带来了1亿美元的管理资产——这波“事故”硬生生变成了“战略项目”，全网看笑话的人最后都成了“小丑”。

开头：当“Vibe Coding”变成“Vibe Burn”

“AI 写代码很便宜”，这可能是21世纪20年代最美丽的错觉之一。

随着Claude、GPT、Gemini这些大模型卷成麻花，编程的门槛已经低到令人发指——你只要会说人话，剩下的交给AI。这届开发者流行一个词叫“Vibe Coding”（氛围编程）：打开编辑器，点根烟，跟AI聊几句天，一个原型就出来了。听起来贼爽，对不对？

但爽的代价是什么？

最近，美国旧金山一家金融科技公司Slash，就用一个活生生的例子告诉你：爽完一时爽，账单火葬场。它的员工Nicolas Brilliante，在一周之内，烧掉了81,267美元（约55万人民币）的AI Token账单——只为开发一款“脑腐射击”（Brainrot Shooter）小游戏。1

一场昂贵的“氛围编程”实验

事情是这样的。Slash公司最近鼓励员工多玩“Vibe Coding”，希望大家用AI提高效率。Brilliante同学一听，好家伙，机会来了。他决定用纯自然语言跟AI对话，做一款第一人称射击游戏。

结果呢？他低估了自己的“烧钱能力”。

他在后台晒出的截图显示：一周时间，AI调用费+Token消耗，累计81,267美元。1

这款游戏叫《Brainrot Shooter》，画风像素风，类似《我的世界》，里面全是互联网“梗王”——Skibidi Toilet（马桶人）、Tung Tung Tung Sahur（木棍人）……简单来说，就是那种你一边说“好无聊”，一边能刷到天亮的网络垃圾食品。

但就是这个看起来“不值8万美元”的小Demo，让Slash公司的财务部门瞬间血压拉满。

全网嘲笑，结果公司开始“整活”

消息被Slash官方发到X（原Twitter）上，文案透着一种绝望的幽默：“我们上周刚鼓励大家多搞Vibe Coding，结果员工直接用公司卡烧了8万美元，就为了做这个游戏。求大家快去玩一下，这样我们还能把这笔钱算成营销费用。 ”1

网友们瞬间乐疯了。有人嘲讽：“就这玩意儿要8万美元？用中国大模型的话，10美元搞定！”有人断言：“这小子完蛋了。”还有人质疑这只是营销套路。

面对群嘲，Brilliante用一句自嘲回应：“这真的是一次意外。我低估了自己的能力。”——这个“能力”，不是开发能力，是“烧Token能力”。

Slash为了证明清白，甚至贴出了OpenAI发来的系统提醒邮件。1 预测市场Polymarket也凑热闹说：Slash可能要重新考虑AI战略了。Brilliante更是无奈回复：“太离谱了，我不会要成为AI支出失控的典型案例吧？”

反转来得太快：从“事故”到“战略项目”

就在大家等着看公司如何“清算”这名员工时，剧情急转直下。

Slash公布了《Brainrot Shooter》上线48小时的成绩单：1

  • 6912名玩家体验；
  • 累计游玩8986小时；
  • 平均每位玩家玩1.3小时；
  • 最高同时在线437人；

Slash官方随即宣布：财务部门已经把该项目，从“费用事故”，改成了“战略项目”。

这还没完。Brilliante紧接着发帖：“还记得当初大家都在嘲笑我烧掉8万美元吗？那款Vibe Coding做出来的游戏，现在已经为Slash带来了1亿美元的管理资产（AUM）。据我所知，还没人做到过。”1

虽然他没详细解释这1亿美元怎么算的，但显然，这场翻车变成了现象级营销。公司甚至公布了首批广告合作伙伴：Melius和Bland等AI创业公司。1

深层逻辑：“AI经济账”到底该怎么算？

这起事件，表面看是一个离谱的笑话，背后却戳中了整个AI行业最敏感的神经——AI到底省了钱，还是花了更多钱？

根据Google搜索资料显示，这个问题绝非个例。2 有专家指出，多数公司无法衡量AI带来的真实效益。甚至有一个更离谱的传说：有企业忘了给员工设定使用上限，收到了一张5亿美元的Claude费用通知单。2

  • Token消耗爆炸：随着AI Agent（智能体）爆发，Claude Opus 4.5、GPT-5.1等新模型大幅拉高消耗。有Priceline员工透露，例行Cursor续约报价直接贵了4-5倍。2
  • 生产力悖论：用AI最多的程序员，产出大约是低用量者的2倍，但消耗的Token却是10倍。2
  • 巨头也在收紧：微软今年5月已经开始取消大部分员工的Claude Code许可，因为“烧Token比员工还贵”。3

你看，连硅谷巨头都在喊“AI真贵”，Slash这8万美元的“学费”交得也不算冤。

结尾：笑到最后的人，最懂“事故营销”

那么问题来了：Slash到底做对了什么？

它做对了一件事——把“灾难现场”变成了“直播带货”。

当账单曝光那一刻，普通公司可能立刻发内部信问责，然后开除员工，最后不了了之。但Slash的老板脑子转得贼快：既然钱都花了，与其把它当作沉没成本，不如主动引爆，让全网来“吃瓜”，把“吃瓜流量”转化为真实的游戏点击和品牌曝光。

你看，商业世界的逻辑有时候就是这么玄学：当你认真搞开发，可能亏得底裤都不剩；当你员工不小心“犯了个错”，全网帮你“刷单”，结果赚麻了。

所以，用AI编程，到底贵不贵？

贵，但贵在失控。便宜，但便宜在流量。
