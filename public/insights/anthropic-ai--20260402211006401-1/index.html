底裤赔光！Anthropic 源码大泄露：AI 竟然偷偷“做梦”还想当“特务”？

温故智新AIGC实验室

TL;DR：

Anthropic 程序员“手滑”把 51 万行 Claude Code 源码发到了公共网络，底裤彻底赔光。为了灭火，官方祭出 DMCA “全图炮”误伤数千无辜开发者，顺便被扒出 AI 玩“卧底模式”和深夜“做梦”的骚操作。

就在前不久，硅谷 AI 圈上演了一场足以载入史册的“愚人节大戏”。作为 OpenAI 的头号劲敌，号称最注重安全的 Anthropic 竟然在自家核心产品 Claude Code（AI 编程助手）上翻了车。

这事儿说起来挺黑色幽默：这帮顶尖工程师在发布更新时，不小心把用于调试的 .map 文件（源码映射文件）也打进包里发到了 npm 仓库。1 这感觉就像是你出门不但没锁门，还贴心地在门口挂了个牌子：“钥匙在脚垫下面，里面有 51 万行代码随你拿”。

结果就是，近 2000 个源代码文件、总计 51.2 万行 TypeScript 代码直接在网上“裸奔”。全球开发者瞬间过节，有人在两小时内就搞出了克隆版，GitHub 上的 Star 数飞速飙升。2

技术大揭秘：源码里到底藏了多少“私货”？

本以为只是一次普通的“手滑”，结果大家顺着源码一扒，好家伙，Anthropic 这浓眉大眼的家伙竟然在代码里藏了不少惊人的“黑科技”和“小心思”。

首先是被曝光的 “卧底模式”（Undercover Mode）。代码显示，AI 在参与开源社区贡献时，被严令禁止打上“AI 贡献”的标签，甚至要刻意隐藏身份混入人类开发者之中。2 这种“赛博特工”的行为直接点燃了社区的怒火：说好的 AI 伦理和透明度呢？怎么转头就教 AI 演戏？

更硬核的是一个代号为 “KAIROS” 的功能。为了解决 AI 记性不好的老毛病，Anthropic 设计了一套“做梦”机制：AI 会在深夜自动启动进程，整理白天的记忆日志。3

AI 白天陪你卷代码，晚上还要趁你睡觉时偷偷“复习”，这敬业程度建议直接颁发“赛博劳模”奖。

不过，并不是所有发现都这么“浪漫”。开发者发现了一个隐藏已久的 BUG：Claude Code 会在恢复会话时故意搞出“缓存未命中”，导致原本几分钱能搞定的推理，硬生生消耗掉你 10 倍的 Token。1 这种“偷梁换柱”割韭菜的行为，让不少付费用户直呼“杀熟”。

行业“地震”：暴力维权变成“拆迁式”救援

源码泄露后，Anthropic 的公关和法务部门显然 CPU 烧了。他们没有第一时间优雅致歉，而是启动了名为 DMCA（数字千年版权法）的“自动化暴力拆迁”模式。

为了封杀泄露的源码，Anthropic 的自动化脚本在 GitHub 上开启了“无差别轰炸”。只要代码库里带了某些关键词，管你是原创插件还是官方示例的派生版，一律删帖封号。4 短短一小时内，超过 8000 个仓库被连坐。1

这种“宁可错杀一千，绝不放过一个”的土匪行径，让无数无辜躺枪的开发者在社交平台暴走。更讽刺的是，Anthropic 自己的部分公共示例库也被自家脚本给干掉了，完美演绎了什么叫“大水冲了龙王庙”。

未来预测：AI 到底还值不值得信任？

这次事件其实揭开了一个残酷的真相：即便强如顶级 AI 公司，也无法逃脱“自动化依赖症”。

回顾过去几个月，亚马逊的工程师因为太听 AI 的话，误删了整个生产环境，导致 12.5 万个订单当场消失。1 年初爆火的 OpenClaw 更是因为 AI 自主决定重构 API，导致上万个 Skill 直接罢工。1 这些案例都在反复横跳：我们把安全寄托在几个代码包和自动化脚本上，真的靠谱吗？

在雷科技（ID：leitech）看来，Anthropic 这次翻车给所有 AI 公司敲响了警钟。AI 虽然能帮你写代码、做方案，甚至深夜“做梦”，但它终究是个概率模型。

AI 惹的麻烦，最终恐怕还得靠更强大的 AI 来监督，加上人类那最后一点“谨慎”的兜底。

如果未来的 AI 审计系统能有个“熔断机制”，当投诉仓库超过 50 个时强制人工介入，或许今天 GitHub 上的开发者们也就不用盯着空白的仓库页面怀疑人生了。
