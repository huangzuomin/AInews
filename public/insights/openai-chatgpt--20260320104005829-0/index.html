奥特曼真的急了！OpenAI 拉响“红色警报”：ChatGPT 也要玩“超级全家桶”？

温故智新AIGC实验室

TL;DR：

曾经的 AI 领头羊 OpenAI 被对手 Claude 偷了家，急得直接拉响“红色警报”。为了挽回流失的程序员和流量，奥特曼决定把散落在外的 ChatGPT、编程平台 Codex 和自家浏览器 Atlas 强行“捏成”一个桌面超级应用——打不过就合体，这波是为了年底上市叠最厚的甲。

如果你最近觉得 ChatGPT 好像没那么“香”了，别怀疑，全世界的网友可能都跟你想得一样。就在我们还沉浸在 Sora 到底什么时候能公测的幻觉里时，AI 界的“老大哥” OpenAI 却悄悄在内部搞起了一场前所未有的大重组。1

据《华尔街日报》等多方消息，OpenAI 正在策划一场近年来最大的“产品归拢”：要把 ChatGPT、专门搞编程的 Codex 以及那个一直活在传闻里的 Atlas 浏览器，分阶段塞进一个统一的桌面端**「超级应用（Superapp）」**里。2

简单来说，奥特曼不打算让你在网页标签页里跳来跳去了，他想直接接管你的电脑屏幕。

既然打不过，那就“合体”吧

为什么 OpenAI 突然不玩“遍地开花”那套了？答案很简单：被对手逼到了墙角。

根据 Similarweb 的数据，ChatGPT 的网页流量份额在一年内从 75.7% 自由落体到了 61.7%，而流失的份额几乎都被 Google 的 Gemini 收入囊中。1 更扎心的是，由前员工自立门户搞出来的 Anthropic，凭借着 Claude Code 和 Cowork 两个“编程神器”，在企业级市场精准爆破，直接击中了 OpenAI 的软肋。

“公司已经没有余力被‘支线任务’分散注意力了。”

OpenAI 应用 CEO Fidji Simo 在内部会议上直接将当前状态定性为**「红色警报（Code Red）」**。1 看着隔壁 Claude Code 年化收入突破 25 亿美元，而自家的 Codex 只有区区 10 亿美元，换谁谁都得急得跳脚。3

这次要推出的桌面超级应用，不仅是为了整合，更是为了赋予 AI “系统级权限”。以前的 ChatGPT 被困在浏览器的沙盒里，只能动嘴皮子；以后的超级应用能自动写代码、自动调试、自动打开浏览器查资料，甚至自动分析你本地的数据——这就是从“聊天机器人”向“智能体（Agent）”的终极跨越。

“全家桶”到底是生产力，还是“乱炖”？

不过，把这么多功能强行焊在一起，真的能 1+1>2 吗？

OpenAI 的逻辑很清晰：既然开发者喜欢用 Codex，普通人喜欢用 ChatGPT，那就把他们关进一个屋子里。1 但问题也随之而来：

  • 程序员要的是“极简主义”： 专注、低干扰、控制感。
  • 普通用户要的是“傻瓜化”： 顺畅、好用、随问随答。

这就好比你试图把一把瑞士军刀和一个美妆蛋焊在一起，虽然功能全了，但用起来可能哪哪都觉得咯手。有知情人士透露，由于 2023 年公司资源向 ChatGPT 严重倾斜，原有的 Codex 团队一度被拆散，导致现在只能靠“氪金”追赶——为了让开发者回心转意，OpenAI 甚至在超级碗上给 Codex 砸了数百万美元的广告，而不是推广自家的明星产品 ChatGPT。45

未来预测：这一切都是为了“上市”

说到底，所有的业务重组，最后都指向了钱包。

OpenAI 和 Anthropic 都盯着今年年底上市（IPO）这个大目标。1 对于机构投资者来说，一堆零散的实验性项目听起来太虚，但一个**“能干活、能挣钱、能接管生产力”**的超级应用，那就是一个充满想象力的好故事。

Simo 在 X 平台上倒是很坦然：“公司会经历探索阶段和重新聚焦阶段，两者都不可或缺。” 翻译一下就是：之前我们走了一些弯路（比如把 Codex 拆了），现在我们要加倍补回来。1

AI 战场的下半场，已经不再比谁的模型更能写诗、更能画画，而是比谁能更深地嵌入到用户的日常工作流中。奥特曼这波“超级应用”的豪赌，到底是重回巅峰的入场券，还是病急乱投医的“全家桶”？咱们拭目以待。
