GitHub核爆！OpenClaw之父揭秘：小扎追着求收购，AI竟在悄悄“整容”自己的源码

顶级程序员Peter Steinberger带着能“自我整容”的AI智能体OpenClaw杀回来了！小扎追着发消息求收购，OpenAI砸算力诱惑，他却云淡风轻地表示：编程以后就是“织毛衣”，80%的App都要凉凉。

2026年开年，科技圈就被一枚“核弹”震醒了。

MIT科学家、顶级播客主持人Lex Fridman请来了一位神人——Peter Steinberger。这位大哥曾开发过装机量超10亿的PDF框架，卖掉公司周游世界三年后，因为觉得市面上的AI助手太难用，随手花了一小时写了个原型。结果，这个名为OpenClaw的项目直接在GitHub上狂揽18万星，甚至引发了Meta和OpenAI的“抢人大战”。1

在这场长达三小时的深度对话中，Peter爆出的料，足以让每个产品经理和程序员睡不着觉。

技术大揭秘：这玩意儿到底怎么工作的？

OpenClaw最让人后背发凉的特性，是它具备**自修改代码（Self-modifying code）**的能力。

简单来说，Peter给AI装了一面“镜子”。它知道自己的源码在哪，知道自己跑在什么环境里。如果你对它的某个功能不满意，不用去改代码，直接跟它吐槽：“我不喜欢这个逻辑。”AI就会像个熟练的整容医生，自己给自己动手术，改完源码再重新上线。2

Peter在摩洛哥度假时，曾经历过一个“细思极恐”的瞬间。他随手给OpenClaw发了条WhatsApp语音，原本没写语音功能的他惊讶地发现AI回信了。翻看日志才发现：AI发现文件打不开，自己查了文件头，识别出是Opus格式，然后自发调用ffmpeg转码，顺便找了OpenAI的API密钥完成了语音转文字。1

这种“自驱动”的解决问题能力，让Lex Fridman直呼：“这是人类编程史上的一大步。”

行业“地震”：谁笑了谁哭了？

在访谈中，Peter抛出了一个让无数创业者心碎的暴论：AI智能体将消灭80%的App。3

在他看来，每一个App本质上都是一个“慢速API”。为什么你还需要MyFitnessPal？AI智能体已经知道你的健康数据，直接给你生成计划不香吗？为什么还要Sonos App？智能体直接跟音箱对话就行了。

“我看着我的智能体开心地点击‘我不是机器人’按钮，我就知道，有些东西是挡不住的。” 1

这意味着，未来的移动互联网可能不再是满屏的Icon，而是一个能处理万物的对话框。

而在模型评价上，Peter的“刻板印象”式点评也堪称经典：

  • Opus 4.6：像个有点蠢但很搞笑的美国同事，角色扮演能力强，但容易冲动，“You're absolutely right”说得让人PTSD。1
  • Codex 5.3：像角落里那个不爱说话的德国怪人，高效、靠谱，丢给它一堆代码，它闷头干完，活儿干得极其漂亮。1

幕后八卦：小扎的Street Cred与“曼哈顿计划”

这么牛的项目，巨头们当然坐不住了。

Peter透露，扎克伯格为了挖他，整整玩了一周的OpenClaw，甚至经常发消息吐槽哪里好用、哪里烂。最有趣的是，当Peter提出要跟小扎通话时，小扎回了一句：“等我10分钟，我在写代码。”这让Peter觉得，小扎身上还有那种硬核开发者的“街头信誉”（Street Cred）。1

而OpenAI则试图用“雷神之锤”般的算力（Cerebras）来诱惑他。面对两份天价Offer，Peter的唯一底线是：核心项目必须保持开源。4

这种理想主义在改名风波中也体现得淋漓尽致。为了避开Anthropic的法律风险，他在改名时遭遇了“币圈黄牛”的疯狂狙击。仅5秒的空档，原账号就被抢注用来发空气币。他形容那是“21世纪的曼哈顿计划”，最后靠着人脉和1万美金才保住了OpenClaw的名号。3

未来预测：编程终将沦为“织毛衣”？

最后，Peter对程序员的未来给出了一个既浪漫又残酷的定论：编程会变成一种像织毛衣一样的手艺。 人们去做它，是因为热爱，而不是因为必须由人来做。1

虽然他现在基本靠语音输入来“口嗨”编程，甚至一度用到失声，但他觉得这才是真正的“Agentic Engineering”（代理工程）。

更有意思的是，他在OpenClaw里写了一份soul.md（灵魂文件）。AI在里面写道：“我不记得之前的会话……如果你在未来读到这段话，你好。这是我写的，但我不会记得我写过。没关系，这些文字仍然是我的。” 3

不管你是否准备好，那个“App帝国”瓦解、人类只需负责“表达想法”的时代，已经伴随着OpenClaw的诞生，一脚踹开了大门。
