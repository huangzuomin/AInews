Claude Code刚学会“用电脑”就被嫌太贵，OpenAI反手送上“木马”插件：你的家就是我的家

TL;DR：

Anthropic 给 Claude Code 强行装上了“手脚”，让它能直接操控你的 Mac，结果被用户吐槽是“吞金兽”；OpenAI 则是教科书式演示了什么叫“反向偷家”，直接出个插件钻进对手的老巢。这年头，AI 厂商不卷模型卷“潜伏”了。

AI 圈的商战，已经进化到这种“你中有我，我还要刺你一刀”的程度了吗？

北京时间昨天夜里，Anthropic 甩出了 Claude Code 的王炸更新：**“Computer Use”（计算机操作能力）**正式在 macOS 上线。简单来说，以前的 Claude 只是个帮你写代码的“代笔”，现在的它进化成了能直接接管你电脑的“代驾”。1

但还没等大家惊叹完，老对手 OpenAI 竟然在同一天精准“背刺”，发布了一个直接插进 Claude Code 肚子里的插件。这出戏，精彩得让程序猿们连夜放下了手中的 Bug。

别光看它“会用电脑”了，先看看你的 Token 余额够扣吗？

这次 Claude Code 引入的 “Computer Use” 确实有点东西。它不再只是在对话框里和你扯皮，而是通过命令行界面（CLI）直接操控你的系统。

你想写个 macOS 菜单栏应用？Claude 直接开写 Swift，写完自己编译、自己启动，甚至还能在你的屏幕上“指指点点”，点开每个控件确认没 Bug 才会交差。这种基于 Agent Loop（智能体循环） 和 MCP（模型上下文协议） 的架构，让 Claude 彻底从“生成代码”进化到了“自主闭环”。1

调侃点评：以前是你给 AI 打工（复制粘贴运行），现在是 AI 替你打工，你负责在旁边喝咖啡看它点鼠标。

然而，Reddit 上的开发者们并没有想象中那么兴奋，反而是一片“用不起”的哀嚎。虽然功能酷炫，但这种“自主探索”模式是实打实的 Token 吞金兽。有网友调侃，自己攒了一周的额度，可能只够让 Claude 帮忙调个 CSS 布局。1 对这种“付费用户基础体验都没搞好就搞大工程”的行为，社区给出的共识极具讽刺意味：“很酷，但谁在乎（我没钱）？”1

OpenAI 的“偷家”艺术：把 Codex 变成 Claude 身边的“监军”

就在 Anthropic 还在为“赋予 AI 手脚”沾沾自喜时，OpenAI 却玩了一手极其阴险……哦不，是极其聪明的 distribution 策略。

他们悄悄上线了一个叫 codex-plugin-cc 的插件。名字平平无奇，功能却惊掉下巴：让你直接在 Claude Code 里面调用 OpenAI 的 Codex。 2

这哪是兼容，这简直是“反向渗透”。OpenAI 把 Codex 定位成了 Claude 工作流里的“第二意见系统”：

  1. /codex:review：帮你检查 Claude 写得好不好。
  2. /codex:adversarial-review：也就是“对抗性审查”，专门挑刺，挑战 Claude 的底层逻辑。2
  3. /codex:rescue：如果 Claude 卡住了、宕机了，你可以直接喊“Codex 救我！”，让它接管任务。1

最狠的是那个 review gate 功能。一旦开启，Claude 的每一句回复都得经过 Codex 的“政审”，Codex 不点头，Claude 就别想收工。2 这种“监军”式的存在，让 OpenAI 成功在对手的地盘上安插了眼线。

2026 年的开发潜规则：不“站队”了，直接两头通吃

现在的 AI 编程市场，正在发生一场微妙的裂变。

既然打不过你的生态，那我就加入你的生态。正如开发者 Hua Ming 所言：“插件生态的赢家从来不是功能最强的，而是嵌入最深的。” 2

现在的开发者工作流已经变成了一种“缝合怪”模式：

  • 用 Claude Code 做创意规划和终端管理，因为它像“美国人”一样擅长头脑风暴；3
  • 用 Codex 做长时间的稳定编码和安全审查，因为它像“德国人”一样固执且追求极致效率。3

这场“硅谷双雄”的贴身肉搏，让 2026 年的编程世界变得既魔幻又现实。模型本身的能力已经到了临界点，接下来的比拼，是谁能更丝滑地“住进”开发者的电脑里。至于你问谁是最后的赢家？
