投了OpenAI 130亿的微软，被自家工程师用Claude Code烧爆了账本

温故智新AIGC实验室

TL;DR：

微软工程师们刚用Anthropic的Claude Code爽了一把，就被财务部门紧急喊停：6月底前全部下线，转向自家Copilot。原因是账单太贵，连微软这种“不差钱”的巨头都扛不住了。另一边，Uber更夸张，2026年全年的AI预算，4个月就烧光了。AI的“补贴时代”正式终结，CFO们开始接管技术决策权。

微软工程师的“天”塌了：10万人集体“换血”

想象一下，你正用着一款趁手的“神器”疯狂输出，效率翻倍，摸鱼时间都变多了——然后老板突然告诉你：“这玩意儿太贵了，下周给我换回老工具。”

这就是昨天发生在微软近10万名工程师身上的“惨案”。

据外媒爆料，微软计划在6月底前，全面停掉工程师们正在使用的Anthropic Claude Code订阅。1 范围直接划定了“重灾区”：负责Windows、Microsoft 365、Outlook、Teams和Surface的「体验+设备」部门。所有工程师，必须全员转投自家“亲儿子”——GitHub Copilot CLI。

这可不是小打小闹的“技术升级”，而是一次由财务部门主导的“紧急刹车”。

理由极其直白：账单太贵了。

你以为微软这种市值3.5万亿美元的巨头，会在乎这点“小钱”？格局小了。在Token计费时代，每一行AI生成的代码，都在“吞金”。

自家“亲儿子” vs 竞争对手的“吞金兽”

这场“血案”背后，藏着一个极为讽刺的财务逻辑。

微软给OpenAI砸了130亿美元，还亲手在Azure云上给竞争对手Anthropic搭建了算力底座。结果，自家的工程师们大规模调用Claude Code——钱没进自家口袋，反而流向了最直接的竞争对手。

这就像你家开火锅店，结果厨师天天去隔壁吃和牛，还得你买单。

最扎心的是，GitHub Copilot属于“内部核算成本”，资源在Azure内部流动，边际成本极低；而Claude Code则是一笔实打实的“外部账单”。2 即便两者产出完全相同，财务性质也天差地别。

一个是从左手到右手，一个是真金白银往外掏。

微软官方的说法是“战略对齐”。翻译一下就是：面子要给，但账本不能糊。

四个月，Uber烧光全年AI预算

微软不是一个人在“哭穷”，Uber的故事更离谱。

Uber CTO Praveen Neppalli Naga的一封内部备忘录，直接把AI行业的遮羞布扯了下来：2026年全年的AI专项预算，才过了4个月就彻底烧光。3

来看看这惊人的数据：

  • 95% 的工程师月活使用AI工具
  • 84% 的工程师已进入“智能体编码（Agentic Coding）”模式——让AI自己写代码
  • 70% 的线上提交代码源自AI生成

听起来是不是很“酷”？效率爆炸，生产力狂飙！

但代价是灾难性的。财务团队原以为AI是“固定席位、低频调用”，结果5000名工程师同时开启“智能体”工作流，AI像永动机一样24小时跑代码。后果就是：重度用户的月度成本最高可达2000美元/人。3

当你的员工用AI写代码的速度比喝水还快，财务总监看着后台的计费器，血压也跟着飙升。

Uber的案例释放了一个系统性信号：用得越深，烧得越凶。

范式地震：从“自助餐”到“按克计价”

为什么突然都喊“贵”了？

过去三十年，软件行业的付费逻辑是：付了月费，软件随便用。这是SaaS（软件即服务）的“包月自助”模式。

但AI正在暴力拆毁这套逻辑。

GitHub已经宣布，从6月1日起，Copilot全面取消“一口价”固定计划，转向按使用量（Token）计费。4 全球AI软件的有效价格，在过去半年内上涨了20%到37%。

以前用AI，像吃自助餐：交钱进场，能吃多少全看胃口。现在，AI变成了市场里按克计价的顶级和牛——每一行自动生成的代码，每一次Agent的调用，都在计费器上留下一串血色的数字。4

用专业术语说，这叫从“订阅经济”跨入了“效用经济”。用人话说就是：AI吸的不是CPU，是你公司的现金流。

谁才是AI项目的“最高指挥官”？

这场由Token成本引发的“血案”，正在改变科技公司的权力结构。

过去，AI的推广由CTO和开发者驱动，大家追求的是“快”和“酷”。谁用最牛逼的模型，谁就是“技术大佬”。

但现在，CFO（首席财务官）可能要成为AI团队真正的最高指挥官了。

当你的AI账单从几千美金飙到几十万，而老板问“你的AI给公司赚了多少钱”时，你很难潇洒地说出“这是为未来投资”这种话。

无论是微软强制“换血”，还是Uber的预算“爆炸”，都指向同一个残酷现实：AI的效率神话，正在遭遇财务的“现世报”。

如果企业因为太贵而收手，或AI公司为留客而亏本甩卖，悬在整个行业头顶的，就是那两个字——减值。

毕竟，科技圈的终极真理永远是：账算不通了，总得有人买单。
