谭待：在AI的“功能机”时代，不仅要做模型，更要重塑生产力

温故智新AIGC实验室

TL;DR： 作为火山引擎的舵手，谭待带领团队从“大哥大”时代的模型探索，迈向了如今深度嵌入企业核心生产环节的“功能机”时代。他坚信模型性能的每一次飞跃都是商业价值的基石，主张通过构建AI云原生架构，让模型真正成为驱动产业效率变革的引擎。

从“大哥大”到“功能机”

在北京那间透着科技极简主义的办公室里，谭待谈起大模型时，神情中少了几分初入局时的紧绷，多了几分对技术周期理解后的笃定。两年前，他曾将大模型行业比作“大哥大”时期，那是少数先驱的玩具；如今，他认为行业已经快进到了“功能机”时代——模型不再是概念的堆砌，而是开始真正扎根于各行各业的工作流中。

这种变化的基准线是清晰的。作为火山引擎的总裁，谭待对“增长”有着近乎严苛的量化逻辑。在火山引擎的版图中，豆包大模型 2.1 Pro 不仅仅是一个产品的升级，它是火山引擎在 Coding 和 Agent 领域实现“上牌桌”的入场券。1

对“生产力质变点”的执念

谭待的思维模式中，有一种深刻的“第一性原理”烙印。当被问及为何火山引擎能在云市场的红海中撕开裂口时，他将原因归结为对“生产级场景”的精准识别。

“你如果真的追上了、甚至超越了，大家会为你付费。”谭待对此直言不讳。他不仅关注模型的参数和跑分，更关注它在企业真实场景中的“耦合度”。他认为，只有当模型的能力跨越了生产力质变点——即模型能够独立处理复杂长程任务、能够自动调用工具并与记忆系统深度结合时，它才具备了真正的商业价值。2

在他看来，定价不再是简单的成本加成游戏，而是价值的体现。2024 年的大模型降价潮是因为“模型只值那个价”，而随着豆包大模型 2.1 Pro 具备了深入核心生产环节的能力，其创造的溢价也随之提升。3

架构师的视野：云与MaaS的合流

面对“卖 API 就能挣钱，为什么还要做云”的质询，谭待表现出了作为战略规划者的冷静。他反驳了将 MaaS 与云对立起来的观点，预言未来的云将彻底进化为“AI 云”。

在他构想的蓝图里，传统云不会消失，而是会成为 AI 云的底座，由 Agent 去智能调度 IaaS、PaaS 和 SaaS 组件。1 这种洞见体现了他对行业深层趋势的把控：如果说 2012 年字节跳动成立时 PC 搜索已是夕阳，那么今天如果不押注 AI 云，就是错失下一个万亿市场的入场券。

工程师思维与“导演”视角

有趣的是，这位深耕底层的技术领袖，近期表现出了一种跨界的谦逊。为了让 Seedance 模型在影视创作领域发挥更大的价值，他开始在团队中招募导演。这不仅仅是一个人才储备的决策，更是一种思维方式的转变——技术不再是孤立的存在，它需要与行业的专业叙事深度对话。

这种“陪跑”式的落地模式，让他从一个纯粹的管理者，转型为产业变革的“前沿部署者”。他鼓励团队放弃微观操作，转而信任团队的创造力，这或许是他从追求单一KPI到追求长期技术生态建设的成熟体现。2

对于谭待而言，征途才刚刚开始。正如他所言，AI 带来的变化远比绝大多数人想象的要巨大、快速。而他在年初一次次调高目标又一次次完成目标的循环中，正逐步将火山引擎推向行业的最前沿。3
