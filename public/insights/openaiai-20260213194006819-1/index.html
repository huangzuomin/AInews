技术大揭秘：这玩意儿到底怎么跑这么快的？

很多同学可能会问，每秒 1000 个 token 到底是什么概念？简单来说，就是你眨一下眼的功夫，它已经吐出了几百行代码。为了实现这种“暴力美学”，OpenAI 这次找了个强力外援——AI 芯片巨头 Cerebras。1

这次 Spark 模型并不是跑在传统的 GPU 堆叠上，而是跑在 Cerebras 的 Wafer Scale Engine 3 (WSE-3) 上。这玩意儿可不是普通的显卡，它是整块晶圆级芯片，长得像餐盘一样大，拥有 4 兆个电晶体。2

实时协作新范式：程序员会被“卷”死吗？

虽然 Spark 是 GPT-5.3 家族里的“闪电侠”，但为了速度，它也做了一点小小的取舍。它是 Codex 的精简版，在处理极其复杂的软件工程任务（比如 SWE-Bench Pro 测试）时，表现略逊于完整版的 GPT-5.3-Codex。2

但这并不妨碍它成为目前最强的“结对编程”队友。它的应用场景非常明确：实时互动。3

  • 瞬时重构： 你想改个接口逻辑，它秒速完成全量替换。
  • 交互式打断： 你可以一边看它写，一边随时打断：“哎，这里用异步实现。”它能立刻调转船头。
  • 低延迟 CLI： 在终端里敲命令，AI 的响应就像本地脚本一样丝滑。4

这种感觉不像是在用一个迟钝的机器人，更像是在和一个手速 600 的顶级极客一起工作。OpenAI 的野心很明显：未来的编程将分化为两种模式。一种是交给大模型去搞数天的“深度思考”；另一种就是像 Spark 这样，和你火花四溅地“实时对线”。2
