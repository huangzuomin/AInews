贾扬清闪电离职英伟达：7亿收购一年散伙，老黄的“开源大饼”画崩了？

温故智新AIGC实验室

TL;DR：

曾经的AI开源大神贾扬清，把公司卖给英伟达才一年就“提桶跑路”了。老黄当初承诺的7亿美元加开源大饼，如今只留下一个停摆的云平台和一地鸡毛。更扎心的是，行业里已经有人用AI Agent一夜之间复刻了同类产品——这波啊，这波叫“硬核白给”。

故事要从一个“开源老炮”说起

贾扬清这个名字，混AI圈的应该不陌生。清华本硕、UC Berkeley博士，博士期间就写出了Caffe——那个年代入门深度学习几乎人手一个的“神级工具”。后来在Google Brain参与早期TensorFlow，在Facebook主导PyTorch 1.0和ONNX，在阿里当技术副总裁搭建AI平台1。

这人二十年来只干一件事：做开源，做工具，让更多人用上。2023年他从阿里出来创业，搞了个LeptonAI——号称“几行Python就能把模型部署到GPU”的轻量级云平台。产品做得不错，开源搜索引擎search_with_lepton还一度在GitHub爆火。

然后，英伟达看上了它。2025年4月，老黄砸了整整7亿美元把LeptonAI收入囊中1。当时圈内一片叫好：开源大神+硬件巨头的组合，听起来就像天作之合。

然后呢？剧情开始离谱了

收购完成一个月后，LeptonAI平台直接停运，禁止新用户注册，官推注销。一个有自己的用户社区的独立云平台，说关就关。为什么这么急？因为英伟达自家的DGX Cloud已经快撑不住了——定价每月36999美元起，结果AWS直接降价45%，价格优势一夜归零1。

自家云都在收缩，LeptonAI的定位自然跟着漂移：从完整的云平台降格成了GPU工作负载调度器，品牌改叫“DGX Cloud Lepton”，对接25家以上云合作伙伴。阵仗不小，但产品没打出水花。

更扎心的是那个开源承诺。英伟达当初白纸黑字说2026年前开源Lepton核心软件平台。现在2026年6月底了，半个字没兑现。SemiAnalysis分析认为，贾扬清离职的直接原因，很可能就是英伟达最终搁置了开源1。

你想想，一个靠开源立身的大神，进了个商业模式靠卖硬件的公司——开源Lepton意味着竞争对手也能用这套调度器管理非英伟达的GPU。这个矛盾从签字那天起就埋下了，老黄答应了开源，但他的商业模式可能压根就不允许这事发生。

更扎心的还在后面：AI已经开始重写AI基础设施了

就在英伟达为了那点开源承诺纠结时，行业里另一股力量已经悄悄改写规则——Agentic Coding。

AMD工程师Anush Elangovan，带着10到12个Claude Code Agent，一夜之间用Rust重写了一个对标Slurm的调度器，叫Spur，每周消耗65亿token1。一个人，一群AI agent，产出了一个对标数十年历史的HPC调度器原型。

Cursor、Claude Code、Codex这些工具正在重塑软件的经济学。英伟达花7亿买来的东西，别人已经开始用AI重建了——而且成本几乎为零。

这波啊，这波叫做“硬核白给”。

贾扬清的下一站：又回到了“开放”的路上

公开信息显示，6月9日，贾扬清以顾问身份加入了Hyperbolic Labs——一家做去中心化GPU算力市场的公司1。

一年前，他把自己创办的公司卖给了全球最大的GPU公司。一年后，他出现在一家让GPU算力更开放的公司里。从Caffe到PyTorch，从ONNX到LeptonAI，二十年他做的都是把AI基础设施做成开放工具，让更多人用上。Google做过，Facebook做过，阿里做过，自己创业也在做。

但在英伟达，他没做成。

这或许不是一个“大神遇冷”的故事，而是一个关于商业模式与开源信仰的经典冲突。当一家靠卖芯片赚钱的巨头收购了一个以开源为基因的团队，结局其实在签字那一刻就注定了。只是没想到，连7亿美金都留不住一个想要“开放”的人。
