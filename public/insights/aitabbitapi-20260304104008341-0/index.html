美团AI浏览器Tabbit翻车现场：代码是“搬”的，API是“送”的，心是“急”的？

温故智新AIGC实验室

TL;DR：

美团想靠AI浏览器Tabbit打个翻身仗，结果刚起跑就因为“借用”代码和免费“派发”API成了科技圈的笑料。只能说，“光年之外”的名头虽然响亮，但美团在AI这条路上走得确实有点“步履仓促”了。

开年第一炮，美团本想高调展示AI肌肉，没曾想却演变成了一场“大型道歉直播”。

3月2日，美团旗下光年之外团队推出了首款AI原生浏览器——Tabbit。正当大家准备感叹“美团终于要在AI赛道搞点大事”时，尴尬的一幕发生了：产品上线还没满24小时，就被翻译产品“陪读蛙”的开发者在X上实锤抄袭1。这波“光速翻车”不仅让美团颜面扫地，更揭开了美团在AI混战中的焦虑底色。

技术不够，“搬运”来凑？

这次争议的焦点在于Tabbit内置的翻译插件。开发者“梦溪睡了吗”不仅贴出了两款产品像素级的界面对比图，更狠的是，在扒出的源码中，美团甚至连原项目的文件名都懒得改。这种“连作业都不带改名字”的操作，确实让见多识广的程序员们看呆了1。

美团的回应倒是很有“大厂风范”。先是解释说2025年底看到该项目时还没开源协议，以为能“随便白嫖”；等发现作者补上了GPL协议后，由于理解“不够严谨”，导致了现在的尴尬23。

调侃点评： 这逻辑就像是看邻居门没锁就进去搬了台电视，事后说：“我当时看他门上也没贴‘禁止入内’啊。”

最终，美团选择了最体面的“自救”方式：移除争议代码、全量开源相关项目，并向原作者致歉。原作者倒是很大度，表示这并非“主观恶意”，更像是合规流程上的生疏2。但对美团来说，这种“出师未捷身先死”的公关危机，无疑给这款AI浏览器蒙上了一层阴影。

API大放送与“骨感”的Agent体验

如果说抄袭只是合规部门的锅，那么接下来被曝出的“API Key内置在客户端”则简直是安全层面的“自杀式袭击”。网友们顺藤摸瓜，直接从客户端扒出了API信息并挪作他用，美团瞬间成了全网免费AI算力的“慈善家”1。

抛开这些风波，Tabbit本身好用吗？

客观地说，Tabbit的设计逻辑是有亮点的。它试图用Agent（智能体）来解决信息碎片化的痛点：

  • 标签页智能分组： 几分钟内能把你收藏的一百多个乱七八糟的网页分门别类，并给出解析1。
  • OpenClaw式的玩法： 结合本地收藏夹和网页信息，通过工作流实现内容分发。比如你喂它一个稿件，它能自动按小红书、微博的调性帮你处理并分发1。

然而，理想很丰满，现实很骨感。在实际测试中，Tabbit的Agent表现极其不稳定，模型无响应、调用执行失败成了家常便饭。相比于字节跳动的“豆包”或阿里的“千问”，美团的AI基础设施在面对高并发和复杂指令时，依然显得“弱不禁风”1。

美团AI：进攻是最好的防守，但你得先有盾

美团CEO王兴曾豪言：“AI将颠覆所有行业，我们对AI是进攻而不是防守。”1

王兴的战略蓝图分为三层：效率提升、产品改造、自研基座模型。光年之外作为这套战略的尖兵，这两年从AI生图产品“妙刷”到现在的Tabbit，几乎是哪个赛道热就往哪钻。但遗憾的是，除了靠发优惠券短期冲榜的“小美”和“问小团”，美团至今没能拿出一个具备统治力的AI爆款。

与其说美团在做AI，不如说美团在“追”AI。从被指责“不聪明”的点餐机器人，到如今身陷抄袭风波的浏览器，美团的AI之路走得异常踉跄。

调侃点评： 股价在跌，业务在卷，美团确实急需一个AI故事来救市。但心急吃不了热豆腐，更何况这豆腐现在看起来还没完全煮熟。

美团的真正困境在于，它拥有极强的本地生活生态，但在底层AI技术的积淀上，显然还没能跟上它的野心。在“出圈”压力下，光年之外交出的这份答卷，目前看只能算是一次略显仓促的“草稿”。
