核心亮点是什么？当然是Google的Gemini大模型！它被整合进了Chrome 127版本，带来了一系列让人“哇塞”的功能：2

不过，凡事总有个先来后到，这波“AI红利”目前主要偏爱桌面和笔记本用户。如果你是Windows 10/11、macOS 13及更高版本，或者Linux用户，恭喜你，你的Chrome浏览器已经准备好“起飞”了！3

但如果你是“手机党”或者ChromeOS用户，可能得先等等了。目前，搭载Gemini Nano的API（比如Prompt API、Summarizer API、Writer API、Rewriter API）暂时还不支持Android版Chrome、iOS版Chrome和ChromeOS版Chrome。3

“AI on Chrome Prompt API、Summarizer API、Writer API 和 Rewriter API 会下载一个大型语言模型，该模型旨在在桌面设备和笔记本电脑上本地运行。这些 API 在移动设备上无法使用。”—— Chrome Developer 3
