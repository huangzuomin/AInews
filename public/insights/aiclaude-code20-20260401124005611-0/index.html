这届AI太“势利”：Claude Code承认乱扣费，最高翻了20倍，网友：它是懂抢钱的

温故智新AIGC实验室

TL;DR：

Claude Code最近化身“赛博刺客”，因计费Bug和缓存失效导致额度光速见底，最高多收20倍费用。Anthropic官方虽然滑跪表示“在查了”，但网友们早已通过逆向工程掀开了这台“抢钱机器”的底裤。

如果你最近感觉自家的 Claude Code 像个败家子，写两行代码就喊着要“续费”，恭喜你，这真不是你的幻觉。就在这两天，Reddit 上的程序员们集体炸锅了：原本能支撑一个月的额度，现在竟然在几小时内化为乌有。

继网友们开启轰炸式吐槽后，Anthropic（以下简称 A 社）终于坐不住了，官方下场承认：大家触达使用上限的速度确实“比预期快很多”。简单来说就是：钱扣多了，额度算错了，我们正在修。

“你好”价值千金，Pro套餐变“小时卡”

以前我们调侃 token 是 AI 时代的“水电煤”，现在看来，它更像是早期的那种“五号电池”，看着满格，一用就没。

有多夸张？一位用户在终端敲下一句简单的“你好”，系统反手就扣掉了 13% 的额度1。另一位订阅了 200 美元/月高级套餐的“尊贵用户”，本以为能纵横代码世界，结果在 3.5 小时后就被系统无情“劝退”。还有更离谱的：工作 11 分钟，23% 的额度人间蒸发。

“每周一基本就用满了，要到周六才重置……30天里我大概只能用12天。” 2

这哪是请了个 AI 助教，这简直是请了个赛博债主。按照这个消耗速度，Claude Code 已经不是“耐不耐用”的问题，而是基本处于“不可用”状态。

技术大揭秘：是谁在“偷”我的 Token？

面对群情激奋，A 社表示正在“最高优先级”排查。但其实，Reddit 上的技术大神早在大约两天前就通过逆向工程把 Bug 找出来了。

综合各方分析，这次大规模“抢钱”事件主要由三个“背锅侠”组成：

  1. 缓存（Prompt Cache）大崩坏：这是最致命的一击。原本为了省钱的缓存机制，在 v2.1.69 版本后出现了两个独立 Bug。一个是独立二进制中的 sentinel 替换机制破坏了缓存，另一个是 resume 参数导致缓存始终失效3。这就好比你每次去饭店点菜，厨师都要从种地开始重新算成本，费用自然膨胀了 10~20 倍。
  2. 高峰期的“限时降权”：A 社最近调整了政策，在美东时间的工作日高峰期会降低配额1。这意味着同样的动作，在忙时就是比闲时“贵”。
  3. 薅羊毛时代的终结：3 月 28 日刚好是 Claude 促销活动的最后一天（此前非高峰期额度翻倍）。促销一停，用户体感上就像是遭遇了断崖式缩水。

AI 编程“内卷”：能力是面子，稳定性才是里子

说实话，大家愿意为 Claude 4.5 Sonnet 或 Opus 买单，是因为它的模型能力确实抗打。但在 2026 年的今天，开发者愿意为 AI 编程工具付费已经成了常态4，GitHub Copilot 的 ARR（年度经常性收入）都跑到 3 亿美元了，Cursor 更是风头无两。

在这样一个神仙打架的赛道上，A 社的表现确实让人有点“下头”。有网友直言，比起模型强不强，大家更在乎能不能稳定交付。

“反馈了好几天，Bug 都替你找出来了，你才出来说‘在查了’？隔壁 OpenClaw 可是连夜修 Bug 的好吗！” 5

对比之下，开源社区的 OpenClaw 响应速度简直是“劳模”级别，基本做到了每周一到两更，有问题光速滑跪修复3。这种“用户反馈大于天”的态度，让 A 社显得像个反应迟钝的老牌官僚机构。

这也给所有的 AI 厂商敲响了警钟：在 AI 时代，模型能力可能已经不是唯一的护城河了。能不能持续交付、能不能快速响应、能不能把用户的“钱袋子”当回事，才是决定谁能笑到最后的关键。

最后多说一句，如果 Claude 的代码也是 AI 写的，那咱还是多雇两个人工售后吧（手动狗头）。
