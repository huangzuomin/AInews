小扎“诈尸”式发帖，就为了它？Meta最强编程Agent模型，价格卷到飞起

温故智新AIGC实验室

TL;DR：

时隔三年，小扎终于在X上“诈尸”发帖了！不为别的，就为了给自家的新模型Muse Spark 1.1站台。这玩意儿号称是Meta最强的编程Agent模型，不仅能力对标OpenAI和Anthropic，价格还只有竞品的四分之一，主打一个“高性价比牛马”。

为了它，小扎连“消失”的人设都不要了

如果2026年你还在玩X（原推特），最近大概会被一条帖文刷屏。发帖的人不是马斯克，而是那个似乎已经“退网”三年的马克·扎克伯格。

这哥们上一次在X上说话，还是2023年7月，那会儿这平台刚改名，满屏都是“X”的诡异气氛。三年没动静，突然冒泡，就为了安利自家的一款新AI模型——Muse Spark 1.1。[^1] 这待遇，亲儿子Llama都没享受过，这玩意儿到底有啥魔力？

简单说，这是一款专为“智能体编程”（Agentic Coding）打造的多模态AI模型。翻译成人话就是：以前你让AI写代码，它可能只给你一个孤零零的代码块；现在你可以让它像一个有脑子、有手、有嘴的实习生，自己去查文档、修Bug、调用各种软件，最后帮你把整个项目跑通。

小扎在帖子里也完全不装，直接吹爆：“Spark是目前最强的智能体和编程模型，尤其是在Agent性能和工具调用方面。” 末了还补了一句“很快还有更多好东西”，吊足了胃口。[^1]

技术大揭秘：这届“AI牛马”有多卷？

为了让大家直观感受这只“牛马”的身价，我们来看看它的简历：

  • 能力一：多模态理解 它不仅能看懂代码，还能看懂图表、图像、视频乃至音频。你说“把我PPT里的那个图表做成一个可以交互的网页”，它能立刻明白你在说啥，并开始干活。[^2]

  • 能力二：超长上下文与规划 这货能在长达数小时的会话中保持上下文。什么意思？就像你给实习生布置了一个任务后去度假，回来发现他已经把这周的所有工作都做完了，中间遇到的各种幺蛾子（比如某个软件崩了、找不到某个数据文件）都自己想办法解决了。[^2]

  • 能力三：计算机操作 这是最逆天的一点。Muse Spark 1.1 可以像人一样操作鼠标键盘，去摆弄那些没有API的老旧软件界面，并从中提取需要的信息。[^2] 你让它“把那个20年前的ERP系统里的库存数据导出来”，它就能自己点来点去完成操作。这波操作，建议所有实习生都来看看。

Meta的AI掌门人Alexandr Wang表示，他们之所以死磕编程能力，是因为这是打造全能Agent的“基建”。“你必须把编程能力作为整体智能体能力的一部分来构建。”[^2] 说白了，能写好代码的AI，才能当好听话的“牛马”。

行业“地震”？Meta这次不讲武德，直接掀桌子

前面提到“牛马”，那肯定绕不开价格。AI行业这半年打价格战打得头破血流，Meta作为后来者，怎么加入战局？答：用更低的价格，提供差不多的服务。

来看看Muse Spark 1.1的“卖身契”：

  • 输入价格：每百万Token 1.25美元
  • 输出价格：每百万Token 4.25美元

这个价格是什么水平？比OpenAI的GPT-5 mini和Anthropic的Claude Haiku 4.5都低，基本和GPT-5.6 Luna持平（甚至还低一丢丢），但直接砍到了Anthropic高端模型Claude Sonnet 4.6的“脚脖子”。[^3] Wang自己也承认，这个定价“非常激进且具有吸引力”。[^3]

别忘了，每个新用户还赠送20美金的免费体验额度！这操作，像极了当年拼多多刚出来时的补贴策略。Futurum Equities的分析师直接点破：“如果Spark 1.1的编程能力真的能打，那Meta终于找到了把AI模型变现的清晰路子。”[^2]

这波“降价+免费试用+能力对标”的三连，Meta这次是铁了心要在OpenAI和Anthropic的盘子里抢肉吃。

战略转向：从“共享开源”到“付费打工”

这背后，是Meta AI战略的一次重大转向。一直以来，Meta都是“开源精神”的旗手，Llama系列模型让无数开发者白嫖。但现在，小扎变了，他开始卖收费的闭源模型了。

原因很简单：华尔街爸爸催得紧，必须得证明投进去的几千亿美元能回本。 [^3]

小扎在接受采访时也直言：“如果你真的想打造最好的用户体验，就必须能够塑造底层技术。”[^3] 翻译一下就是：免费开源虽然好，但不赚钱啊。为了让大家用上最好的AI助手，我们不得不先赚点钱。

不过别担心，Wang说了，团队依然“致力于开源”，正在开发一个“Muse Spark的变体版本”，未来会开源，但没给时间表。[^2] 这就像一个程序员跟你说“改天请你吃饭”，懂的都懂。

除了Muse Spark，Meta还在闷声憋大招。据说正在训练一个代号为 “西瓜”（Watermelon） 的更强模型，内部评测已经赶上OpenAI的GPT-5.5了。[^1] 上一个代号还是“牛油果”（Avocado），这瓜田里的代号，有点意思。

总而言之，小扎这三年的“沉默”，换来了一颗能打能拼、价格还便宜的“牛油果”。对于开发者来说，多一个选择总是好事。下一步，就看这个“AI实习生”能不能真的像小扎吹的那样，成为我们人手一个的编程好帮手了。
