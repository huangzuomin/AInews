1600人“原地毕业”，连CTO都开了！Atlassian：别问，问就是AI太香了

温故智新AIGC实验室

TL;DR：

澳洲SaaS巨头Atlassian挥刀自宫，裁掉10%员工强推“AI优先”，连CTO都成了“时代的眼泪”。当AI让生产力坐上火箭，打工人却面临“活干完了，人也可以走了”的尴尬，是时候重新聊聊“缩短工时”这个保命命题了。

在这个“万物皆可AI”的时代，如果你觉得AI还只是个帮你写周报、润色PPT的“赛博打工人”，那澳洲软件巨头Atlassian可能要给你兜头浇上一盆凉水：AI不仅能帮你写代码，还能顺便把你的工位也给“优化”掉。

最近，Atlassian丢出了一枚深水炸弹：宣布全球裁员约10%，也就是1600名员工。更狠的是，这次裁员名单里不仅有基层的“码农”，连首席技术官（CTO）Rajeev Rajan都要在3月底卷铺盖走人1。这波操作，直接把“开猿节流”玩出了新高度。

“SaaS末日”：Jira还没卡死，股价先崩了

作为Jira、Confluence等程序员必备（也常被吐槽）工具的东家，Atlassian的日子其实过得挺纠结。一边是AI工具带来的生产力“大跃进”，开发者们用上Anthropic的Claude后，效率高得连自己都怕2；另一边则是资本市场的“无情抛弃”。

由于投资人担心AI平台（如OpenAI、Anthropic）会直接用一个Prompt（提示词）克隆出整个Jira，Atlassian的股价在2026年遭遇了“史诗级”滑铁卢，市值直接腰斩1。网友甚至调侃：“以前我们要学半年才能玩转Jira，现在AI一句话就能搞定，那Atlassian还有啥存在的意义？”

这种被称为“SaaSpocalypse（软件服务末日）”的焦虑，逼得联合创始人Mike Cannon-Brookes不得不出来“整活”。他直言不讳地表示，如果假装AI不会改变岗位需求，那就是“不诚实”3。

技术大揭秘：裁员是为了“自筹资金”？

Atlassian这波裁员的逻辑非常“渣男”：我裁掉你，是为了省下钱去投更有前途的AI。

“我们这样做是为了自筹资金，进一步投资AI和企业销售。” —— Mike Cannon-Brookes1

翻译一下就是：虽然你们工作很努力，但AI不仅更便宜，还没脾气。目前，Atlassian已经全速转向“AI优先”，推出了AI工具Rovo，还豪掷10亿美元收购了开发者智能平台DX1。

有趣的是，这种“AI式裁员”在科技圈正成为一种传染病。前脚Jack Dorsey的Block刚裁了40%，后脚WiseTech也砍掉了30%的人手。这些巨头们似乎达成了一个共识：既然AI能让剩下的员工干两个人的活，那裁掉一个不就成了“降本增效”的神迹？

深度拷问：生产力红利，打工人能分到一杯羹吗？

这就引出了一个非常扎心的问题：如果AI真的让工作效率提高了50%，为什么我们还在996，而不是下午3点就下班打球？

经济学家John Quiggin指出，AI带来的生产力提升是不争的事实，但目前这些红利似乎全落进了老板和股东的口袋2。当“人机协作”变成“AI替人”，所谓的“技术进步”对普通打工人来说，更像是一场生存竞赛。

  • 资本的逻辑：效率提升 = 裁员 = 财报好看 = 股价回升。
  • 工人的逻辑：效率提升 = 活儿干完了 = 应该早点下班陪家人。

这种矛盾让“缩短工时”的呼声再次高涨。如果社会生产力已经足够覆盖大家的需求，我们是不是该考虑从“疯狂卷”转向“优雅躺”？2

未来预测：不当“提示词工程师”，就当“待业青年”？

现在的科技圈正处于一种诡异的平衡：一边是大规模裁员，一边是疯狂抢夺AI人才。Atlassian在通告中明确表示，优先保留那些拥有AI相关技能的员工4。

所以，这场变革的本质并不是AI消灭了工作，而是AI正在重塑“什么是值钱的工作”。对于每一个还在敲代码、写文档的打工人来说，这不再是一场关于“勤奋”的比赛，而是一场关于“进化速度”的赛跑。

毕竟，当你的老板发现一个Prompt就能完成你一天的活儿时，他首先想到的可能不是给你涨工资，而是问HR：“那个1000美元离职补偿金的笔记本电脑，什么时候能收回来？”1
