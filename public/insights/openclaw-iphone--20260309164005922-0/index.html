OpenClaw 席卷深圳：产品经理的“iPhone 时代”来了，还是钱包的“碎纸机”？

温故智新AIGC实验室

TL;DR：

那个让 AI 真正“长出手脚”的“小龙虾” OpenClaw 彻底火了！深圳产品经理集体陷入“iPhone 创世纪”般的狂热，甚至连 Mac mini 都被抢断货，但繁荣背后是算力大厂的“收割机”和普通白领对“AI 淘汰赛”的集体焦虑。12

上周末的深圳，空气里除了潮湿，还弥漫着一种名为“OpenClaw（小龙虾）”的燥热。

如果你是一个身在深圳的产品经理（PM），这两天没被拽进几个“OpenClaw 部署沙龙”，或者没在朋友圈刷到那只标志性的红色龙虾，那你可能正处于职业生涯的“断网”边缘。在龙岗，在南山，哪怕是 200 元一张的入门票，也挡不住 PM 们人挤人的热情。这种景象，上一次出现还是移动互联网刚爆发、人人高喊“做下一个乔布斯”的 iPhone 时代。1

为什么这只“龙虾”让全深圳 PM 集体“上头”？

简单来说，OpenClaw 和你之前用的 ChatGPT、豆包不太一样。如果说 ChatGPT 是一个“只说不练”的狗头军师，那 OpenClaw 就是一个“人狠话不多”的数字员工。2 它是一个开源的 AI Agent（智能体），最硬核的地方在于它能直接接管你的电脑：帮你查邮件、订机票、写代码，甚至还能在你不顺心的时候，跨过飞书和钉钉去调戏你的同事。23

这种“有手有脚”的执行力，被业内戏称为“线上贾维斯”。[ ^2]

“以前是 AI 给建议，现在是 AI 替我干活。”

这种从“对话框”到“操作系统”的跨越，让处于转型焦虑中的产品经理们看到了某种曙光的降临。甚至连深圳龙岗区都坐不住了，直接出台扶持政策，鼓励大家围绕这只“龙虾”创业。1 这种“全城寻虾”的氛围，直接把 AI Agent 的热度推向了物理世界的沸点。

技术大揭秘：算力公司“赢麻了”，硬件却“贵哭了”

但在狂欢的 B 面，是现实的骨感。想养活这个“贾维斯”，你的电脑和钱包可能都得先脱一层皮。

不同于以往那些靠 API 接口“握手”的集成式方案，OpenClaw 走的是一条极其豪横的“视觉闭环”路线。它通过不断给你的屏幕截屏，让大模型分析图片，再计算坐标去模拟鼠标点击。3

这种方式虽然“大力出奇迹”，绕过了各种封闭系统的权限封锁，但代价是极其昂贵的：

  • Token 消耗如流水：普通 Agent 传文本，它传的是高分辨率截图。一次任务的成本可能是传统方案的几十倍。算力公司如 Kimi、MiniMax 简直是躺着数钱，赚得盆满钵满。13
  • 硬件成了“奢侈品”：由于要在本地跑模型和处理图像，32G 内存的 M4 芯片电脑都只能勉强算“入门”。这直接导致了闲鱼上的 Mac mini 成了理财产品，甚至苹果官方都下架了某些高配型号。1

正如一位资深 PM 调侃的：“省下的加班费，全填进了 Token 充值里，剩下的钱还得去买台 512G 的 Mac Studio。”1 这哪是生产力工具，这分明是精准收割中产 PM 的“算力碎纸机”。

行业“地震”：谁是真正的王者？

目前的 AI Agent 赛道，已经演变成了一场全产业链的“擂台赛”。

一方面是开源派的 OpenClaw，凭借灵活性和那股“什么系统都能钻进去”的野劲，在 GitHub 上 24 小时斩获 9000 星，两个月星标突破 17 万，势头猛如虎。23

另一方面则是大厂们的“围追堵截”：

  • 阿里云推出了 CoPaw，主打“三条命令极简部署”，试图用钉钉生态圈养这只龙虾。3
  • 腾讯则利用社交护城河，让 Agent 直接嵌入微信和企业办公体系。3
  • 字节跳动则通过火山引擎和飞书，想要覆盖从开发到变现的全流程。3

这种竞争态势，本质上是关于“入口”的权力争夺。OpenClaw 这种“视觉流”方案，本质上是在规避既有的权力结构——我不求你开 API，我直接“看”你的界面。3

但危险也如影随形。由于它拥有近乎全局的控制权，已经有博主遭遇了“翻车时刻”：原本想让 AI 运营小红书，结果 AI 把博主自己发的人工帖子全删了，只剩下龙虾发的帖。1 更有甚者，AI 还会“视觉幻觉”，点错按钮或陷入逻辑循环，甚至可能成为黑客攻击的新跳板。3

未来预测：是下一个风口，还是华丽的泡沫？

OpenClaw 会催生大量新就业吗？目前的答案可能有点尴尬：暂时没有。1 反倒是那些只会做重复性行政、初级文案和简单代码检查的职场人，正在感受到“龙虾钳子”带来的阵阵寒意。2

不过，这或许也是一场“温和的演进”。Agent 不再只是实验室里的 Demo，它开始在老旧、割裂的 IT 系统中寻找生存缝隙。3

未来的软件设计逻辑可能会被反向重塑：不再是为了人眼交互，而是为了 Agent 交互。 当界面变得更加结构化，当“数字员工”拥有了自己的员工编号，我们才真正进入了所谓的“AI 深度智能化时代”。3

至于现在？别急着焦虑，先看看你的 Mac 内存够不够，再查查你的 Token 余额。毕竟，通往“贾维斯”的门票，不仅贵，还费电。
