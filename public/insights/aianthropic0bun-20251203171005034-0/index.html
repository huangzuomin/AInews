AI巨头Anthropic豪掷千金，竟把「0收入」前端公司Bun娶回家？这波操作有点野！

最近，科技圈又搞了个大新闻！AI巨头Anthropic，就是那个有着Claude Code的“实力派”，突然宣布收购了一家名叫Bun的初创公司。等等，你没看错，这家Bun公司，目前竟然是0收入！12

是不是听起来有点“离谱”？一家AI独角兽，豪掷千金去买一个暂时不赚钱的“潜力股”？但这背后，可不仅仅是“有钱任性”，而是一场AI编程领域深思熟虑的**“基建狂魔”式布局**。更劲爆的是，Anthropic还顺势官宣了一个惊人数字：Claude Code在面向公众开放仅6个月后，年化营收就已突破了10亿美元大关！13 好家伙，这是妥妥的“左手吸金，右手囤装备”啊！

谁是Bun？竟让AI巨头“上头”到无法自拔？

可能有些小伙伴对Bun还不太熟。简单来说，Bun就是前端和后端JavaScript开发者的“效率神助攻”。它可不只是一个简单的JavaScript运行时，而是一个集大成者：运行时、包管理器、打包器和测试运行器，统统安排得明明白白！24 用它来跑JavaScript代码，那速度简直是“坐上了火箭”，比传统的Node.js快上好几倍！

Anthropic为啥对它“上头”？官方的说法是，Bun一直以来都是支撑Claude Code基础设施扩展的“关键力量”。很多AI编程工具，比如Claude Code、FactoryAI、OpenCode，都离不开Bun的加持。想一下，当AI智能体（Agent）要帮你写代码、跑测试时，如果底层的工具链慢悠悠的，那体验简直是“灾难片”现场。

而Bun最“骚”的操作，就是它的单文件可执行程序（single-file executables）功能。你可以把任何JavaScript项目打包成一个自包含的二进制文件，不管用户有没有安装Bun或Node，都能直接运行。这对于需要高效分发和部署CLI工具、AI Agent来说，简直是“神来之笔”！用Anthropic首席产品官Mike Krieger的话来说：

“Bun 恰恰代表了我们希望引入 Anthropic 的那种卓越技术。Jarred 和团队从第一性原理出发，重新思考了整个 JavaScript 工具链，同时始终关注真实场景。”1 (嗯，这大概就是大佬看大佬，惺惺相惜的最高境界吧。)

从“我的世界”到AI核心，高中辍学大佬的逆袭之路

要聊Bun，就不得不提它的创始人——Jarred Sumner。这位小哥，可谓是“天赋异禀”的典型代表。早在五年前，他还是个在浏览器里捣鼓《我的世界》像素游戏的技术宅。可每当代码库越写越大，一个小小的改动都要等上45秒才能测试，这让他忍无可忍！1 别问，问就是“打工人”被开发环境折磨的痛苦！

于是，Jarred一怒之下，决定自己动手丰衣足食。他把esbuild的JSX和TypeScript转译器从Go语言迁移到Zig语言。仅仅三周，一个“勉强能用”的转译器就诞生了。更传奇的是，Jarred在自己的X（前Twitter）简介上，赫然写着“高中辍学”！他曾获得PayPal联合创始人Peter Thiel设立的“Thiel Fellowship”，这个项目专门鼓励年轻人“辍学创业”，提供20万美元资助。妥妥的“天选之子”剧本！1

Jarred在奥克兰狭小的公寓里“闭关修炼”，一边写代码，一边在社交媒体上更新Bun的进展。为了让Next.js的服务端渲染跑起来，他硬是啃了一个月WebKit的源码，搞懂了JavaScriptCore的底层奥秘，最终搞出了Bun的初代JavaScript运行时。

2022年7月，Bun v0.1.0横空出世，瞬间引爆开发者社区，发布第一周就斩获2万颗GitHub Star！Jarred回忆道，那两周简直“疯狂”，他从整天写代码变成了整天回复消息。随后，Bun所属的公司Oven获得700万美元种子轮融资，Jarred也终于可以“领工资，招小弟”了。1 2023年9月，Bun v1.0正式发布，团队扩充到14人，又完成了1900万美元的A轮融资。

“这感觉大概比目前的发展进度领先了几个月，绝对不是几年那么遥远。”1 (翻译一下：这AI代码能力，简直是“YYDS”啊！)

“0收入”也敢“叫板”？Bun为何选择“嫁入豪门”？

回到那个灵魂拷问：Bun为啥选择加入Anthropic，而不是继续独立发展、探索商业化呢？毕竟，Bun的月下载量已超700万，GitHub上拥有超过8.2万颗星，Midjourney、Lovable等明星公司都在用它。手里还有能支撑4年多的资金跑道，完全可以继续“浪”下去啊！12

Jarred直言，他收到的最多问题就是关于可持续性的：“Bun怎么商业化？”“它五年后还在吗？”面对这些，他以前的标准回答是：最终会做云托管产品，并与Bun运行时和打包器进行垂直整合。

但时代变了，AI编程工具正在极大地改变开发者的生产方式。当AI智能体成为编写代码的主力军时，底层基础设施的重要性就变得前所未有的高。

“与我刚开发 Bun 时的世界已经截然不同。AI编程工具正在极大地改变开发者的生产方式，而当由智能体来编写代码时，基础设施层变得愈发重要。”1 (划重点：这不是“躺平”，这是“拥抱未来”！)

  • “前排座位”： 能提前洞察AI编程工具的未来趋势，让Bun的演进更具前瞻性。

而且，Bun的开源承诺不变，依然会保持MIT协议，原有团队继续负责开发，并在GitHub上公开构建。Anthropic之所以要这么做，一个很重要的原因是Claude Code本身就是以Bun可执行文件的形式交付给数百万用户的——“Bun出问题就是Claude Code出问题，因此Anthropic有充分动力把Bun做好。”1 简直是“一荣俱荣，一损俱损”的利益共同体！
