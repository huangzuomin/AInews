狂揽4万星！OpenClaw最强平替来了：5美元养个“会进化”的AI打工人

温故智新AIGC实验室

TL;DR：

别再盯着OpenClaw那只容易“断片”的龙虾了，Nous Research整出了个会自己写SOP、越用越聪明的开源Agent神器。不仅支持5美元VPS“穷养”，还能在Telegram上随叫随到，主打一个“拒绝失忆，带脑子上班”。

别让那只“龙虾”折磨你了，AI也需要“脑白金”

在Agent圈子里，OpenClaw（也就是大家常戏称的“龙虾”）一度是很多人的心头好。但用久了，大家发现这玩意儿有个致命槽点：记性差得像金鱼，工作流动不动就“断片”。你辛辛苦苦教了它半天怎么写周报、理数据，睡一觉醒来，它可能就一脸无辜地问你：“亲，你谁？”1

最近，Agent开源社区终于坐不住了。由顶级实验室Nous Research打造的Hermes Agent横空出世，上线不到两个月，GitHub Star数已经狂飙到4万星2（也有版本显示在28k+，但这涨粉速度，基本就是Agent界的顶流预备役了）。

它的口号很嚣张：“一个会跟着你成长的Agent”。简单来说，它不仅是个干活的工具，还是个懂得自我复盘、不断优化的“赛博员工”。

技术大揭秘：它是怎么学会“偷懒”的？

Hermes Agent之所以能让网友大呼“换掉OpenClaw太爽了”，核心武器是一个叫**“内置学习闭环（Built-in Learning Loop）”**的黑科技。

这个闭环被拆成了三层，层层递进，把AI的“职场进化”玩明白了：

  1. 第一层：永不磨灭的记忆。 不同于那些聊完即忘的聊天机器人，它内置了MEMORY.md和USER.md。前者记录环境信息和历史教训，后者记录你的偏好（比如你喜欢Markdown还是表格）。它甚至支持基于FTS5的跨会话搜索，几个星期前你随口提的一句需求，它都能给你翻出来2。
  2. 第二层：自主技能生成（Skill Generation）。 这是最骚的操作。当它完成一个复杂任务（比如连续调了5次工具），它会自我总结：“诶，这套连招不错，我把它写成个脚本吧。” 于是，一个结构化的.skill文件就诞生了。下次遇到类似的事，它不再重新推理，直接调用“技能包”，效率拉满3。
  3. 第三层：训练数据反哺。 它在日常干活时产生的轨迹，可以直接拿来喂给下一代模型。这种“边工作边产生训练集”的逻辑，简直是把AI的自我进化写进了基因里。

调侃式点评： 这种自己给自己写SOP、自己给自己攒经验的自觉性，建议全国的实习生都进来学习一下。

5美元“穷养”出奇迹，一键跑路OpenClaw？

很多AI Agent框架动不动就要高端GPU，或者让你在云端烧钱。Hermes Agent主打一个“经济实惠”：每月5美元的廉价VPS（大概也就一杯奶茶钱）就能跑起来1。

它不锁定任何大模型厂商。你可以接入OpenRouter上的200多个模型，可以用本地的Ollama，甚至可以用Kimi或MiniMax。它就像一个不挑食的“特工”，只要有API，它在哪都能上班。

最让社区兴奋的是它的网关（Gateway）系统。你可以通过Telegram、Discord甚至是企业微信跟它聊天。在公司电脑端发起的任务，下班路上在手机Telegram上就能看进度。如果你是OpenClaw的老用户，官方甚至贴心地准备了hermes claw migrate命令，一键搬家，数据和记忆全带走，连API Key都不用重新输1。

行业“地震”：谁笑了谁哭了？

Nous Research并不是什么草台班子，这支20人左右的精英团队刚拿了5000万美元的A轮融资。他们之前出的Hermes系列开源模型下载量已经超过了5000万次2。

这一次，他们不再只是卖“发动机”（模型），而是直接造了一辆“自动驾驶汽车”（Agent）。对于那些主打云端闭源Agent的平台来说，这无异于一次降维打击。当用户发现5美元就能在自家服务器上养个私有、安全、且会自我进化的AI时，谁还会愿意把数据拱手交给云端平台呢？

当然，Hermes Agent目前也有天花板：它的“聪明”程度依然取决于你背后接的模型。它目前还不会自动微调模型权重，只是在应用层玩到了极致2。

未来预测：私有AI的自进化时刻

长期运行，才是Agent真正的工程挑战。Hermes从v0.5的“安全加固”到v0.8的“智能 release”，进化路径非常清晰：先活下来，再跑得稳，最后再谈智商2。

当Agent开始自己积累技能、自己生成训练数据、再反哺模型时，一个不需要人工干预的“自进化系统”就不再是科幻电影里的情节了。

如果你已经厌倦了每天对着AI重复同样的指令，或者担心隐私泄露，那么一行命令部署一个Hermes Agent，或许是你开启“赛博员工”时代的最佳姿势： curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash 3
