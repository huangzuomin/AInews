余烬与薪柴：中国 AI “双雄”的高价逻辑与代币经济学

温故智新AIGC实验室

TL;DR：

智谱与 MiniMax 在港股的狂飙揭示了估值逻辑的范式转移：从衡量流量的“软件”转变为衡量产能的“数字能源”。即便面临 700 倍市销率的荒诞，市场正押注于 Agent 时代 Token 消耗从“人类间歇性”向“机器永续性”的指数级跃迁。

2 月 20 日，当港股恒生科技指数在马年的首个交易日蹒跚跌落近 3% 时，两颗来自人工智能领域的彗星却划破了惨淡的云层。上市未满百日的智谱与 MiniMax，以一种近乎挑衅的姿态无视了大盘的引力。智谱单日暴涨逾 42%，其市值跃升出的一个“B 站”身位，足以让那些还在纠结基本面的分析师们推倒重来。12

这两家年轻的公司——一家上市 60 天，另一家仅 43 天——正以超乎常理的速度在市值榜单上超越携程、快手与京东，直逼搜索引擎老大哥百度的侧翼。这种令社交媒体充斥着“高处不胜寒”的恐慌与“未能上车”的悔恨的混合情绪，背后隐藏着一个远比股价波动更深刻的商业悖论。

价格战的终结，还是定价权的开端？

在过去的一年里，中国的大模型市场看起来更像是一个底特律式的折扣卖场。字节跳动的豆包曾将价格压低至每千 Token 几厘钱，阿里与腾讯随之跟进，试图通过焦土政策清理战场。然而，这种“流量换规模”的旧互联网逻辑在今年 2 月戛然而止。1

智谱于 2 月 12 日发布的涨价函，不仅没有吓跑客户，反而成了某种“反向营销”。其编程套餐整体涨幅自 30% 起，海外 API 价格直接翻倍，结果却是上线即售罄。1 这种极其缺乏弹性的需求证明了一件事：在 AI 的世界里，开发者不再仅仅追求便宜的“流量消耗”，而是在争夺稀缺的“优质算力产出”。

如果说过去的模型是按需取用的自来水，那么现在的旗舰模型更像是高端制造业的精密机床。当 MiniMax 的 M2.5 模型定位为“Agent 场景原生设计”时，它实际上是在重新定义供需关系。正如中金公司所指出的，行业定价逻辑正在发生质变：从廉价的“走量”转向了对“算力价值变现”的硬性溢价。1

700 倍 PS：一场关于“数字电力”的豪赌

对于信奉格雷厄姆式价值投资的信徒来说，MiniMax 高达 **700 倍的市销率（PS）**简直是一场财务上的亵渎。3 相比之下，OpenAI 约 65 倍、Anthropic 约 190 倍的估值倍数显得异常“理性”。1

然而，资本市场之所以愿意支付如此高昂的门票，是因为他们正在重构对“Token”的认知。

  • 消耗范式的切换：人类用户的手速是 Token 消耗的天花板，但 Agent（智能体）不是。一个 7×24 小时不间断运行、自主决策的 Agent，其 Token 消耗量是人类的百倍甚至千倍。
  • 从软件到能源：如果我们将 Token 视为“数字能源”，那么智谱和 MiniMax 的市值就不应按软件公司（PS）来衡量，而应按电力公司（产能与负荷率）来估值。

正如 2000 年人们无法预见短信业务将演化为移动互联网的汪洋大海，今日的 3000 亿港元市值，本质上是市场为“Agent 时代全面到来”投下的一张远期期权票。14 投资者赌的不是今天的 5000 万美元营收，而是未来作为“通用基础设施”的定价权。

稀缺性溢价与未知的黄昏

但在拍案叫绝之余，我们仍需警惕这种“繁荣”下的裂痕。MiniMax “卖一块赔十块”的财务现状，以及其海外收入高度依赖 AI 社交应用 Talkie 的结构性风险，都是不可忽视的变量。1

此外，港股市场的特殊性放大了这种狂热。在一个渴求中国 AI 纯正标的的市场中，当资金涌入智谱与 MiniMax 这极窄的赛道时，溢价便不再完全由技术领先程度决定，而是由标的的稀缺性驱动。2

在全球视野下，尽管国产大模型在编程与特定 Agent 场景展现了极强的韧性，但面对亚马逊、微软与 NVIDIA 背后交织的战略深度，中国 AI 双雄仍是在“狭缝中起舞”。1 它们敢于涨价的底气来自于短期的供需错配，而长期的护城河则取决于它们能否在 Token 价格战归来前，彻底完成从“技术陪跑者”向“生态掌控者”的蜕变。2
