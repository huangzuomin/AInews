挡住豆包的那堵墙，被“龙虾”推倒了：手机AI正式进入“养虾”时代

温故智新AIGC实验室

TL;DR：

以前你以为手机APP是“割据一方”的诸侯，现在“龙虾”（OpenClaw）告诉它们：大人，时代变了！小米、三星带头在手机里“养虾”，字节豆包准备变阵突围，连傲娇的苹果都开始请救兵，一场关于“谁才是手机真正入口”的混战正式打响。

最近 AI 圈最火的生物是什么？不是奥特曼家的那个“奥德赛”，也不是哪家实验室的机器狗，而是一只名叫 OpenClaw 的“龙虾”。1

这个开源的多智能体框架在 PC 端火得一塌糊涂，现在火星子终于烧到了大家的裤兜里。上周，小米启动了移动端 AI Agent 产品 miclaw 的封测。雷军在微博上兴奋得像个刚拿到新玩具的孩子，连发三条动态，直接给它赐名：“手机龙虾”。1

一时间，整个手机圈都响起了“乒乒乓乓”拆墙的声音。

小米雷军也“养虾”：AI Agent 从 PC 烧到手机

小米这只“龙虾”可不是来陪你聊天的。基于自研的 MiMo 大模型，miclaw 的目标很明确：少废话，直接干活。2

在小米的设想里，你只需要说一句“我要带朋友回家，准备一下”，miclaw 就能自动帮你调灯光、放音乐、烧热水。2 以前实现这些得在各种智能家居 APP 里点到手软，现在 Agent 就像个掌握了你家所有钥匙的管家。

但想要这只“龙虾”好使，前提是它得有“特权”。

调侃点评： 以前的小爱同学是“电子客服”，现在的 miclaw 像是拿了系统“最高赦免权”的特工。

小米 miclaw 运行在系统底层，拥有 50 多项系统级原生 API 的调用权。3 相比之下，一直被超级 APP 们“围追堵截”的豆包手机助手，处境就有些耐人寻味了。

“暴力读屏”vs“官方开底盘”：Agent 的技术路线之争

同样是让 AI 替你操作手机，江湖上分成了两派：

  1. “暴力美学派”（豆包手机助手）： 走的是 GUI 读屏路线。AI 像人眼一样盯着屏幕，截屏、分析、模拟点击。4 这种方案最通用，但最不招大厂待见。微信、银行 APP 一看这操作，反手就是一个“账号环境异常”警告，直接把你关在门外。5
  2. “正统基建派”（小米 miclaw、谷歌 AppFunctions）： 走的是 API 调用路线。小米通过系统原生的 AIDL 协议操作，稳如老狗，还不怕被封号。3 谷歌联手三星推出的 Gemini 智能体也类似，主打一个“名正言顺”。4

豆包此前因为太“不讲武德”，被马化腾在内部会议上点名批评“不安全、不负责任”。1 但吊诡的是，当 OpenClaw 这种“外来龙虾”席卷全球时，曾经傲娇的超级 APP 们，态度竟然微妙地发生了转变。

为了不掉队，从飞书到钉钉，各大 APP 竟然开始主动对接 OpenClaw 相关的标准。1 这就造成了一个很有趣的“双标”现场：既然你能接纳“洋龙虾”，凭什么把家门口的豆包挡在墙外？

这堵以“安全”为名修筑的高墙，终于在 OpenClaw 的重锤下裂开了一道缝。

超级 APP 的城墙，挡不住“真香定律”

在科技圈，有个长久以来的迷思：用户真的愿意把隐私交给 AI 吗？

OpenClaw 用 100 天证明了：只要 AI 足够好用，用户是愿意“让渡”一部分控制权的。1 大家都想当“甩手掌柜”，这种对效率的渴望，直接掀翻了所谓的“数据安全城墙”。

这时候，最慌的可能不是那些被封锁的 Agent，而是苹果。

常年靠 Siri 卖萌、AI 进度拉胯的苹果，在 2026 年初终于低下了高贵的头颅，宣布下一代模型将基于谷歌 Gemini 打造。1 连“探照灯”苹果都得去请救兵，说明这波“手机龙虾”的浪潮，谁也躲不过去。

下一个出口：Agent 手机还是超级 APP？

字节也没闲着。既然“暴力读屏”容易被封杀，那就换个姿势。最近火山引擎上线的 ArkClaw，似乎暗示豆包手机助手正在向 OpenClaw 的技术栈靠拢：不再强求模拟点击，而是构建一个通用的智能体框架。1

一个扎心的现实正在浮出水面：

  • 对于手机厂商来说： Agent 是保卫硬件入口、重塑流量分配的“杀手锏”。
  • 对于超级 APP 来说： 这是一个悖论。不接入，会被时代抛弃；接入了，用户可能再也不会点开你的首页，只会对着手机说一句“帮我点个外卖”。

超级 APP 的黄昏或许还没到，但那种“只要我守住接口，用户就得在我这儿看广告”的好日子，确实快到头了。

大家都在忙着“养虾”，谁能先让这只龙虾在手机里“活”得舒坦，谁就能拿到 AI 时代的超级门票。至于那些还在固守城墙、拒绝互联的旧势力，可能很快就会发现，用户已经带着他们的“龙虾”，搬家去新世界了。5
