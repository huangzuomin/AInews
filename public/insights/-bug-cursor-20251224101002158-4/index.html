写代码爽如龙，修 Bug 累成狗？Cursor：不装了，我直接买个“质检员”回来！

温故智新AIGC实验室

TL;DR：

Cursor 觉得自己写代码太快，人类的 Code Review 已经跟不上趟了。为了不让自家的编辑器被 Bug 堆到“散架”，他们反手买下了拥有 Meta 纯正血统的评审神器 Graphite，准备在 AI 时代把“写、审、合”一条龙彻底焊死。

现在的程序员，快乐往往只需要一个 Tab 键。

自从 Cursor、Claude Dev 这些 AI 编程神器横空出世，写代码这件事从“逐行雕琢”变成了“狂暴输出”。你以为你在写代码，其实你是在盯着屏幕玩《节奏大师》，只要 Tab 按得够快，千行代码平地起。

但这种“爽”是有代价的。就在 12 月 19 日，这头估值 293 亿美元的独角兽 Cursor 官宣：他们把代码评审初创公司 Graphite 给“吞”了。 1

这操作背后的逻辑很硬核，也很扎心：AI 写代码的速度已经比人类读代码的速度快了 70%，如果再不找个靠谱的“质检员”，这套代码库迟早得因为 Bug 太多而当场“散架”。

技术大揭秘：当 Code Review 遇上“暴力美学”

所有程序员都懂一种痛：你辛辛苦苦写完一个功能，发起一个 PR（拉取请求），结果 Reviewer 忙着改 Bug 根本不理你；或者更惨，他直接回你一句 “LGTM” (Looks Good To Me)，然后上线就崩。

这就是现状——AI 已经进化到了 2024 年，但人类评审代码的方式居然还停留在 2011 年。

“在过去 2.5 年里，Cursor 让写代码快了很多。但对大多数团队来说，评审代码的方式和三年前一模一样。” 1 —— Cursor CEO Michael Truell

根据 Graphite 的数据，现在每位工程师产出的代码量比去年多了 70%。这不仅是工作量的增加，更是**“信任模型”的崩塌**。以前你看到同事的代码，大概知道他的思路；现在你看到一个 3000 行的 PR，心里只会想：“这到底是哪个 Agent 乱吐出来的？它真的能跑吗？”

Cursor 的投资人 Theo 甚至开启了“毒舌”模式：他上周专门去 Cursor 办公室吐槽了两小时，因为这软件 Bug 实在太多，看起来“正在慢慢散架”。1 于是，Cursor 决定暂缓新功能，开启“硬核修 Bug 模式”，顺便把专门帮人修 Bug、理流程的 Graphite 给收了。

行业“地震”：谁是 Stacking 模式的真神？

Graphite 并不是一家普通的 AI 公司，它带有一种**“Meta 基因”**。

这群创始人曾在 Meta（Facebook）工作，回到了 GitHub 体系后，感觉就像从开法拉利变成了蹬三轮。在 Meta 内部，工程师们不用 GitHub 那种“一个功能一个大 PR”的笨办法，他们用的是一种叫 Stacking（堆叠） 的高级玩法。1

  • 传统模式： 写一个大功能 -> 提一个巨型 PR -> 等待 -> 被阻塞 -> 摸鱼。
  • Stacking 模式： 把任务拆成无数个小 commit（改动） -> 像叠罗汉一样一层层往上盖。

在 Graphite 的世界里，改动被拆得很细。哪怕你还没等第一个小改动合进去，你就可以直接在它上面写第二个。这种“小步快跑”的节奏，简直就是为 AI Agent 量身定制的。

“超过 100 行的代码，基本就不适合 AI review 了。” 1 —— Graphite 联合创始人 Tomas Reimers

Graphite 的 AI 评审规则非常清流：它会把大 PR 拆成“肉片”，让 AI 像吃火锅一样一小口一小口地品。它不仅能发现你的逻辑漏洞，还能留下**“可落地的行内评论”**。最重要的是，如果它没把握，它会选择“保持沉默”，绝对不乱发无意义的意见来刷存在感。这种“克制”，才是 AI 时代最稀缺的信任。

未来预测：下一个“风口”是给 AI 擦屁股？

Cursor 这波收购，相当于是把**“创建、评审、合并”**这三块拼图凑齐了。2

以前 Cursor 只是一个“打字机”，现在的它正试图变成一个“全自动工厂”。整个 Graphite 团队都会并入 Cursor，未来的进化方向已经很明确了：

  1. Bugbot 进化： Graphite 的 AI Reviewer 将与 Cursor 的 Bugbot 融合，打造地表最强“找茬”工具。
  2. 流程自动化： 从“我有一个想法”到“代码上线”，中间那些烦人的合并冲突、重连、Rebase，全部交给 Background Agents 去搞定。
  3. 资深工程师解脱： 资深架构师只需要在开头写好设计文档（Markdown 赛高！），在结尾把好质量关，中间的体力活全丢给这套集成系统。

说白了，Cursor 正在从一个单纯的 IDE（集成开发环境），向一个 AI 驱动的工程闭环转型。

如果你还在纠结要不要学写代码，或者担心被 AI 替代，这笔收购给了我们一个启示：代码本身正在变得廉价，但能够定义结构、约束质量、以及在千万行生成代码中揪出那个致命 Bug 的能力，反而变得越来越值钱了。

毕竟，能写出 10000 行代码的 AI 到处都是，但能确保这 10000 行代码不让公司倒闭的工具，可能只有买了 Graphite 的 Cursor 了。3
