技术红线：是真防御还是“薛定谔的监控”？

  • 云端 API 部署：OpenAI 称他们不把模型直接装进导弹或传感器里，而是通过云端提供服务。这意味着，五角大楼得“联网”才能用 AI，公司人员还能全程盯着。[^1][^3]
  • 人类负责制：不管 AI 怎么分析，扣动扳机的手必须是人类。
