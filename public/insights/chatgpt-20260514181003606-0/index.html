谷歌给鼠标装上「大脑」，ChatGPT聊天框要凉？

温故智新AIGC实验室

TL;DR：

别再跟ChatGPT玩「角色扮演」写小作文了。谷歌直接把AI塞进了你的鼠标里，现在你只需指着屏幕说句“把这个，移到那”，它就能帮你搞定一切。这波操作，是冲着干掉聊天框去的。

1968年的旧金山，一位叫道格拉斯·恩格尔巴特的仁兄，在一个后来被誉为“演示之母”的发布会上，掏出了一个带着两个小轮子的木盒子——鼠标诞生了。1

那是人类第一次用手里的小玩意儿，去指挥屏幕里的小箭头。此后的五十多年里，这根箭头穿过Excel表、游戏地图和无数个网页，成为我们进入数字世界最熟悉的向导。但它也“笨”得可怜：它知道自己的坐标（X，Y），却永远不知道你指着的，是一张发票、一行代码，还是一只猫的照片。

它能做的，只有三件事：点击，拖拽，等待下一次点击。

但在刚刚结束的Android Show上，谷歌干了件大事：它给这个“睁眼瞎”的鼠标，装上了“眼睛”和“大脑”。

这根开了光的AI箭头，到底能干嘛？

你可能会问，现在AI不都挺牛的吗？聊个天、写个诗、甚至还能帮你P图。但谷歌觉得，现在的AI交互体验，简直是个“反人类”的灾难。

想象一下，你正沉浸式阅读一份50页的PDF，突然想让它总结一张图表。你得做什么？截图 -> 保存 -> 打开浏览器 -> 进入AI网页 -> 上传图片 -> 输入提示词。这一套组合拳下来，你的创作“心流”早飞到九霄云外了。

谷歌管这叫 “AI绕路（AI detours）”。2 说白了，就是AI能力很强，但找到它、用上它的过程，比直接上手干还麻烦。

所以，谷歌的解决方案简单粗暴：把AI的“灵魂”，直接注入你每天摸来摸去的鼠标里。

  • 第一，看图说话的终极形态。 你看到一张城市风景照，想移动其中的一栋建筑。以前你得学PS，现在你只需把AI光标悬停在那栋楼上，然后对着麦克风说：“把‘这个’移到那儿去。”3 AI光标会瞬间理解你指的像素是什么，并完美执行。鼠标从告诉你“我点了哪里”，进化到了告诉你“我指的是什么”。

  • 第二，告别“提示词小作文”。 再也不用写“请将以下食谱中所有食材的分量乘以二，并保持风格不变，谢谢”这种又长又绕的Prompt了。你只需要用光标选中那段文字，随口说一句：“把‘这些’的分量翻倍。”唰的一下，AI就在原地给你改好了。3

  • 第三，把屏幕变成“活的”。 你在刷旅行Vlog，视频里闪过一家看起来很棒的餐厅。按下暂停，用鼠标指过去——好家伙，原本死气沉沉的画面瞬间活了，旁边直接弹出这家餐厅的订座链接。3 或者你拍了一张写满鬼画符的便利贴，鼠标一指，它立马变成一个可以打勾的To-Do List。

发现没？以前，是你屁颠屁颠地去找AI；现在，是AI顺着你的鼠标，乖乖来到你的指尖。

杀死AI提示词，回归人类“指手画脚”的本能

谷歌这次的设计哲学，说白了就一句话：拥抱“这”与“那”的力量（Embrace the power of This and That）。2

这才是人类最自然的沟通方式。你跟同事改稿子，绝对不会说：“请将坐标(120, 350)处的蓝色矩形右移50像素。”你只会指着屏幕说：“把这个，往右挪一点。” 我们极度依赖“这个”、“那个”，配合手势和极简的口语。机器应该来适应人，而不是让人去学机器的“黑话”。

好消息是，这把“魔法指针”已经开始落地。Chrome浏览器里的Gemini已经率先支持，而谷歌新发布的笔记本产品线 Googlebook，更是直接把这功能内置进了操作系统层面。4

说到Googlebook，这可不是一台普通的笔记本。它被定义为“Android手机的完美伴侣”。你可以像苹果的iPhone镜像一样，把手机App直接投射到笔记本桌面上跑，文件也能跨设备自由穿梭。5 它甚至还有个专属的“Glowbar”发光条，生怕你看不出它跟普通笔记本的区别。首批产品将由宏碁、华硕等五家厂商制造，预计今年秋天上市。5

这背后，指向的是谷歌传闻已久的“Aluminum”系统——一个深度融合了Android和ChromeOS的全新系统。AI，正在成为操作系统级别的基础设施。

人机交互的十字路口：Chatbox只是过渡品

回看1968年的那个初代鼠标，功能简单到令人发指：追踪位置。此后半个多世纪，它虽然加了滚轮、加了侧键，但它的“灵魂”依然是一张白纸。

谷歌的AI光标，完成了交互史上罕见的一次进化：它不仅知道你在哪，更知道那是什么。 1

过去一年，无数创业公司挤破头，想造出下一个“AI时代的超级入口”。大家疯狂地卷聊天框的拟真度，卷Agent的工作流。但谷歌这次用行动上了一课：最好的科技，是润物细无声。聊天框（Chatbox）从来都不是AI的最终形态，它只是一种过渡期的妥协。 2

未来的AI，应该退居幕后，成为一种附着在你日常动作上的基础设施。从命令行（CLI），到图形界面（GUI），再到触屏（NUI），过去几年的大模型让我们短暂地倒退回了打字交流的时代，让无数人患上了“Prompt焦虑症”。

58年前，当恩格尔巴特握住那个简陋的木制鼠标时，他的终极梦想是“增强人类的智慧”。1

58年后，当AI附身于这个古老的指针，机器终于开始“看懂”这个世界。属于提示词工程师的黄金时代终将落幕，而人机交互的终极闭环，也将在我们一句句含糊不清的“这个、那个”中，向前迈出历史性的一大步。
