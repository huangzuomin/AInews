“软件工程师”要成历史遗迹？Claude Code之父：我把IDE卸了，AI正在自己组队“打怪”

【AI内参·锐评】 别再打磨你那引以为傲的“工匠精神”了，在AI自我重构的巨轮下，你辛辛苦苦写的优雅架构，不过是下一代模型眼中的昂贵垃圾。

【事实速览】 Claude Code 创始人 Boris Cherny 在 YC 访谈中抛出重磅观点：他已完全卸载 IDE，仅凭 Opus 4.5 每日产出 20 个 PR。数据显示，Anthropic 内部人均工程产出因此提升了 150%。Cherny 认为，编程作为核心能力的时代已经结束，取而代之的是“多 Agent 协作”模式。在这种模式下，AI 可以自主组队、Debug 甚至主动跨部门对齐需求。更残酷的是，由于 AI 重构效率极高，代码的“保质期”已缩短至数月。

  • 【[开发者]必读】：不要再沉迷于掌握某种编程语言的语法。Boris 的核心建议是保持“新手心态”。未来的生存门槛不再是写代码（Coding），而是写 Spec（规格说明）和搞定跨部门“扯皮”。如果你还在筑墙（搞复杂的工程套件），你其实是在制造技术债，因为永远不要和模型对赌，新模型发布之日，就是你那些精巧工具作废之时。
  • 【弦外之音】：这不仅是工具的更替，更是生产关系的倒置。当 AI 能够周末自动完成复杂功能研发时，人类从“创作者”降级为“审核员”或“需求翻译官”。软件公司的招聘标准正在从“技术大牛”转向“能承认自己会犯错的终身学习者”。

伦敦警察版“老大哥”上线：Palantir 用 AI 盯梢警察，这波是“内鬼”竟是我自己？

【AI内参·锐评】 监视者正在被监视，当 Palantir 将“猜忌”自动化，警局内部的信任契约正在被冷冰冰的算法粉碎。

【事实速览】 伦敦警察局（Met Police）确认引入硅谷巨头 Palantir 的 AI 工具，对内部员工进行全天候行为分析。系统通过挖掘病假频率、加班模式和巡逻轨迹等数据，构建“风险模型”以捕捉潜在的违规行为。警察工会将此抨击为**“自动化猜忌”**，认为这种不透明的算法监控严重破坏了职业信任，并可能导致由于算法偏见产生的“系统性歧视”。

  • 【弦外之音】：Palantir 这种具有浓厚军方背景的公司入驻警局，标志着**“监控技术由外向内”**的全面渗透。原本用于抓捕本·拉登的技术，现在被用来计算警员周五请病假是否“合理”。这不仅是警务工具的升级，更是管理逻辑向“算法中心主义”的彻底倒戈。
